## 已纠正的问题

1. Decoder 补充表原列名 `sample_weighted_estimate` 与计算顺序不符。合并 query 的 gene-pair balanced accuracy 为 0.8363，队列等权估计为 0.7864（95% CI 0.7742–0.7970）；两者差异有实际解释价值。现列名为 `pooled_query_estimate`，正文说明其逐特征计算方式，区间只对应 `cohort_equal_estimate`。
2. Decoder 基准比较的原文字把 RMSE 写得像逐 query 损失差；实际是每个 cohort、特征先对平方误差均值开方，再比较并汇总。已改正计算说明，未改变真实计算值。
3. 技术近邻图原纵轴写作 “same-technology excess”，但其两臂差严格等于实际同技术近邻比例差。已改为 “same-technology neighbor rate”，避免将背景扣除误读为混杂控制。
4. kNN Jaccard 原区间重算时删去未抽中的 cohort，改变近邻候选库，得到 0.3356–0.3795 的区间；原完整图点估计 0.3349 不在区间内。现在固定完整图、整组重采样 query cohort，区间为 0.3132–0.3547；代码、方法标签、报告解释和合成回归测试均已同步。
5. 结构热图的完整横轴队列名互相遮挡。两张图共用相同行列顺序和色阶；横轴改用顺序说明，队列名称只显示一次，正文指向明细表以定位具体队列对。

## 出版解释边界

2026-10-06 按负责人要求，将 IFNγ 与 IL6-JAK-STAT3 分别评分。两条原签名各含 200、87 个基因，天然共享 22 个，各自在自己的签名中保留。旧合并方案和结果已弃用；本次修订发生于查看原结果之后，不能称为原始预注册或独立确证。

当前广队列结果均基于 43 个 external query cohort、14,060 个配对 query，差值为 d1−Direct 的连续表达近邻效用，正值表示 d1 较高。以下 95% CI 来自 cohort bootstrap；五项 BH 调整后 P 值均为 0.000500。

|---|---:|---|
| 增殖 | −0.043858 | [−0.061002, −0.023924] |
| 免疫 TME | −0.048451 | [−0.067797, −0.027342] |
| 基质 TME | −0.051743 | [−0.069764, −0.033216] |
| IFNγ | −0.051883 | [−0.072874, −0.030248] |

这些负差描述当前连续表达近邻任务上的局部损失，不能单独区分测量异质性、癌种组成和信息可读取性的影响。诊断回算的 215 个 cohort–anchor 格子与当前基线一致，最大绝对误差为 5.6×10⁻¹⁷。全契约共同签名分别仅为增殖 5/15、免疫 4/26、基质 1/18、IFNγ 39/200、IL6-JAK-STAT3 19/87，均未达到严格覆盖门槛；低覆盖残余评分不能替代完整锚点证据。

五锚点结构分析的全队列对正向平均差为 −0.012403（节点 bootstrap 95% CI [−0.029750, 0.004776]），反向为 0.002105（[−0.016810, 0.019001]）。未设可接受损失界值，不能因区间跨零宣布结构等价或无损。100% 学习曲线只有一种独立训练设计，设计层 CI/P 仍为 NA；固定训练设计下的外部 query cohort 区间是另一估计对象。

Reference d1 含 in-sample 生成路径，query d1 来自冻结外部预测；表达锚点又来自相关表达数据。当前结果适合报告为冻结表示的诊断性比较，不能据此声称个性化泛癌分类已有独立临床验证、技术噪声已被选择性消除，或生物结构已证明无损。

## 五锚点高覆盖验证的当前结果

主比较为各锚点选定合同下的秩评分、同癌种候选池，效用差为 d1−Direct，正值表示 d1 较高。实际效应人数须与测量合同人数区分；95% CI 为条件于冻结 bank、测量合同及评分人群的 cohort bootstrap 区间，BH 校正族固定为五项。完整表以 `BH_family` 标明每行 q 值的族：主行沿用跨选定档位的五项主族，其余行使用对应覆盖档、评分和候选池的完整五项族，同档显示的 q 值不能一概归为同一族。

| 锚点 | 共同签名 | 合同 query 队列 | 实际效应队列／query | 效用差 | 95% CI | BH q |
|---|---|---:|---:|---:|---|---:|
| 增殖 | 14/15 | 16 | 0／0 | 不可估计 | NA | NA |
| 免疫 TME | 19/26 | 16 | 14／5211 | -0.004535 | [-0.015527, 0.006751] | 0.773519 |
| 基质 TME | 17/18 | 15 | 13／4804 | -0.016328 | [-0.026619, -0.006451] | 0.056152 |
| IFNγ | 161/200 | 15 | 14／5066 | 0.003138 | [-0.011293, 0.016498] | 0.840302 |
| IL6-JAK-STAT3 | 72/87 | 16 | 15／5473 | 0.008506 | [-0.004300, 0.022726] | 0.670929 |

全部 80 个覆盖率×评分×候选池格子保留，包括不可估计状态。增殖的秩背景仅 4,848 个基因，低于 5,000 门槛，秩主效应保持不可估计；原尺度对照仍保留，增殖仍计入五项 BH 分母。不同锚点的高覆盖人群和共同基因不同，不能直接把各自的效应差异当作通路间差异。区间跨零或校正后不显著均不证明等价或信息无损。

读取器与邻居效用需要分别解释。IL6-JAK-STAT3 的秩 ridge 标准化 MAE 差为 0.049034（95% CI [0.023556, 0.071039]），固定五项 BH q=0.013428，正值表示 d1 误差较高；其秩 XGBoost 差为 0.007528（[−0.023955, 0.038230]），q=1。免疫 TME 的秩 XGBoost MAE 差为 0.036831（[0.015446, 0.058721]），q=0.037842。不同读取器给出的信息可读取性证据不同，邻居效用差不显著不能替代读取器验证，也不能据此概括为全部信息丢失或无损。

完整读取器、覆盖率稳定性、共同患者差中差及留一结果见[生物锚点报告](../test/ablation-03/02.02.00.%20生物锚点分析.html)。严格诊断回算的 215 个 cohort–anchor 格子通过基线核对，低覆盖探索不发布 p/q。

# ablation-03 必要分析双向外部验证优化计划

## 通俗解释：究竟发生了什么

- **一句话说明：** 当前多数分析只让一组固定的 cohort 模型观察另一组新样本，因此一些结论可能既反映 d1 的性质，也反映这组模型恰好覆盖了哪些癌种、组织和平台。
- **具体场景：** 这像只让甲医院医生评阅乙医院病例。即使评阅结果很好，也不能确定是方法本身稳定，还是甲医院的专科配置刚好合适。双向验证会再让乙医院医生评阅甲医院病例，并在两边医生数量和专科构成相近时重复比较。
- **对应到本问题：** 医生是 cohort-specific modules，病例是未参与这些 modules 训练的 target 样本，评阅结果是 d1；Direct-GSClassifier 是同一病例的原生特征对照。
- **改变前后：** 现在主要知道 `reference bank → external targets` 会怎样；改进后还能判断结论换一侧 bank 是否保持、是否受 bank 规模与组织构成影响，以及哪些结果只在特定方向成立。

## 专业判断：问题在哪里

### 当前证据边界

`ablation-03` 已完成双向独立队列生物结构可复现性分析，但其余主要结果仍以正向合同为主：150 个 reference modules 和 reference atlas 提供训练信息，17 个 external cohorts 作为未见目标。当前报告因此能可靠描述既定生产方向，却较难区分以下两种解释：

- d1 的变化是换一组 cohort bank 后仍会出现的表示性质；
- d1 的变化主要来自当前 reference bank 的规模、癌种覆盖、tissue 构成或技术来源。

这一区分尤其影响当前三个关键发现：技术来源聚集一致下降、癌种中心化减弱，以及四个连续表达锚点均偏向 Direct。若这些方向在反向外部投影和公平匹配后仍能复现，机制解释会明显增强；若方向改变，则应把结论收窄为 bank-dependent 现象。

### 现有数据是否足够

本次规划判断为：**实现双向分析不需要新增原始数据。**现有输入已经包括：

- 24,487 个 reference 样本与 5,705 个 external 样本；
- 147 个 reference cohorts 与 17 个 external target cohorts；
- 完整 d1 中的 150 个 reference modules 与 43 个 external modules；
- 两侧样本的 529 维 Direct-GSClassifier 输入及完整 d1 输出；
- 四个表达锚点所需的 signature、完整结构分析 anchor cache、module tissue 审计及样本/cohort 映射；
- 已生成的正向 retrieval、readout、learning-curve、technical inference 和结构可复现性产物。

数据足够不代表两侧天然可比。完整 bank 为 150 对 43 个 modules，共同 tissue 内只能组成 22 对 22 的无放回匹配；反向 readout 的癌种覆盖也可能弱于正向。因此实施时必须先生成资格审计，对不可估计的 endpoint 如实返回 `not_estimable`，不能降低纳入门槛或静默删样本来强行得到结果。

## 要达到什么目标

### 完成后的变化

- 对确实依赖 bank/target 角色的主要分析，同时给出 `reference bank → external targets` 和 `external bank → reference targets` 两个严格无重叠方向。
- 每个方向都在 bank 一侧完成标准化、调参和模型拟合，再把冻结变换应用到未见 target；Direct 与 d1 使用同一批目标样本和同一资格条件。
- 完整 bank 结果回答真实方向下会发生什么；22 对 22 tissue-matched 重复回答规模和组成变化是否改变结论。两类结果分开报告。
- 将结论分为“两个方向一致”“方向依赖”“证据不足”三类，不用单一方向代表 d1 的一般性质。
- 保持现有正向结果和已有结构分析兼容，不改变项目版本号，不引入新数据源。

### 不在本次处理范围

- 不重复实现已经完成的双向生物结构可复现性；它作为本计划的公共 bank、样本和匹配合同来源。
- 不把反向分析冒充生产模型的主要外部验证；生产方向仍以 reference bank 到新 cohort 为主。
- 不把癌种检索或癌种 readout 当作 CCS 新状态的最终生物学效用。
- 不给学习曲线、decoder、module 贡献集中度、null 对照和 breadth/depth scaling 机械增加镜像版本。
- 不扩展到 d2、d3、metaCCS、治疗反应或临床结局，也不修改 `DESCRIPTION` 版本号。

## 统一的双向验证合同

### 方向与外部性的定义

外部性只由“目标样本是否参与当前所用 module 的训练”决定：

| 方向 | Bank/拟合侧 | 未见目标侧 | 完整 module 数 |
|---|---|---|---:|
| 正向 | reference cohorts | external cohorts | 150 |
| 反向 | external cohorts | reference cohorts | 43 |

每个方向必须满足：

- bank cohort 与 target cohort 无交集，fit sample 与 target sample 无交集；
- Direct 的中心、尺度及 d1 的 module-balanced 变换只在 bank 侧拟合；
- anchor gene 的尺度只在 bank 侧拟合；
- readout 的预处理、内部 grouped CV、超参数选择和最终拟合全部限制在 bank 侧；
- target 侧只参与最终计算，不得反馈到特征筛选、阈值、调参或资格规则。

### 完整 bank 与匹配敏感性

完整 bank 是每个方向的主要描述结果，但两个方向的绝对数值不能直接当作“方向效应”比较。公平性检查复用现有 module tissue 审计，在共同 tissue 中每侧抽取 22 个 modules，至少完成 20 次预先固定种子的配对重复。

匹配重复输出的是 **design sensitivity range**，不是置信区间。主要统计区间仍以 target cohort 为重采样单位；同一 cohort 参与多个样本或 dyad 时，不得把这些行视为独立重复。

## 改进方向

### 外部化 d1 对原生空间的改写

当前几何结果主要来自 reference 样本，而 reference d1 被保守标记为 `in_sample`。新增分析应分别在两个方向的未见 target 上计算 Direct 与 d1 的几何一致性，包括 Linear CKA、Distance Spearman 和 kNN Jaccard；同时保存 cohort 级指标，使不确定性不再由单次全局计算代替。

每个方向报告全体 target 的描述值和 cohort 分布。重点判断的不是两个方向哪一个数更大，而是“全局关系较多保留、局部邻域明显重排”这一模式是否双向成立。样本过少、距离方差为零或无法形成 kNN 的 cohort 应进入显式排除审计。

对普通读者而言，这项改变会说明：地图被重画的程度是否只在甲医院病例中出现，换成乙医院病例后是否仍是同一种改法。

### 合并扩展外部癌种检索与技术来源评估

癌种检索与 assay/platform/source technical excess 都来自同一套邻居，因此应共用方向化 retrieval 产物，避免两套候选池或尺度造成不可解释差异。

正反两个方向分别构造 bank atlas 和未见 query，Direct 与 d1 共用目标样本、候选资格、`k` 和近似搜索门禁。癌种 endpoint 继续作为 lineage 保护性参照；technical excess 继续扣除癌种/候选池机会基线，并增加 cancer type、assay、platform、source 条件化结果。必须审计每个 target 癌种在 bank 中的 cohort 覆盖，覆盖不足时标记不可估计。

主要问题是：技术聚集下降能否在两方向复现，以及它是否总与癌种可恢复性下降同步。只有在条件化后 technical excess 仍下降、且生物锚点没有同步恶化时，才增强“选择性削弱技术捷径”的解释。

对普通读者而言，这项改变会区分“方法减少了拍摄设备留下的痕迹”和“方法把设备痕迹连同疾病信息一起冲淡”。

### 为局部独立生物学锚点增加反向外部检验

复用方向化 top-k 邻居和完整结构 anchor cache，分别计算 IFN/IL6、immune TME、stromal TME、proliferation 四个连续锚点的 query–neighbor 距离与 utility。每个方向的 gene-wise anchor 标准化仅由 bank 侧样本拟合，再同时应用于 bank atlas 与 target。

主要 estimand 仍是每个 target cohort 内的 `d1−Direct` 配对差，再对 cohort 等权汇总。四个锚点构成同一多重比较家族；保留效应量、cohort bootstrap CI、sign-flip P 值及 BH 校正。完整 bank 之外，再使用 22 对 22 匹配 bank 检查当前“四个锚点全部偏向 Direct”是否依赖 module 数与 tissue 构成。

若两个方向及多数匹配重复均偏向 Direct，应把结论明确收窄为“d1 不擅长保持局部连续 signature 幅度”；若反向或匹配后方向改变，则结论改为 bank-dependent，不再概括为 d1 的一般性质。

对普通读者而言，这项改变会确认 d1 模糊局部门牌号究竟是稳定代价，还是某一张地图画法造成的。

### 为外部线性 readout 增加反向训练—测试

两个方向都使用 bank 侧样本训练 readout，并只在未见 target cohorts 上评估。Direct 与 d1 独立调参但共享 grouped folds、超参数预算、标签资格和目标样本；d1 仅使用对应方向 bank 的 module blocks。报告 pooled 指标作为当前样本描述，同时以 target cohort 等权 accuracy 差作为主要外部推断。

反向训练侧只有 external cohorts，癌种类别和 cohort 覆盖可能不足。实施不得强求与正向拥有相同类别数，而应预先定义：类别至少需要多少训练 cohorts、目标 cohort 如何纳入、无法预测的类别如何报告。方向间不直接比较 balanced accuracy 绝对值，只比较各方向内部同一目标上的 `d1−Direct`。

22 对 22 匹配 bank 可作为 d1 维度和组织构成的敏感性分析；若计算成本过高，先完成完整双向 readout，再由完整结果是否方向相反决定是否运行全部匹配重复，但这一触发规则必须在查看匹配结果前固定。

对普通读者而言，这项改变会检验：不仅地图外观看起来相似，拿它训练一个简单判别器后，换一批医院是否仍能使用其中的信息。

## 为什么其他小节不纳入

| 小节 | 本次不做双向版本的原因 | 更合适的方法 |
|---|---|---|
| 独立队列间的生物结构可复现性 | 已完成双向完整 bank 和 22 对 22 匹配验证 | 作为统一合同与对照基线维护 |
| 癌种 readout 的样本效率 | 简单交换两侧会同时改变类别、样本量、cohort 数和训练比例，难以解释为方向效应 | 待完整双向 readout 后，必要时做匹配 cohort 子集的重复 cross-fitting |
| cohort evidence 二维 scaling | 研究对象本身就是 bank 如何扩展，单次正反交换不能分离 breadth、depth 和组成 | 多次轮换 bank/target 的 matched cross-fitting，而非镜像一次 |
| module 贡献集中程度 | 描述特定 bank 内部贡献，不是 target 外部泛化问题 | module/cohort bootstrap、排名稳定性和 leave-one-module-out |
| 输入信息压缩与可恢复性 | decoder 主要解释信息瓶颈；反向不是当前关键结论的最短证据链 | 后续若 readout/anchor 显示方向依赖，再做跨 cohort decoder transfer |
| Null 对照 | 关键是维度、秩、稀疏度与 seed 是否公平，不在于方向本身 | 将同一公平 null 嵌入必要分析，而非单列双向章节 |

## 实施范围与顺序

### 建立共享方向化数据层

新增独立的 reciprocal-validation stage，复用 Stage 04 已审计的 module table、reference/external 划分、共同样本、完整 d1 和 matched-bank design。该层一次性生成方向合同、bank/target matrices、metadata、尺度参数和 hashes，供后续四类分析共用。

优先考虑新增：

- `test/ablation-03/05-ablation03-reciprocal-validation_functions.R`
- `test/ablation-03/05-ablation03-reciprocal-validation.R`
- `test/ablation-03/tmp/ablation-reciprocal-validation/`

公共的方向、变换和审计逻辑不得分别复制到 biology、retrieval 和 readout 脚本。可复用 Stage 04 helper，但不要让报告层 Rmd 承担全量计算。

### 先生成共同邻居，再派生三个结果家族

先完成两个方向的 target-only geometry 和 query-to-bank retrieval。随后从同一 retrieval 依次派生癌种检索、technical excess 与连续生物锚点 utility，保证三者的目标样本、候选池和 `k` 完全一致。

这一步完成后应先检查：正向新实现能否在相同合同下复现现有正向结果；若不能，先解释合同差异，不继续用新旧结果混合推断。

### 最后运行方向化线性 readout

在共享方向合同稳定后运行完整双向 readout。先冻结类别资格和 grouped CV 规则，再计算结果；不得根据结果事后调整类别或剔除 cohort。匹配 bank 重复按预先固定的触发规则执行，并与主要 cohort-level CI 分开保存。

### 集成报告而不复制章节

`02-ablation03-experiment.Rmd` 在现有相应小节内增加方向列、完整 bank 摘要和匹配敏感性，不新增四套重复叙事。已有“双向独立队列结构可复现性”保留原位，并在讨论中与局部 anchor、technical excess、readout 形成联合证据表。

同步更新：

- `test/ablation-03/README.md` 的执行顺序、数据合同和主要产物；
- `CHANGELOG.md` 的 `[Unreleased]`，只在实际实施时记录行为变化；
- 新增相邻编号的 reciprocal-validation 合同测试；
- 重新渲染的 HTML、矢量 PDF 和同源 JPG 预览。

## 如何确认完成

### 数据与泄漏门禁

- 两个方向的 fit/target sample overlap 和 bank/target cohort overlap 均为零。
- reference/external modules 分别唯一覆盖 150/43 个 modules；匹配重复每侧均为 22 个且逐 tissue 计数相同。
- 每个方向的全部尺度、anchor 统计量、readout folds 和超参数都只来自 bank 侧。
- Direct 与 d1 在每个 endpoint 上使用相同的目标样本、真实标签和资格集合；缺失不得静默删除。
- 现有原始表达、signature 和 d1 足以完成计算；若缓存 hash 不匹配，只重建受影响缓存，不下载或引入新数据。

### 统计与解释门禁

- 主要推断单位是 target cohort；样本数只作描述，不当作独立重复。
- 正反方向分别报告，不合并成一个伪总体效应；方向绝对值不直接比较。
- matched-bank 重复范围明确标记为设计敏感性，而非 95% CI。
- 癌种、technical、anchor 和 readout 各自固定多重比较家族；CI、P 值与效应量采用同一方向定义 `d1−Direct`。
- `not_estimable` 是合法结果；资格不足时保留原因、分母和排除审计。

### 回归与交付门禁

- 新实现的正向结果在合同一致时复现既有 retrieval、technical、anchor 和 readout 数值；有意改变的合同必须列出差异及影响。
- 合成测试覆盖 bank/target 泄漏、目标样本错配、缺失 module、未知 tissue、单 cohort、类别覆盖不足、零方差和行顺序改变。
- 使用 `C:\R\R-4.3.1` 运行定向测试、Stage 05、Rmd 渲染和必要的现有 Stage 04 回归测试。
- HTML 中所有方向、样本数和区间均由机器可读产物动态生成；图表检查无裁切、错色标或方向标签混淆。
- `git diff --check` 与 BAC 哈希链验证通过；不改项目版本号。

## 结果判读矩阵

| 观察模式 | 最稳妥的解释 |
|---|---|
| 两方向及匹配重复方向一致 | 支持该结果是较稳定的 d1 表示性质 |
| 完整 bank 一致、匹配后减弱 | 结果部分由 module 数或 tissue 构成解释 |
| 正反方向相反 | 结论具有明显 bank/context 依赖，不能概括为 d1 的一般性质 |
| technical 改善但 anchors/readout 不恶化 | 增强选择性削弱技术捷径的证据 |
| technical、anchors 和 readout 同时恶化 | 更接近一般性信息瓶颈或过度混合 |
| 多数结果区间跨零 | 当前数据可完成分析，但跨 cohort 证据精度不足，应报告不确定性而非等价 |

## 风险与待确认事项

- **两侧不对称：** 150 对 43 个 modules、147 对 17 个 cohorts 使反向成为互惠性与 bank 依赖诊断，不是生产方向的等价复制。
- **癌种覆盖：** 反向训练侧可能不能覆盖所有 reference target 癌种；计划接受较小但预先定义的可估计集合，不接受事后放宽规则。
- **混杂仍存在：** 条件化分析可以减轻 cancer/cohort/assay 绑定，不能声称完全消除混杂。
- **计算成本：** 完整表达文件较大，但现有结构 anchor cache 足以服务四个锚点；正常情况下无需再次加载 5 GB 级原始表达。邻居、readout 和匹配重复应设置缓存与 hash 门禁。
- **后验性质：** 这些扩展来自已观察结果后的方法学强化，应在报告中标记为 exploratory/sensitivity analysis，不能包装成事前确认性检验。
- **成功标准：** 本计划提升的是证据对称性和可审计性，不预设 d1 必须胜过 Direct；发现稳定负效应或方向依赖同样属于有效完成。

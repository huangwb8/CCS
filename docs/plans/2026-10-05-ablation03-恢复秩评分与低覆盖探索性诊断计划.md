# ablation-03 恢复秩评分与低覆盖探索性诊断

## 冻结设计

依据负责人“恢复一下”的指示，恢复 common_raw/common_rank 两种评分及评分切换对照，primary 为 common_rank。严格诊断保留共同背景至少 5,000、原签名至少 50% 且至少 8 基因的门槛；不会把门槛放宽后的结果标成完整锚点证据。

独立低覆盖产品仅对四项原锚点的固定共同残余基因计算原尺度／秩代理。全部 190 个契约队列共同背景仍为 1,130；增殖、免疫、基质、IFN/IL6 分别剩 5、4、1、51 基因。清单按可用性交集固定，不按效应、样本或队列改变。基质作为单基因描述，不发布区间或检验；多基因结果可有条件区间，不发布 p/q。不训练低覆盖预测器，不执行低覆盖技术来源／拆分／不重叠分支。

## 缺失与尺度

背景中任一非有限值使该样本秩代理缺失，不缩减样本内背景。原尺度逐基因标尺仅以有限 reference 值拟合（至少两个且标准差正）；任何残余基因不可定标使整个签名不可定标。每个样本须具备全部固定残余基因值。随后每项代理以有效 reference 分数再次定标（至少两个且标准差正），记录 reference 有效人数、基因标尺及每队列有效人数。query 不参与标尺，不填补缺失，不按样本更换基因。

## 对比、区间与用途

复用现有通过精确核对的 top-15 名单，要求两臂各完整 15 个有效邻居。每项代理的原尺度／秩 × 全癌种／同癌种四格及切换差中差使用四格共同患者；另列全癌种广覆盖描述。两项 d1 距离改变各自与对应基线在相同患者上配对，Direct 保持原距离。报告每项对比实际队列及 query 人数，不能把不同人群间变化归因于规则变化。

多基因的 cohort 内患者配对均值再在 cohort 间等权；至少 20 query/cohort、3 cohort、2,000 次 cohort bootstrap 中至少 1,900 次有效，才发布 95% 条件区间。同 cohort 集合共享重采样索引，不发布逐患者区间。区间条件于残余基因、冻结 bank、reference 标尺与已拟合表示，不覆盖基因选择、平台偏差或 bank 重训。单基因仍报告同样的人数门槛和均值，但无区间。所有预定对比完整保留，不按方向筛选。

结果只用于提出“当前残余基因代理对评分、候选池、距离是否敏感”的线索，不能确证原负差根因、完整生物功能保留或临床效用。

## 执行与验收

沿既有包 namespace、_targets.R、crew 与正式 store 执行，科学 helper 不另建 runner。报告读取同一 inference 产品中独立 exploratory 字段，导出独立 CSV／PDF。通用技能 checker 对旧项目包 namespace wiring 的 R/ 布局提示作为预检限制记录，实际一致性由同 DAG 验收判断，不迁移流程。

先执行科学断言、同 DAG 隔离合成验收与 R 4.3.1 包检查／安装，再按技能进行三项新的串行独立审查。正式 tar_make()/tar_watch() 后核对原 172 格、人数与原科学文件 MD5 不变、严格不可估计状态仍保留、低覆盖完整性与无 p/q、正式报告及 store 一致。保持版本 0.8.4，BAC 验证完整；全量执行前不声称新效应已获得。

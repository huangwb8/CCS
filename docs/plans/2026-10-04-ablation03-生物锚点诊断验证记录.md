## 推断与输出口径

utility 使用患者配对、cohort 内均值及 cohort 等权。四格比较使用共同患者；不足 20 个有效患者的 cohort 保留描述值，至少 3 个合格 cohort、2,000 次 bootstrap 中至少 1,900 次有效才发布区间。各 utility 实验的四项原锚点单独成检验族；预定变化和连续读取器采用声明的族，并完整保存原始 P 值与 BH 结果。

相关零方差只影响相关；MAE 使用自身有效分母。相同有效 cohort 集合使用同一重采样索引。读取器仅在 reference 内定标、调参和触发非线性补充，外部 query 不参与选择。所有区间条件于冻结 bank、训练模型及 reference 标尺。

患者级表达、名单和模型只留受控缓存。可分享报告只输出 cohort、模块和实验聚合表。表达单位缺少可靠记录时保留未知；未知平台不作为真实同平台。清单或候选池支持不足保留不可估计状态，不降低门槛。

# ablation-03 生物锚点可视化设计

## 目标与现状

`02.02.00` 报告目前用 coverage、utility 和 inference 表呈现结果，没有正式图。图表应依次回答：整体配对效应是什么、效应在 cohort 间是否一致、锚点分数的基因覆盖是否足以支持解读。保留现有表格作为精确数值和审计入口。

当前正式 `anchor_inference.csv` 有 4 个锚点，均覆盖 43 个 query cohort 和 14,060 个配对 query；队列等权的 d1−Direct utility 差约为 −0.044 至 −0.055，4 个 95% cohort bootstrap 区间均在零以下。`anchor_coverage.csv` 含 190 个 cohort × 4 个锚点，其中 43 个 external query cohort × 4 个锚点均为 `estimable`，19 个组合的基因覆盖率低于 100%，最低约 80.8%。当前 `anchor_missing_pairs.csv` 的 8 个锚点／表示组合均为 0 个缺失分数邻居对。这些数字只描述本次正式产物，不写死到图代码中。

## 图 1：四个锚点的队列等权配对效应

- **主图，放在“连续表达锚点 readout”的推断表之前。** 横向森林图，每行一个锚点；点为 `anchor_inference$estimate`，线为 `ci_low` 至 `ci_high`，零线为虚线。正方向标注“d1 utility 更高”，负方向标注“Direct utility 更高”。
- 行末排印 `cohort_count`、`query_count` 与 BH 校正 P 值。仅 `inference_status == "estimable"` 绘制区间；未达门槛的锚点仅绘空心点并标“描述性”。四个锚点固定为配置文件顺序，不按本次效应大小重新排序。
- 图注写明：先按 query 配对，再按 cohort 等权；线为 cohort bootstrap 95% CI；P 值来自 paired sign-flip 并在可推断锚点内 BH 校正。Monte Carlo P 值按模拟分辨率显示（例如 `<0.001`），不画显著性星号。
- 数据直接来自已有 `anchor_inference.csv`，无需重算生物评分。

## 图 2：各 cohort 的效应方向与异质性

- **主图，紧接图 1。** 43 行 cohort × 4 列锚点的发散色热图，色值为该 cohort 内配对 query 的平均 `utility_d1 − utility_direct`；零为白色，负值为蓝色，正值为橙色。色标以零为中心，正负两侧使用相同绝对范围。缺失组合为灰色且有图例。
- cohort 按 `query_cohort` 字典序排列；不得按本次效应大小重排。每个格子是一个独立 cohort 的估计，不画格子级 P 值。图旁给出每格配对 query 数的范围；完整 `query_cohort`、`anchor`、`query_count`、两臂均值和差值另存 CSV，供追查极端格子。
- **所需最小数据变更：** `.biology_paired_contrast()` 内已有 `query_pairs` 和 `paired`，但最终只返回锚点总体推断。将配对聚合提取到 `.biology_cohort_deltas()` 并导出 `anchor_cohort_deltas.csv`，保留 `anchor`、`query_cohort`、配对 query 数、两臂 cohort 均值和差值；总体推断继续由同一张 cohort 表聚合，避免两条口径漂移。不得从现有 `anchor_contrasts.csv` 反推队列差值，因为该表是汇总值。

## 图 3：锚点基因覆盖边界

- **辅助图，放在 coverage 表之前。** 四个锚点分面；横轴为 `genes_found / genes_required`，纵轴区分 external query cohort 与 reference cohort。每个点代表一个 cohort，轻微纵向错位以减少遮挡；叠加中位数与四分位范围。图内标出各组 cohort 数，0–100% 统一横轴。
- 数据直接来自已有 `anchor_coverage.csv`。图注说明基因覆盖是分数可解释性的条件，不是 utility；`status` 异常或覆盖不足须在图上有单独形状。当前缺失邻居对均为 0，可作为图注数字呈现，无需为全零结果再画一张图。

## 解读边界

`utility = exp(-|锚点分数差|)` 衡量检索邻居的连续表达分数接近程度。锚点来自表达数据，虽不使用癌种标签，仍与模型输入共享数据来源。图 1 的负差只能表明本次锚点局部相似性较低，不能单独推出临床效用或新分型价值降低；图 2 用于查看平均差值是否掩盖 cohort 异质性，图 3 用于追查覆盖所致的解读边界。

# CCS 0.8.8 流式精确搜索接入计划

## 要解决的问题

现有 R 穷举器会同时保存全部切分及逐队列结果，107 个状态在 K5 时就超过保护预算。已验证的 C++ 原型能逐个评价切分、仅保留优秀结果，使本机完整搜索高 K 成为可行选择。正式接入后，用户通过原有函数选择新算法，并直接获得默认 2,000 个优秀方案。

## 接口与行为

增加 `norm_search_method = "stream_exact"`，保留已有默认方法与位置参数。新增参数 `norm_exact_top_n = 2000L` 追加在公开签名末尾，仅控制离散精确搜索；返回至多该数量的候选，不足时返回全部。现有 continuous 模式的继承约束与 `norm_top_n` 保持原定义，不能静默把 stream_exact 改成 DP。

新后端支持固定排序下 K2–K8，复用既有排序、Raw/OptimizeRank 和全部五种目标。R 负责预统计、候选核验与传统结果结构，C++ 负责完整组合遍历和确定性 Top N；原生代码按标准 Rcpp 包结构编译，支持无 OpenMP 时单线程运行。诊断明确记录全集访问数、候选保留范围、数值容差、并行数和最优性状态。同分策略采用明确的 Info 顺序，非默认目标保留队列均值次序。

Top 2000 必须使用小顶堆等有界结构，避免每个候选移动整张列表。结果生成须单独计时；全部保留候选与既有 R 批量评分核对，并通过小规模全候选原始 ROC 对照、完整输出快照和最终候选原始 ROC 抽检验证语义，不把快速评分核验冒充逐项原始 ROC 调用。

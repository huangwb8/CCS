## 问题与目标

这一节已经给出总体和同癌种子集的平均变化及区间，但读者需要在宽表中寻找数值。补充一张两面板图：左侧并排展示两个比较范围的平均差与区间，右侧用 A–B、A–C 共享队列 A 的示意图解释为何不能独立重抽队列对。

## 改动范围

结果面板读取正式 `structural_summary` 的正向全体及同癌种两行，以 d1−Direct 为横轴、零为参考，标注队列数和队列对数。区间沿用已有 95% 队列节点 percentile bootstrap，不混用补充推断表的区间。示意图不含实验结果，只解释共享节点导致的依赖。

保留明细表、统计方法、现有 Figure 11–14 编号与科学结论。新 PDF 和 HTML 通过既有 `structural_report` target 更新，图形参数留在 Rmd 绘图块中，README 和 CHANGELOG 同步说明。包版本不变。

## 实施与验收

1. 补充绘图块和自然、准确的图注，复核区间来源及示意图含义。
2. 依次审查数据流、R 实现和统计解释，按 nsfc-humanization 检查报告表达。
3. 使用 Windows R 4.3.1、项目 renv、正式 targets store 增量渲染，检查 PDF/JPG 与 HTML，核对统计输入哈希和上游 target 时间不变。

完成后应能直接看出两组点估计接近、同癌种区间较宽，并理解 A–B 与 A–C 不能作为独立比较重抽。区间跨零不解释为等价或无损。

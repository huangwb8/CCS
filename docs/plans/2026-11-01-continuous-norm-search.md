# normCCS 连续继承搜索实施计划

## 通俗解释：究竟发生了什么

现有搜索对每个等级数独立寻找分组，增加等级时可能丢掉先前表现好的分界。连续模式先给状态排好顺序，再从少等级方案逐层细分。例如，三等级方案进入四等级搜索时保留原有两个分界，只增加一个分界；每层保留若干优秀方案，供下一层继承。

## 专业判断：问题在哪里

`test/normCCS-optimization/verification.md` 记录训练侧排序网格未达到四项联合目标，而保留论文 K4 分界的细分方案出现点估计增益。这是尝试继承约束的依据，尚不构成新搜索优于旧搜索的实证。现有 DP 的固定方向均值代理与最终目标不同，也不能保证中位数目标全局最优。

## 要达到什么目标

公开函数增加 `norm_mode = "discrete"` 和 `norm_top_n = 10`。连续模式探索 1 到指定 K，固定状态顺序，各层仅继承上一层 top 方案。输出沿用 `Raw`、`Summary` 和现有 Info 映射语法，增加搜索诊断，不改变下游 `newSubtype()` 的使用方式。

## 改进方向

连续搜索由 `subtypeNorm_continuous()` 承担。K1 穷举唯一映射；之后对每个父方案做保留全部分界的受约束 DP，以加权固定方向 AUC 产生候选，并完整评分所有合法单次细分，避免代理目标漏掉该邻域的优秀方案。跨父方案去重后，按原目标保留 top；最终保留结果逐队列用原 ROC 复核。有限 top 仍可能剪掉通向更优高 K 方案的路径。

排序由统一内部函数产生。旧四种规则保持原排序语义；新增队列等权均值 NRR、下尾 NRR、Jeffreys 平滑后的队列中心化 log-odds，以及 RR/NRR 秩融合。它们体现不同的支持度与稳定性取舍，不预先认定一种最优。

## 实施范围与顺序

1. 保存工作区原始 `phenotype.R` 作为离散回归基线，保留用户已有参数布局。
2. 将现有 DP、目标函数原样归入 `phenotype.R` 尾部，新增排序与连续搜索；离散搜索主体保持原样，仅接入共用排序入口。
3. 同步 roxygen、README、受文件移动影响的现有引用、CHANGELOG，并按指定版本更新为 0.8.7。
4. 真实运行合成与回归测试、文档生成、构建及包检查，记录结果和 BAC。

## 如何确认完成

测试必须覆盖旧四种排序和离散结果回归、各目标及两种 ROC 模式、K1 和 K=M、top 宽度变化、父子分界继承、完整单次细分独立穷举核对、确定性、非法参数、公共入口与 `newSubtype()`。较大产物固定写到 `D:/cache/ccs/continuous-norm-087/`。现有真实分析仍由各自原 targets 图控制，本次不启动或替换其正式计算。

## 风险与解释边界

保留分界限制了搜索空间，因此某层得分不保证提高，最终得分也不保证全局最优。训练内改善不能替代外部验证；新排序必须在训练数据上估计并冻结。K1 的唯一恒定评分 AUC 为 0.5，不能代表分类能力。

# ablation-03 统计推断补充计划

## 通俗解释：究竟发生了什么

现有报告已给主要队列比较画出误差范围，但有些图只给出一个数，读者难以判断它对更换队列或更换模块设计有多敏感。好比几家医院都测了同一种指标：把所有患者当成彼此独立，会让结果显得过分精确；先辨认哪些患者属于同一家医院，再按医院重新抽样，才能回答跨医院是否稳定。本项目的“医院”通常是 cohort；模块组合实验则另以设计重复为单位。

本轮只使用已经归档的输入快照与正式 targets 缓存。改进后，每个新增区间都说明它围绕哪个估计量、重新抽取什么、能推广到哪里；没有合理零假设或独立重复的格子继续明确标注为描述结果。

## 专业判断：现有数据是否足够

**结论：足以实施下述补充，无须增加原始数据。**只读核查确认正式 cache root 的输入快照、targets store、表示输入、生物锚点表达缓存和结构结果均存在。表示输入保留 24,487 个 reference 与 14,060 个 query 的 Direct/d1 矩阵及 cohort 元数据；decoder 保留 5,000 × 529 的外部预测矩阵，能与同一批 query 的真值逐行逐列对齐。结构结果保留 11,056 个带两端 cohort 标识的方向性队列对，matched-bank 结果有每方向 20 次设计重复。

现有 `learning_curve.rds` 只有每次训练设计的总体分数，没有逐 query 预测。100% 比例虽然与普通 readout 使用同一批 query，d1 的拟合结果并不完全相同，不能借用 readout 预测冒充学习曲线结果。生物锚点的逐 query utility 也没有单独落盘，但现有表达锚点缓存和 `anchor_retrieval.rds` 足以按原算法重新得到它；缓存记录的原始表达与签名来源目前仍可用于既有哈希核验。两项都需要通过正式 targets 图增量计算，仍不需要新增原始数据。

当前主要推断并非空白：检索、readout、技术近邻和四项生物锚点已有 cohort 级区间与 p 值；学习曲线及 scaling 已有按训练或 bank 设计重复定义的推断表。保留这些定义，避免把新补的条件区间和既有总体效应混为一谈。

## 要达到什么目标

- 给 decoder、几何诊断及有明确抽样单位的局部效应补可追溯的 95% 区间，并保留估计量、样本数、独立单位、方法和不可估计原因。
- 对结构复现的总体配对差，在处理共享 cohort 节点后评估零假设检验；检验有效时报告 p 值及预设比较族内的校正值。
- 对 100% 学习曲线补“固定训练设计、变化外部 query cohort”的条件区间，使其与原有“变化训练设计”的 NA 并列，而不改写后者。
- 所有科学产物和 HTML 只通过现有 `_targets.R`、正式 store 与 `tar_make()` 更新；测试使用同一依赖图的隔离 store。

## 改进方向

### Decoder：先补区间，再定义有意义的比较

以现有预测和真值重算原来的逐特征指标，并按外部 query cohort 整组重采样；每次都重新汇总特征类型。原报告的样本加权点估计与新增的 cohort 等权估计分列呈现，区间必须紧随自己对应的点估计。六个显示指标均可给以冻结 decoder 为条件的 cohort 区间；遇到某次重采样缺少二分类的一个类别或连续特征没有变异，应记录有效重复数，而非填零。

p 值只用于事先写明的配对基准比较：例如 gene-pair 的 Brier score 对 reference 特征阳性率基准，连续特征误差对 reference 均值基准。以同一 query 和 cohort 配对两种预测的损失，再做 cohort 级检验，并控制预设比较族的多重性。Balanced accuracy、Spearman 及为绘图变换的分数可报告区间；不为每根柱子临时选择容易显著的零值。

### 结构复现：把共享队列节点留在推断单位里

保留现有 cohort-node bootstrap 均值区间。对正反方向及全体／同癌种四行，先核验节点重采样在稀疏同癌种网络上的有效重复率和模拟覆盖；再选定与均值差为零相匹配的节点层检验，输出原始及四行同族校正 p 值。若稀疏图不支持可靠校准，该行维持 NA 并写清原因，不能把 11,056 个队列对当作独立观察做普通 t/Wilcoxon 检验。若正文继续解释中位差或 d1 较高的队列对比例，应另给节点重采样区间；它们作为辅助指标，不另建一组事后 p 值。

### 几何诊断：条件性队列区间

由已保存的 reference Direct/d1 矩阵重建原有标准化及模块加权尺度，以 cohort 而非样本对为抽样单位，对 CKA、距离 Spearman 和 kNN Jaccard 重新计算。先做少量只读性能试算，再确定能在合理成本内完成的重复数与固定随机种子；kNN 重采样须处理重复 cohort 的邻居身份，不能直接在旧邻居表上重复计数。新增区间明确限定为**冻结模型和现有 reference atlas 条件下**的队列组成敏感性，不冒充外部新模型验证。三项指标没有共同、自然的零假设，本轮不强配 p 值。

### 单队列结果：给局部波动，不把热图变成显著性地图

检索、readout 已有逐 query 配对结果；每个满足预设样本门槛的 cohort 可在该 cohort 内按 query 重采样，给局部差的点式 95% 区间。生物锚点先从现有缓存恢复完整配对的逐 query utility，再对 cohort–anchor 格子做同样处理。表中明确标为“同队列患者波动”，与跨 cohort 的主效应区间分开；事后选出的最大／最小格子只作追查，不发布未经预设和多重性控制的单格 p 值。

### 100% 学习曲线与模块设计敏感性

在原训练子集、种子和调参合同下保存 100% 训练比例各臂的逐 query 预测，核对重算总体分数与当前产物一致后，按外部 query cohort 重新抽样，给固定训练设计条件下的配对差区间。原来的设计层 CI／p 值仍为 NA，因为 100% 只有一种独立训练 cohort 组合。若保留多个随机拟合重复，需先定义它们如何汇总，不能把重复种子当成新训练设计。

Matched-bank 的 20 次抽样已经展示最小—最大范围。可加预先命名的设计分布中心区间或均值的设计重复区间，但它只衡量当前固定患者和冻结模块池下更换 bank 组成的敏感性；重叠模块使重复并非独立新 cohort，不给人口层 p 值。Module 前十方差份额若需要区间，应在每次按 reference cohort 重采样后重新排序前十，注明它仍是描述性集中度；数据构成和基因覆盖是当前输入的审计计数，不加抽样 p 值。

## 实施范围与顺序

1. 先冻结正式输入、缓存及现有结果的身份和数值基线；把新增估计量、独立单位、比较族与 NA 条件写成验收契约。
2. 优先完成 decoder 与结构总体推断，再补逐 cohort 区间、100% query 条件区间、几何及设计敏感性。新增结果接入正式 targets 依赖和报告来源，保留用户当前未提交的 Rmd 解读修改。
3. 用同一 `_targets.R` 图在隔离 store 上跑保留 cohort、缺失类别、稀疏网络等边界的小型验收；经统计和来源核查后，在原正式 store 用 `tar_make()` 增量更新科学产物、图表与 HTML。`tar_watch()` 只指向该正式 store。

## 如何确认完成

- 每个新增区间都能从正式产物追到估计量、cohort／设计重复数、随机种子、有效重采样数、区间方法与数据身份；原有主要数值在预期范围内保持一致。
- decoder 的点估计与区间对应同一加权规则；结构 p 值通过共享节点和稀疏网络检查；局部区间、设计区间和跨 cohort 区间在表头与正文中清楚区分。
- 100% 学习曲线重新生成的总体分数通过原产物对照；新增 query 条件区间没有替换原设计层 NA。
- 隔离 targets 验收、正式 `tar_make()`、相关数值测试、Rmd/HTML 数字和图表核对完成；正式 store 的 metadata、crew/autometric 日志和 BAC 哈希链可验证。

## 风险与边界

- 几何重算尤其 kNN 的队列 bootstrap 成本可能较高；先测量时间和内存，再确定批次数。成本不足时保留经核验的留一 cohort 敏感性，不把它标成 95% CI。
- 同癌种结构网络、单队列二分类和个别缺失锚点可能导致有效重复不足；输出 NA 是预设的正确结果，不用样本级独立性假设填补。
- 常规 skill checker 对既有项目的 `targets/` 函数目录报 `targets-not-r-first`；这是现存布局与通用模板的差异。本计划遵循项目 `_targets.R`，不为统计补充迁移目录或新增 runner。

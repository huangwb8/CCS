# normCCS 分级搜索与四队列外部验证隔离

## 研究问题与完成标准

原流程相当于在制定分级标准时已经看过验证患者的应答，再用同一批患者评价标准。修改后，验证患者只接受已经定好的评分；即使隐藏他们的应答，训练得到的分级也必须完全一样。

固定上游 CCS 模型和 scaller，比较 K=2–12 在四个指定外部队列的冻结规则表现。搜索仅使用其余满足质量要求且与外部来源无重叠的队列。历史 train/extravalid 名单不决定本轮角色。历史结果留存，不进入本轮候选选择。

## 数据与选择规则

在结局统计之前，以队列名、来源组、患者标识、样本标识和表达指纹建立隔离。四个外部队列及其来源关联队列优先保留在外部侧，搜索侧排除重叠来源；患者重复测量按基线优先、标识字典序保留一次，不依据结局选择。保留既有基线、完整结局和有效 CCS 的质量约束；搜索队列需有两个结局类别和至少两个状态。ICI 限制与历史名单分别审计，不自动作为新增排除条件。

本轮固定训练侧 NRR、OptimizeRank、median（包含仅由搜索数据构成的 pooled All）。每个 K 以训练目标最高、规范化映射字典序决胜；K=2–4 主方案完整穷举并核对 DP，K≥5 使用现有 DP，不声称全局最优。K=4 同条件重算。不按外部成绩选择 K。

每个所选映射的评分顺序从搜索数据确定：训练 pooled one-vs-rest AUC 排序，按训练顺序打破并列，再在训练数据确定固定 ROC 方向。冻结后外部侧仅查表评分。训练未见状态记未映射，不插补，不依据外部结局修改规则。

## 实施范围与顺序

先核查正式缓存 manifest、冻结预测和原始输入对应，分离无结局身份信息、搜索数据及外部数据 targets；新结果写入独立的正式分析子目录，沿用正式 targets store。搜索文件内容与路径均不依赖外部结局或外部审计统计；外部文件改变可触发上游拆分，但相同搜索数据不重建搜索。

然后完成 K 搜索、训练规则冻结、逐队列评价与报告，保留全部搜索候选及 DP 诊断。合成数据通过同一 `_targets.R` 在独立 store 运行，并扰动、打乱、移除外部结局及移除外部队列，逐项比较状态排序、完整候选、目标分数、冻结选择与搜索 target 时间戳。

完整穷举通过已安装 CCS 包的 `norm_prepare_counts`、`norm_auc_batch` 和 `norm_info` 批量评价每一个合法切点向量，不截取 DP 候选；合成小输入逐候选核对原始穷举接口，正式输入核对全部最优并列、固定间隔候选及全部 DP 候选的原生 ROC 分数。这样保留同一目标和搜索空间，同时降低完整枚举的运行成本。

最后执行正式 `tar_make()`，用指向同一 store 的 `tar_watch()` 监测，核查 crew、主进程与 worker 的资源日志，完成正式科学验收与 BAC 校验。报告交付前按 humanization 检查表达及数字不变量。

## 估计对象与不确定性

逐队列报告完整结局分母、映射覆盖率、未映射数、可评价人数与应答数、固定方向 AUC。相对 K=4 的 ΔAUC 在共同可评价患者上配对计算，使用同一患者的结局分层 bootstrap 给出 95% 区间；区间以冻结训练映射为条件，不覆盖训练搜索不确定性，也不支持从十一种外部成绩中宣称某 K 独立验证最优。不设显著性筛选或事后 p 值。

## 验收证据

验收包含患者／来源零交集、外部结局扰动不变性、搜索缓存局部失效、外部固定评分、K=2–4 穷举完整性与 DP 同映射目标一致性、全部 K 外部共同分母比较、文件与 provenance 对应、HTML 渲染及正式 store 的实际重跑复用。原图 config 的 always cue 会使 tar_outdated 保守传播预期失效，验收同时保留这份预检列表与实际 tar_make 前后科学节点的时间戳／哈希，不把二者混为一谈。若 DP 未达到穷举最优，报告差距，不把它作为计算故障。

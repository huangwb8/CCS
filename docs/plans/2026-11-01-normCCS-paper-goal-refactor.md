# normCCS 论文复现与高 K 目标搜索实施计划

## 通俗解释：究竟发生了什么

这次要在同一批数据上，寻找比论文四级分组表现更好的五至十五级分组。具体来说，同一个组合必须让训练队列和外部队列的两种 AUC 中位数都提高。原流程最终推荐 K3，回答的是偏向简单模型的训练内选优问题，不能直接回答这次的问题。

改造后，报告先展示论文 K4 的复现结果，再给出所有 K2–15 候选的四项差值、达标组合及其完整映射。找不到时明确指出卡在哪个指标，并提出下一步可检验的策略。

## 专业判断：问题在哪里

原始有效训练集为 20 个队列、1177 条记录；全部有效数据为 29 个队列、1435 条记录。训练名单、结局、冻结 CCS 和论文映射沿用已经核对的来源，不重新训练 metaCCS。原论文名单中没有有效记录的队列仍在审计表中说明。

旧结果的只读盘点发现：历史排序条件下存在四项中位数均改善的 K≥5 组合，训练侧重新排序的原网格尚未找到。历史排序涉及外部来源，不能把这两个结果合并解释为训练侧学习已经成功。本轮将明确分为训练侧学习、论文冻结顺序条件性分析和论文 K4 三种来源。

## 要达到什么目标

主判据由负责人明确为队列 AUC 中位数。对同一个候选映射，计算训练 OptimizeRank、训练固定方向、全部外部 OptimizeRank、全部外部固定方向四个中位数；K≥5 且四项相对论文 K4 的差值都大于预设数值容差才达标。汇总不包含 pooled All，不按成绩排除队列。

固定 AUC 始终以更高等级预测应答，方向预先固定；不以自动方向 Raw 或平滑概率 AUC 替代。OptimizeRank 沿用原包统计定义，只作结局依赖的描述指标。每个候选都完整保留逐队列 AUC、覆盖、有效等级及训练支持。新的候选、训练内推荐及探索性外部筛选分别登记，不把选优后的外部集称为独立确认。

本轮不修改公共 R API、模型、软件版本、旧 premium 结果或原始输入，也不删除已有 targets 图。旧 K2–30 结果保留为历史产物，新流程限制 K2–15。

## 改进方向

### 先复现论文，再搜索

从现有输入合同恢复原训练名单、107 状态顺序和 K4 映射，逐项核对重点外部 AUC，并对全部训练和外部队列重新计算基线。确认论文映射沿历史排序可表示为连续四段；这给后续比较提供可审查的起点。

### 扩大有科学含义的参数组合

比较四种训练排序、历史完整排序和限制到训练可见状态的历史排序；搜索评分为原 OptimizeRank 与固定方向 AUC；目标包括原 median（含 All）、cohort_median、mean、lower_tail 和 mean_lower_tail。K2–4 完整枚举，K5–15 为明确标注的多起点 DP 加局部改进，不能声称穷举最优。绘图、meta 分析估计器等不改变归一化映射的设置不参与 AUC 调参。

新增保留论文 K4 分界的细分候选：只在原四段内部增加切点，以训练侧两类 AUC 增益的较小值优化，并保留多个不同切点起点。这检验“原四级结构有可迁移信息，重新排序破坏它”这一假设。它继承论文基线来源的限制，单独列为论文条件性策略。

### 使目标与证据对应

先冻结所有候选映射及训练侧推荐，再计算外部成绩。训练推荐仅按训练两类 AUC 的较小增益排序，外部达标表按四项最小增益排序，并列时优先较小 K 和稳定的配置标识。探索性外部筛选是本轮的明确目标，报告保留筛选数量和来源，不声称验证了未见队列性能。

四项中位数与相对 K4 差值给出来源组配对 bootstrap 95% 区间；每次抽取来源组时保留组内队列，不把重叠队列当独立来源。区间以既有预测和候选选择为条件，不包含重新拟合或多候选选择校正。逐队列 AUC 是描述结果，不批量制造显著性检验。

## 实施范围与顺序

1. 建立新目标、数据与统计合同，沿同一 `_targets.R` 添加有语义名称的论文目标分支；正式 store 和监测继续指向原 cache root。
2. 实现论文复现、参数搜索、K4 细分、冻结登记、外部比较、区间与报告，产物写入原外置缓存内的独立子目录，保留旧输出。
3. 用同一 DAG 的合成数据完成实际运行、失败恢复和路径隔离测试；按结构、R 实现、科学统计顺序独立审查并修正。
4. 运行正式 targets，核对全量覆盖和结果，生成报告与策略建议，最后润色并核对数字和贡献账本。

## 如何确认完成

- 论文训练名单、CCS、结局和 K4 重点 AUC 核对通过，输入哈希不变；基线及全部候选在相同记录上评估。
- 新分析只含 K2–15，完整列出每种排序、评分和目标；K≥5 的四项达标判定可由逐队列表重新计算。
- 历史条件性达标、训练侧达标和外部筛选分别报告；不将条件性或探索性达标写成独立泛化证明。
- 合成同 DAG、恢复、输入只读、隔离路径和生成报告均有实际证据；正式运行用 `tar_make()`，`tar_watch()` 指向同一正式 store。
- 正式代码及报告源留在项目，模型、store、表格、HTML/PDF 和测试现场留在 `D:/cache/ccs/normCCS-optimization/`；版本不变。

## 风险与待确认事项

负责人已经确认中位数口径。全部九个外部队列的主汇总保留论文范围，另外展示来源去重及无训练来源重叠的敏感性汇总，不能事后用更有利子集替换主终点。高 K 近似搜索找不到不证明不存在更优映射；即使观察到达标，也不保证新队列表现改善。

## 执行结果

2026-11-01 已完成真实全量运行。972 个候选配置中，205 个论文条件性配置满足四项点估计判据；最小达标 K 为 5，最大共同增益来自保留 K4 分界的 K15 细分方案。560 个训练侧排序配置没有达标，主要结果及区间见 `test/normCCS-optimization/verification.md` 和外置正式 HTML。算法、输入、软件版本和历史输出的边界按本计划保留；点估计达标不作独立泛化提升的确认。

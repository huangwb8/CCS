# normCCS 论文复现与高 K 搜索重构

## 研究问题与完成条件

在原始数据、固定 metaCCS 和论文 normCCS 训练名单不变的条件下，寻找同一个 K≥5 映射，使训练与全部外部队列的 OptimizeRank AUC、固定方向 AUC 四项中位数均超过论文 K4。K 仅取 2–15；中位数按队列等权计算，排除 pooled All，四项增益均超过 `1e-12` 才达标。有效训练集为 20 个队列、1177 条记录，全部数据为 29 个队列、1435 条记录。

论文映射与归档排序先通过全队列 AUC 复现门禁，再启动资源试跑和搜索。所有候选共享记录范围与未见状态默认规则；原覆盖口径另行复现。metaCCS、公共包 API 与软件版本不变。

## 科学设计

比较四种训练排序、完整历史排序及训练可见历史排序，以 OptimizeRank 或固定方向 AUC 搜索 median（含 All）、cohort_median、mean、lower_tail、mean_lower_tail。K2–4 完整枚举，K5–15 使用多起点 DP 加局部改进。另保留论文 K4 三个分界，只在四段内部细分，以训练两类中位数增益的较小值保留候选束，每级满足最小训练支持。

映射和训练推荐先冻结，再计算候选外部 AUC。涉及历史外部来源的方案标记为 `paper_conditional`，训练侧重新排序的方案标记为 `training_only`。外部成绩参与筛选后，结论属于探索性比较。来源组配对 bootstrap 95% 区间保留组内全部队列，以拟合预测为条件，不含重新拟合、患者层抽样或多候选选择校正；区间跨零时不能确认稳定优势。

## 替换范围与执行顺序

上一轮保留旧图的实现没有完成替换。本轮删除旧嵌套验证 DAG、仅供旧图使用的模块、S3 概率评分、重复配置、旧报告和旧测试，只保留当前目标流程。正式入口仍是原 `_targets.R`，crew、renv、正式 store 和监测继续使用 `D:/cache/ccs/normCCS-optimization/`。

1. 保存当前映射、逐队列 S1/S2、四项中位数、判定、区间和论文复现结果，作为清理前参照。
2. 按依赖审计删除退役代码，收敛配置、入口与报告，完成同 DAG 合成测试和三轮串行审查。
3. 确认正式流程没有写入者，将旧 `fits/`、`derived/`、`trial/` 和旧顶层 `exports/` 文件复制至 `archive/pre-paper-goal/`；逐文件核对数量、大小、SHA-256 后移出活动目录。唯一副本不得删除，不覆盖不同内容。
4. 用 `tar_prune()` 清理退役目标，沿原 store 执行正式 `tar_make()`，核对全部当前映射与 AUC 不变。`tar_watch()` 仍监测同一正式 store。
5. 润色报告并核对数字、公式、代码和证据范围，经正式 targets 更新 HTML；验证实际表格显示、结果完整性与 BAC 哈希链。

## 验收

活动源码、配置和 manifest 只描述一套流程，不存在旧嵌套验证节点或兼容 runner。活动科学结果目录只保留当前产物，退役结果有独立清单可审计。轻量测试必须实际覆盖报告生成、失败恢复、重复执行跳过有效节点、输入只读和正式 store 隔离；正式运行与轻量测试分别记载。

逐候选映射、逐队列 S1/S2、四项中位数及达标判定应与清理前一致，论文 58 项 AUC 继续复现。未达标训练侧方案保留完整结果及可检验策略，历史条件性点估计改善不能写成独立泛化优势。最终执行证据见 `test/normCCS-optimization/verification.md`。

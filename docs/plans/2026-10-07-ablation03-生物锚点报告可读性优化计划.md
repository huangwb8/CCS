# ablation-03 生物锚点报告可读性优化计划

本计划供负责人审阅，当前仅形成改写方案。计划依据为现有生物报告正文、广队列与高覆盖主效应导出表、近期方案修订记录及正式 targets 报告依赖。

## 通俗解释：究竟发生了什么

报告希望回答一个直观问题：为同一位患者换一种寻找相似患者的方法后，找到的人在增殖、免疫等表达状态上，是否仍与他接近？当前读者往往要先穿过数据清单、函数名称、评分公式和统计限制，才看清这个问题及主要发现。

例如，一名读者看到免疫相关结果为负，最想知道的是“负值说明什么，为什么会这样”。现在他需要来回查找指标定义、候选患者范围和后面的讨论。改写后，结果附近就会说明：负值表示 d1 找到的邻居在当前免疫表达分数上较不接近患者；接下来分别检查基因测量、癌种组成及表达分数能否从表示中预测出来。完整计算规则仍可向下查阅。

这次优化的目标是让读者跟得上推理：先理解发现，再判断解释，最后按需核查细节。

## 专业判断：问题在哪里

现有报告已经包含清楚的科学问题、教学示例和充分的限制说明，问题集中在它们的排列和衔接。

- **主线出现偏晚。** 报告以数据概览和源代码表开头，核心问题及主要发现分散在结果和讨论中。
- **分析分支替代了科学问题。** 高覆盖验证、严格诊断和低覆盖探索各有合理职责，但读者不容易看出它们怎样共同检验候选解释。
- **术语混用增加理解成本。** “合同”“资格”“冻结”“两臂”等工程用语频繁进入正文；邻居表达接近度与预测表达分数的模型都使用 readout，容易混淆任务。
- **数值方向和分母需要来回查找。** 接近度差为正表示 d1 更好，MAE 差为正却表示 d1 更差；队列清单人数、测量满足条件人数和实际配对人数又不相同。
- **限制重复打断推理。** 关于等价性、固定模型和临床验证的说明多次出现，有时占据了本应用来解释结果的篇幅。

上述判断来自报告正文。哪些图最难读、折叠细节是否方便使用，仍需在实施时检查实际 HTML；不能仅凭 Rmd 推断最终阅读体验。

## 要达到什么目标

读者只读开篇和主要结果，就能说清楚分析的问题、当前发现与尚未确定的原因；继续读正文，可以理解每项对照为什么做、它提供了什么证据，以及为何有些比较无法完成。熟悉方法的读者仍能定位公式、检验口径、完整状态和源代码。

本次范围为报告的结构、文字、表格显示说明和阅读导航。沿用当前五项 gene signature 及全部科学计算、模型、样本集合、阈值和检验族，不增加实验，不重新选择有利结果，不调整包版本。正文统一使用既有的 gene signature 称谓；代码键和历史文件名保留。

## 改进方向

### 用问题和主要发现建立开篇

在报告开头增加约三至五段的阅读导引：解释 Direct 与 d1 是本次比较的两种患者表示，reference 是用于评分定标和提供邻居的样本库，query 是接受评估的外部患者；随后用少量动态结果概括广队列发现、高覆盖证据和仍未解决的解释。

开篇同时交代 gene signature 是几组基因表达汇总成的参照分数。邻居接近度评价这些分数的局部匹配，预测模型评价这些分数在指定训练规则下能否从表示中恢复，两者须分别判断。

结果概括直接读取正式产物，避免将本计划中的当前观察写死进报告。原广队列五项差值均为负，可以作为主要发现；高覆盖结果则应逐项说明有效性、区间和校正证据，不能概括成“差异消失”。例如，当前基质项区间低于零，但五项 BH 校正 q 约为 0.056；增殖项因秩背景不足而不可估计。这些差别应在摘要中保留。

读者由此先知道报告的判断，再决定深入哪一层证据。

### 按科学问题调整章节

采用下列主目录。标题表述可在改写时润色，但保留问题之间的递进关系。

| 建议章节 | 回答的问题 | 现有内容的去向 |
|---|---|---|
| 本报告问什么，主要发现是什么 | 为什么做这项比较，现有证据怎样 | 前置科学问题及讨论中的主要发现 |
| 我们怎样比较同一位患者的邻居 | 分数、邻居和配对差值各是什么 | 精简的数据角色、实验控制和指标定义 |
| d1 找到的邻居，表达状态是否更接近 | 广队列的效应方向及队列差异 | 原主效应、覆盖概况、异质性与队列内区间 |
| 统一基因测量并限制癌种后，结果怎样 | 测量条件更一致时得到什么证据 | 高覆盖选择、主比较和覆盖档位对照 |
| 哪些因素可能改变邻居匹配 | 评分、候选池与距离规则是否影响差值 | 共同患者对照、模块距离、邻居重叠及严格诊断 |
| 表达分数还能从表示中预测出来吗 | 局部匹配与目标可恢复性是否一致 | 高覆盖及严格诊断的连续预测模型结果 |
| 测量不足时，探索结果提供什么线索 | 残余基因能提示什么，完整签名还缺什么 | 独立呈现低覆盖探索和不可估计原因 |
| 这些结果支持什么解释，下一步怎样验证 | 证据怎样组合，哪些假设仍待检验 | 收敛后的讨论与独立验证建议 |
| 方法与审计补充 | 怎样复核计算、样本和完整状态 | 详细公式、统计规则、完整清单、修订历史及代码地图 |

高覆盖仍紧接原广队列结果，保持既有递进关系；完整表和对应图随章节移动。预测模型结果集中后，逐项标明来源分支及有效人群，不把高覆盖与严格诊断拼成一个总体估计。

章节移动遵循 Rmd 的对象依赖：展示前完成对象准备，不为方便排版复制计算或加载另一套结果。正文引用和目录同步更新。

### 统一术语，并让每张图就近可读

正文采用下列用词；专业英文在首次出现时解释，后续保持一致。表格的原始字段与代码标识仍可用于追溯。

| 现有用语 | 正文建议 | 必须保留的含义 |
|---|---|---|
| gene signature utility | gene signature 分数的邻居接近度 | 0–1 的指数接近度，不是正确率或临床获益 |
| 测量合同、冻结合同 | 预先固定的队列、共同基因和测量要求 | 不按效果选择基因或队列 |
| 资格、门禁 | 纳入条件、最低测量或推断要求 | 区分测量满足条件与实际效应可估计 |
| 两臂 | Direct 与 d1 两种表示 | 同一患者内的配对比较 |
| 连续读取器、readout | 预测 gene signature 分数的模型 | 仅用 reference 训练和调参，外部 query 用于评估 |
| 秩评分 | 根据同一样本内基因表达排序计算的分数 | 排序依赖固定背景基因集，不宣称自动消除技术偏差 |
| 差中差 | 切换规则后，d1 相对 Direct 的差值改变了多少 | 先在共同患者上比较，改善不保证切换后 d1 优于 Direct |

每张主要图在正文中配套三个相连的内容：图前说明问题，图旁说明坐标与差值方向，图后先讲观察，再解释与该观察直接相关的限制。必要时使用一个明确标记为教学示例的数字帮助理解。

接近度图注明“d1−Direct，正值表示 d1 更接近”；误差图注明“d1−Direct，正值表示 d1 预测误差更高”。同时显示实际有效队列／患者数，说明空白或省略项的原因。保持发表用图的坐标、图例和必要数值标注，解释写入 HTML 正文或图注，不增加图内脚注。

表格显示层可使用清楚的中文列名和紧邻的字段说明，原 CSV 字段、数值及导出接口沿用现有规则。

### 把证据、解释与缺口分开讲清楚

关键段落先陈述观察到的差值、区间和检验结果，再讨论解释。预测模型的结果按 ridge 与 XGBoost 分别呈现，模型间不一致的证据明确保留；某个模型误差增大，只说明当前模型与训练条件下预测较差，不能直接证明目标信息不可逆地丢失。

用一张简短的解释表串起证据：

| 证据组合 | 可以推进的判断 | 仍需保留的缺口 |
|---|---|---|
| 邻居接近度下降 | 当前邻居名单对这些分数的局部匹配较差 | 尚未区分技术来源、癌种组成、距离与信息压缩 |
| 在共同患者中切换评分或候选池后差值改变 | 结论对该规则敏感 | 不能把不同对照变化相加为机制贡献比例 |
| 邻居匹配较差，但预设预测模型仍表现良好 | 与信息存在而局部距离利用不足的解释相容 | 需检查模型证据与区间，不能由未显著变差推断无损 |
| 邻居匹配和预测均较差 | 增加目标表达信息较难利用的证据 | 仍受测量、模型能力和训练条件限制 |
| 比较不可估计 | 当前测量或人群支持不足以完成比较 | 不能据此认定没有效应 |

不可估计项在结果附近给出具体原因。例如增殖项应说明共同秩背景为 4,848 个基因，低于 5,000 门槛；该数字在实施时从正式产物动态获取。完整五项仍进入既定 BH 检验族，图中省略项在摘要或状态表中可见。

原基线、高覆盖与低覆盖探索分别保留人群、评分和证据性质。跨分支比较用于理解证据，不用不同人群的总体差值缩小来认定某项因素解释了原负差。

### 为正文和方法细节安排不同阅读深度

正文保留决定判断的内容：评分直觉、配对和队列等权、主要统计证据、实际有效人数及直接相关限制。重复的通用限制合并到讨论或方法补充，并在需要的位置简短引用。

详细标准化与接近度公式、重采样及 sign-flip 算法、完整 BH 族、检索精度门槛、全部队列清单、修订历史和代码路径放入同一 HTML 的方法与审计补充。相关规则首次涉及主结论时仍简述；例如基质项必须就近区分区间方向与 BH 校正结论，不能让读者自行去附录寻找。

继续使用现有目录、代码折叠和表格交互。确有必要时复用已有折叠能力，不引入新前端框架或改变共用模板。细节可定位、可展开，不删除完整状态或不利结果。

## 如何确认完成

### 阅读与科学表达

- 只读开篇，能回答比较对象、主要发现、哪些解释仍未确证；能区别邻居接近度与预测模型任务。
- 只看任一主要图及邻近正文，能理解单位、差值方向、有效人数、观察与限制，不必反复返回指标总表。
- 能明确区分广队列、高覆盖、严格诊断和低覆盖探索；每个不可估计项都有具体原因和完整状态入口。
- 基质项的区间与 BH 结论、增殖项的测量不足、不同预测模型的结果差异均保留；正反结果使用同等解释深度。
- 正文结论、讨论和摘要一致；没有把区间跨零写成等价，把评分标准化写成去批次成功，或把表达代理写成独立临床验证。

### 内容完整性与运行验证

- 用实施前后的图表对应清单核对所有既有比较、图、完整表和不可估计状态均有去向；新的正文数值来自正式产物，不手工复制固定结果。
- 记录上游关键科学产物的哈希、target 状态及主效应字段，更新后核对效应、区间、p/q、检验族和有效人数一致。报告导出的文件可能因渲染被重写，检查其数据内容，而非仅凭时间戳判断科学变化。
- 使用 `C:/R/R-4.3.1`、项目 renv 和既有 `_targets.R`，经实际正式 store `D:/cache/ccs/_ablation-03/targets` 的 `biology_report` target 生成报告；通过 `tar_make()` 增量执行，监测沿用同一 store 的 `tar_watch()`。不在 DAG 外独立调用 render 生成正式 HTML。
- 更新前检查过期节点与依赖；预期复用有效科学上游。若出现非预期科学节点失效，先查明原因，不绕过 targets 或强制标记缓存有效。
- 检查 Rmd 展示顺序、HTML 目录和内部链接、图表顺序、公式、表格搜索及折叠代码。只有改动触及报告 wiring 或渲染重试逻辑时，才运行相应既有回归检查；纯文字整理不新增镜像测试，也不扩大到全包重算。
- README、相关说明与实际目录一致；包版本沿用现值；交付前经 `bac verify --json` 核验哈希链，并如实保留既有告警说明。

## 风险与待确认事项

简化措辞的主要风险是抹平不同估计对象，而非计算错误。因此，“局部匹配”“指定模型下的可预测性”“独立临床效用”始终分开表达；原队列、共同测量队列和实际评分人群也分别说明。

重排预测模型内容可能跨越现有代码块依赖，实施时需整体检查对象初始化与展示顺序。把细节后移也可能让统计限制难以找到，验收应检查主结论旁是否仍保留必要限定及明确的细节入口。

建议阅读定位为：熟悉肿瘤生物学或数据分析、但尚不了解 CCS 内部流程的研究者。报告提供必要直觉和解释，避免重复讲解基础统计。当前请求仅要求审阅计划，报告改写与正式渲染尚未执行。

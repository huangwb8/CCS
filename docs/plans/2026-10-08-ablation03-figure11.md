# Figure 11 可读性改进计划

## 问题与目标

原图把每个队列对在 Direct 和 d1 中的结果用线连接，数百条线相互遮挡。读者很难判断哪些比较改善、变化有多大。改为每个队列对一个散点，参考线上方表示 d1 的一致性更高；旁边的差值分布展示改善与下降的幅度。

## 改进范围

Figure 11 使用等比例配对散点图和以零为界的差值直方图。标注有效队列对数、d1 不低于 Direct 的比例、平均配对差及已有的队列节点 bootstrap 区间。散点颜色随差值变化，最大增幅和降幅用少量数值标注突出。轴范围覆盖全部观测值，图注解释参考线、颜色和统计单位。

本次沿用已有科学结果和推断方法，只修改报告呈现。PDF 和 HTML 由正式 `structural_report` target 更新，报告依赖仍由 `structural_report_sources` 跟踪。

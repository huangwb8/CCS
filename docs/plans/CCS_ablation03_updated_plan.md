## 通俗解释：究竟发生了什么

**一句话说明：** 现有 CCS 已证明多个队列模型的联合输出能产生有用的患者画像；但我们还需要判断，这幅画像好，是因为**汇集了不同队列各自学到的经验**，还是因为**采用了较复杂的特征变换或后续监督学习**。

设想新患者接受“多医院专家会诊”：

- **真实 CCS**：让每家医院的专家依照各自医院患者积累的经验评分，合并评分。
- **打乱患者评分**：保持专家评分的总体分布，却把分数分配给错误患者，检查患者级对应是否必要。
- **重复已有专家**：把已有专家的判断复制若干遍，检查增加人数是否等同于增加不同经验。
- **打乱专家的训练来源**：保留患者总数与专家名额，但把不同医院的历史患者重新混合、分配给专家学习，检查保留原始医院边界是否重要。
- **单一大型专家或普通特征提炼器**：在同样的历史患者上训练共享模型或非线性编码器，检查是否无需“各医院分别学习”也能得到类似结果。

**类比与 CCS 对应：** 医院＝cohort；专家＝cohort-specific GSClassifier model；评分＝冻结状态概率输出；综合画像＝d1；“更好”必须用未参与训练的患者、预先指定的生物状态评价以及独立 ICI 应答任务来判断。类比不能替代严谨的训练数据与推断设计。

**改进前：** ablation-03 已有 Direct/d1、随机投影、模块库扩展、matched-bank 和生物锚点分析，但缺少“在相同数据上按不同来源边界训练”的正式比较。  
**改进后：** 同一份新增 Rmd/HTML 清楚分开回答四个问题：联合响应是否非随机？不同真实模块是否提供增量？邻域变化是否具有生物学选择性？**真实独立队列训练是否比打乱队列边界、混合训练和普通非线性变换更有优势？**

## 专业判断：需要弥补的证据缺口

### 已经具备的证据

已核对 `R/ccs_model.R`、`R/ccs.R`、`R/ablation.R`、`test/ablation-03/_targets.R`、`README.md`、`analysis-plan.yaml` 以及 `02.03.00` 结构复现相关脚本：

- CCS 的 `ccsSubModel_GSClassifier()` 调用 `GSClassifier::fitEnsembleModel()`，训练输入为每个局部训练组自己的 `expr` **和** `subtype`，随后将多个模型对同一患者的概率输出拼接为 d1。
- 当前 ablation-03 已有 Direct-GSClassifier vs Cohort-d1 的几何、来源近邻、下游 readout、连续生物锚点、decoder、bank scaling、matched-bank 和跨队列结构分析。
- `R/ablation.R` 存在 `.ablation_permute_blocks()`，但现有正式 Null-Perm 分支主要完成资格判断，**不等同于已完成模块置乱后的正式任务性能比较**。
- 目前 `02.03.00` matched-bank 在**冻结模型池内抽取模块子集**，没有重新训练在混合数据上学习的模型。既有报告对小模块池和不独立的重复抽样已有提醒。
- 正式源数据、冻结模型和患者级 RDS 主要在外部只读位置与缓存，不应以 GitHub 上已有的图表代替新增计算所需的数据。

### 当前尚不能直接作出的推断

1. **d1 与 Direct 不同**，不等于**独立 cohort 边界提供了独特增益**。
2. **真实新增 cohort module 优于复制旧 module**，也不等于**按 cohort 分别训练优于使用相同患者混合训练**。
3. **置乱后结果变差**，主要说明真实患者与模型响应的对应关系必要，不能证明与普通 MLP、autoencoder 或其它非线性方法相比更好。
4. **原始 normCCS 预测 ICI 的 AUC 较高**，不能直接归因于 d1：部分增益可能来自后续 metaCCS 聚类、状态选择和使用 ICI 结局的监督映射。

**本计划真正的补充，是把“训练来源边界”作为受控变量，同时把下游 ICI 映射单独纳入公平比较。**

## 共同科学设计：先冻结输入和评价边界

新增 D 必须和 A/B/C 共享一份不可被结果反向更改的科学合同，否则四项实验无法形成证据链。

### 数据角色与泄漏防护

必须建立至少四层清晰的来源清单，不把“出现于某个完整 d1 矩阵”误认为“从未用于训练”：

1. **`model_train`**：真实独立模型、伪队列模型、共享模型和编码器共同允许使用的患者表达数据。确定 cohort 清单、样本 ID、检测平台、cancer type、输入基因与 `subtype` 生成来源。
2. **`representation_calibration`**：用于训练表示的中心化、方差/模块权重、必要的容量对齐投影或无监督变换参数。不得使用 external query。允许与 `model_train` 有经审计的重合，但不得把该组结果称为外部验证。
3. **`development`**：只有在比较 ICI 时允许使用的推导人群：原论文 20 个 ICI derivation cohorts（n=1,177），用于训练/选择**各臂自己的**临床读出或状态映射；其治疗结局绝不允许参与前两层特征学习或无监督模型调参。若这些患者曾作为无监督模型训练样本，必须额外提供完全 cohort-disjoint 的严格敏感性分析，并在报告中标示转导式/非严格外部的界限。
4. **`external_test`**：不参与模型训练、预处理拟合、超参选择或结局映射选择的生物学/技术评价 cohorts；临床扩展使用 Kim2018、Zachary2024、Binghua2024 及 QL1706（前提是数据访问和角色核验通过）。QL1706 不能参加模型选择和任何数据驱动的设计修改。

对于已有 ablation-03 的 reference/external 和 `full_d1`，逐样本核查冻结 bank 训练来源、现有对象中 `in_sample`/`external_frozen` 标记、重复 ID、按数据集的具体样本重叠，以及原论文 derivation/validation 集。**若不能证明临床验证集与全部训练操作独立，停止“独立验证”标签，生成阻断审计，而不是静默继续。**

### 训练和比较公平性的可操作合同

- **相同患者和基因信息：** A/B/C/D 使用同一 `model_train` 样本总集及可比较输入特征。真实 cohort 划分是被研究的变量，不允许在某一臂额外使用患者或额外临床结局。
- **相同预处理信息：** 32 基因 panel、TSP/Direct 特征生成、缺失处理与基因匹配尽可能复用相同实现；需要学习的处理参数只从允许的训练集拟合。不同训练组内部必要的分布处理须记录，做全局共同预处理敏感性分析。
- **按 cohort 留出，而不是随机拆患者：** 设计抽样和调参按真实来源 cohort 分组。伪 cohort 创建时必须严格跟踪患者的原始 cohort，不能因改了伪标签就解除泄漏约束。
- **相同评价人群和分层：** 每一项成对效应使用完全相同的 query、reference 候选池、癌种/组织支持规则、五个锚点、搜索算法及统计单位。每臂需要的缺失数据使用交集资格，报告被排除的样本与偏差风险。
- **模型复杂度不能只看“模块数”：** 对比 GSClassifier bank 时，同时报告 module 数、各模块状态数、总概率列数、树/基学习器数量、训练样本数、训练耗时；对共享模型和编码器还要报告参数量、训练计算量及预测开销。不同模型家族无法严格逐参数匹配，须采用**等输出预算主分析 + 复杂度/计算预算敏感性分析**，而不是虚称完全公平。
- **模型选型冻结：** 对照臂的超参网格、种子、早停、容量范围在评价 external_test 之前冻结。只可使用 `model_train` 内按 cohort 分组的验证与预先固定的资源预算进行选择，禁止利用 external 生物锚点或 ICI AUC 反复挑模型。
- **两种特征读出路径：** 主分析采用统一、reference-fitted 的固定维度表征和共同下游读出，避免 d1 因特征维数、权重或距离尺度自然占优；原生 CCS block-balanced 距离作为机制敏感性分析，不能混为同一终点。标准化和降维不可在 external_test 上拟合。

### 先审计可行性，再冻结正式规模

审计所有允许 cohort 在 tissue/cancer_type/平台上的覆盖、每个模型局部类别数、原始训练样本量和临床验证的基因可测性。正式 D **优先覆盖具备有效来源重排条件的全部组织**；若部分组织只有一个 cohort 或数据量不足，应在看结果前依据可复现的资格规则筛除，并在 HTML 中写出目标人群已经变窄。禁止看过 AUC 后只保留有利组织。

目标是进行至少若干独立训练种子和若干伪分组设计的重复，而不是一次偶然结果。正式配置建议 `5` 个训练种子 × `3` 套伪 cohort 划分（具体规模要在资源审计后冻结）；训练难度过高可先运行**同算法、缩小数据子集的预检**，但不得用预检结果宣称 D 已完成。若资源不足，必须将 D 标记为 `blocked_by_compute` 并如实说明，而不能悄悄变成“可选实验”。

## 实验 A：患者与模块响应的置乱负对照

**作用：** 先证明真实联合响应确实携带患者层面的结构；这是质量控制，不是 H4 的替代。

- `real_d1`：既有冻结 d1。
- `independent_module_permutation`：在**每个真实 cohort 内**对每个 module 的完整概率块独立置乱患者行；reference 与 external 分别置乱，保留每块的联合概率和各 cohort 内边际分布，破坏患者—模块身份及跨模块对应。
- `joint_patient_permutation`：每个 cohort 对所有模块使用同一个置乱索引，保留被置换的联合向量本身、破坏它与原患者生物标签的配对；借此区分联合结构与患者身份错配。
- `Direct`/既有随机投影：仅作合理可比的参照，不把历史随机投影分数与新的条件不同的终点直接相减。

**预设主要终点：** 外部 query 中，在同癌种、跨 cohort 候选池上，真实 d1 与独立模块置乱的五锚点局部生物效用配对差，正向为真实 d1 更好。建议冻结 100 个有效置乱设计，记录各 cohort 的唯一有效排列数；小队列不能生成有效置乱时返回不可估计状态。

**边界：** 真实优于置乱并不证明独立 cohort 边界的特殊价值；“模块打乱”也可能破坏所有学习型表征均有的有意义结构。

## 实验 B：不同真实 cohort models 的增量贡献

**作用：** 检查 bank 的价值是否超过重复同一组概率输出；与已有 matched-bank/scaling 互补，不重复结论。

按组织配额构建 `base_bank`，再配对比较：

- `novel_expansion`：加入 base 未见的真实 cohort models。
- `duplicate_expansion`：增加相同 slot 数，但仅复制 base 模块，不增加新模型学到的函数。
- `random_existing_expansion`：等预算抽取合格真实模块作为组成敏感性参照；它可能与 novel 重合，必须说明其角色是随机组成基线而非新的训练策略。

**主要终点：** 在同一外部 query、同一五锚点资格下比较 `(novel − base) − (duplicate − base)`，即真实新增相对于复制的**增量差**。报告模块冗余、有效秩、近邻稳定性及模型成员名单，但**不以冗余指标的机械变化冒充生物学收益**。

**重要统计和数学约束：** 用按模块聚合且经过相同 reference 拟合的距离，控制不同 module 的概率列宽；重复模型产生的权重效果须与预定义权重方案匹配并显式说明。需要设置**相同长度的真实新增模型组**作为主要比较，复制在某些归一化下等价于重新加权而不是新增独立维度，这也是本实验要隔离的事实。记录全部唯一 bank 组合；候选池有限时穷举，不把重复种子当独立样本；模块抽样与 query cohort 变异分别汇报。

**边界：** B 支持“冻结模型池中不同函数的条件增量”，但不能单独证明“按队列训练边界”最优，后者交给 D。

## 实验 C：选择性生物学邻域重构

**作用：** 检验 d1 的局部重组是否倾向于组织生物状态相似的患者，而不只是产生新的邻居名单。

- 外部 cohort 的 query，从不包含 query 同 cohort 的参考池中找候选；主设计限制同一 `cancer_type`，按既有 gene coverage 合同确定每个锚点可测人群。
- 用**仅依赖 Direct 和来源元数据**的规则，提前定义距离接近的候选配对；不能根据生物锚点评分选有利候选再回头调阈值。
- 每对候选中的“生物学更近者”依据已有五个高覆盖、reference-only 定义的锚点判别，要求差异超过预先冻结的可分辨阈值；并列及不可测保持不可估计。
- 计算 d1 在 Direct 起始距离相近的候选中，将锚点更接近者排在前面的概率；采用明确的 ties 规则，另外报告相同条件下 Direct 的实际排序表现（不要把 Direct 强行设成 0.5）。
- 同一 query 的多个候选对先聚合，最后以外部 query cohort 为独立推断单位；分癌种、平台和来源进行敏感性分析。可以在对照中增加 A 的置乱 d1，以检查选择性是否依赖真实模型响应。

**边界：** 表达来源锚点与 CCS 输入有一定同源性，属于内部/外部 cohort 的生物性质证据，而不是独立病理或蛋白确认。必须并列展示既有某些锚点下 d1 劣于 Direct 的结果。

## 实验 D：真实队列训练 vs 混合训练 vs 普通非线性变换（本轮核心新增）

### 为什么 D 不应只使用现成 d1 做比较

CCS 的原始局部模型使用 `data.i.j$expr` 和 `data.i.j$subtype` 调用 `GSClassifier::fitEnsembleModel()`。因此，**改变训练来源边界时，局部状态标签也可能改变**。只把现成的 d1 列交换、随机重排或用已有模型预测新数据，不能替代完整训练策略对照。

D 必须在受控的**同一批原始训练样本**上建立各自模型，完整生成外部患者概率输出；对照方法的局部状态标签按同一、参考专属的上游算法重新产生，不能借用真实 cohort 的状态标签作为伪队列或 pooled 的“真值”。

### 训练臂：明确要控制的因素

| 实验臂 | 训练数据怎样使用 | 模型/输出 | 主要检验目的 |
| --- | --- | --- | --- |
| `D0_direct` | 相同原生输入，不训练 cohort bank | Direct-GSClassifier / 必要时固定投影 | 原始输入基线 |
| `D1_real_cohort` | **保留真实 cohort 边界**，每 cohort 各自产生状态标签并训练模型 | 原 CCS 局部 GSClassifier → bank → d1 | 目标方法；须重新训练一份可复现的 matched D1，同时保留历史 frozen D1 作一致性参照 |
| **`D2_pseudo_cohort`** | 在允许的组织/来源分层内，混合原始 cohort 的患者再重分成**数量与规模可比的伪 cohort** | 同一状态生成与 GSClassifier 训练链，构建同数量的模型库 | **最关键对照：改变“训练边界是否对应真实独立队列”，尽量不改变模型族和模型数** |
| **`D3_pooled_ensemble`** | 同一组织内合并允许的患者，学习共享状态；以固定种子/自助抽样生成共享模型的多个成员，模型预算与 D1/D2 对齐 | pooled GSClassifier-based model bank 或匹配的共享多状态模型 | 区分“保留 cohort 作为学习单位”与“统一数据学习后再做集成” |
| **`D4_autoencoder`** | 相同无标签原生输入，不使用 cohort 边界或 ICI 结局 | 参考数据训练的 MLP autoencoder（另含线性 PCA 或随机投影的简单参照） | 排除“任何足够灵活的非线性特征变换都有同样性质”的竞争解释 |

**D1 和 D2 是最重要的、模型族尽可能匹配的主比较；D3 和 D4 是必要的不同范式比较，不因天然架构不同而伪称严格因果对照。** 评价中同时记录每臂的训练信息、模型规模、维度及计算成本；D1/D2 更适合研究来源边界归因，D3/D4 更适合检验替代策略是否也能达到类似实用价值。

### 伪队列（D2）的构建原则

1. 预先确定合格组织及真实 cohort 容量：保留每组织 cohort 个数与各组样本量分布；尽可能在 `cancer_type` 和 assay/platform 的可行分层中重排原始患者来源，**避免仅由于癌种或技术组成被重写而产生虚假的优劣**。
2. 每一伪 cohort 应尽量包含来自多个真实 cohort 的患者，且需要**记录原始 cohort 的混合程度**；仅改名、不发生来源混合的组为失败设计，不得记作有效伪队列。
3. 当平台/癌种分层使来源根本无法混合时，不可为满足指标而放松泄漏或强行制造混合；把该分层标记为不可识别，并考虑仅在多 cohort 共有平台/癌种的严格子集做 D1-D2 比较。
4. 对每一有效伪 cohort 重新执行原 CCS 上游 `subtype` 生成及 `GSClassifier::fitEnsembleModel()`；原始 cohort 来源 ID 保留在审计中，不能用新的 pseudo ID 冒充统计上独立的队列。
5. 同一次伪分组设计下每个模型严格使用训练集合，不得包含 evaluation query；允许的 label-generation 算法及其参数必须记录。生成失败、类别不稳定、组内样本不足应保留 `not_estimable`，不事后挑选“训练成功且效果好”的分组。

**一个值得单列的科学限制：** D1-D2 不仅改变训练 cohort 边界，还会改变局部训练标签的定义及组内技术分布；这正是“队列作为学习单位”整套设计的差异，但仍不等于只改变了一个数学参数。为更清楚归因，建议设 `D2a`（尽量匹配癌种/平台组成）为主分析、`D2b`（同组织自由混合）为敏感性分析，并同时审计组内标签数、标签分布和模型区分能力。

### Pooled 模型（D3）的公平定义

- 在同一组织或预设分组内，对**完全相同的 model_train 患者**进行统一状态发现；模型不接收真实队列身份作为下游标签。
- 如果用多个 pooled 模型形成 ensemble，应事先冻结每个成员的训练抽样策略和输出状态预算；不能为了凑齐 D1 的模块数而在同一模型上重复复制并称为独立证据。
- 尽可能匹配 D1/D2 的**总模型输出维度、状态预算及可训练学习器数量**，并记录无法完全匹配的部分。采用共同的参考校准和固定输出维度评估，另给原生模块距离的敏感性结果。
- 该臂有可能使用不同的标签组织方式，因此 D1-D3 比较属于**完整训练策略的效用比较**，不应解读为“纯训练边界单因素因果试验”。

### MLP/autoencoder（D4）的正确训练约束

- 这是“学习型非线性特征变换”，**不是**用 ICI response 标签监督训练的预测网络；否则比较的已不是表征，而是不同监督信息量。
- 在同一 Direct 输入上，仅以重构/掩码重构等预先固定的**无监督目标**拟合 MLP autoencoder；编码层输出作为 patient embedding。
- 超参及训练停止在 model_train 内按真实 cohort 分组验证，不允许查看 external query 生物锚点或 ICI outcomes 后优化。
- 主分析将所有臂校准到相同预设的 embedding 宽度，并做维度敏感性曲线。参数量和训练 FLOPs 跨树模型/神经网络不严格同构，须报告**训练资源—效果曲线**和若干预设计算预算，而不是宣称参数量恰好相同就绝对公平。
- PCA、Null-RP 是解释性下界或简单替代方案，至少在主报告保留一个；若 D4 无法优于该简单参照，也如实展示。

### D 的两层评价：表征贡献与临床映射必须拆开

**层 1：不使用 ICI 结局的表征评价（D 的主证据层）**

使用外部 cohort 及与 A/B/C 一致的评价合同，在以下方面成对比较 D1、D2、D3、D4：

- 五项高覆盖 RNA 生物锚点的跨队列局部匹配效用（预设一个主评分/共同候选池，并完整报告队列资格与人数）；
- C 的受控选择性邻域排序及外部状态距离结构一致性；
- 技术标签近邻比例与癌种读出（**仅作为同时报告的混杂/信息权衡指标**，不把技术聚集下降直接定义为优胜）；
- 不同训练种子/伪队列边界的重现性、模型容量、训练时长、预测时长和模块冗余。

所有臂共享**一批完全相同的外部 query 和可测锚点**。不同表征采用同一套下游距离合同；需要固定维度时，仅在 reference 数据拟合映射，输出宽度的主设置在 external 评估前锁定。报告同一终点的**配对 cohort 效应**、95% CI 和每个训练设计的稳定性分布。

**层 2：有 ICI 标签的下游临床评价（D 的必要第二证据层）**

这里要避免一个严重的不公平对照：**不能把原 CCS 的 metaCCS 状态编号、normCCS 固定映射或在真实 d1 上拟合的临床模型，直接套到 D2/D3/D4 上。** 不同表示没有共同坐标语义。

建议同时开展两个不同问题的实验：

1. **共同下游监督读出（主临床比较）**：各臂使用**同样的 ICI derivation cohorts、相同 response 定义、相同分组交叉验证、相同的简单受限读出器**（例如事先冻结惩罚式 logistic 或 ridge logistic；所需正则化仅在 derivation 内选），分别拟合后锁定，测试三个公开外部队列及 QL1706。比较同一受试者的 AUC、校准、响应富集和临床净获益时，必须注明样本量及事件数、给成对不确定性，不得以小样本 ROC 排名断言普遍优势。这项设计主要回答“**相同监督资源下，表示自身让 ICI 应答变得更易读出吗**？”
2. **各臂完整状态映射（补充临床比较）**：若技术条件允许且在资源审计通过后，为 D1/D2/D3 采用相同的状态构建、超参冻结和 ICI 映射选择流程，在 derivation 内独立生成各臂自己的 meta 状态与 response-oriented grades，再使用**各自已经锁定的映射**做 external 验证。D4 若无法自然生成与 CCS 一致的离散状态，按预设共同聚类协议构建并如实记录方法不完全同构。该层评价是**完整 pipeline**，不单独归因于 bank；不允许以原 normCCS 状态标签强行对齐替代模型。

**两个临床实验都必须出现在新 HTML 的资格和结果结构中**。如果新增比较所需的 20 ICI derivation 样本、四个独立外部队列表达/结局或原 mapping 训练契约尚未提供，报告该实验的精确阻断条件，正式交付状态为 `partial` 而不是“全部完成”。在缺少 QL1706 可访问数据时，不能替换成自造或代用的临床结果；可先完成公共 cohort 的有效部分，同时保留 QL1706 待验证状态。

### D 的首要科学判断与对照矩阵

| 观察结果（示意条件，不预设发生） | 论文中允许说什么 | 不允许说什么 |
| --- | --- | --- |
| D1 在多个独立生物终点稳定优于 D2，且来源/容量审计充分 | 真实队列边界学习相较伪混合划分在该数据与任务中提供优势 | 这种优势适用于所有癌种、平台和未来队列 |
| D1≈D2，但二者优于 D3/D4 | 分别训练多个状态模型可能重要，而真实来源边界的独特作用未得到支持 | 独立队列知识互补性已被证实 |
| D1≈D3/D4 | 其它学习型表示可能达到类似性质；CCS 的价值需更多强调固定参考、模块化复用及可解释性 | 只要 A/B/C 有正效应就能声称独立学习最优 |
| D1 仅在重新训练的下游临床映射后优于对照 | 改进可能涉及表示与监督映射的交互，需与共同读出结果并列 | 把性能差全部归因于独立队列知识 |
| 所有臂均接近，或 D1 在部分任务落后 | 当前任务未显示特殊性能增益；可保留真实模型复用的架构事实和已证临床关联 | 事后更改主终点，筛选有利癌种，或写成无损优越 |

## 统计推断、预设和科学解释

### 主终点与比较顺序

为了避免四项实验、五个锚点和多模型形成大量事后显著性，采用以下**预先冻结的层级**：

1. **D 的主要方法学比较：`D1_real_cohort − D2_pseudo_cohort`**，对指定的外部高覆盖生物锚点效用在相同 cohort 中做配对估计；五个锚点为固定检验族，采用 Holm 调整作为保守主报告（另报告效应和 CI）。如果锚点定义需要进一步统一，应在阅读新结果之前固定，并保留原始五锚点全部指标，不能只取最好一项。
2. **D 的关键辅助比较：D1 vs D3 / D4**，使用相同生物学终点、相同外部 cohort；多臂/多终点做预先规定的调整，清楚标记探索性。
3. **ICI 主临床比较：D1 vs D2 的共同下游读出**；按队列与患者配对报告 AUC 差及对应区间，其他臂和完整状态映射为支持性结论。外部队列较少、部分癌种事件极少，应以区间和 cohort-specific 结果为核心，不将 P 值作为唯一判别。
4. A/B/C 按各自预先指定的对照与主终点评估，主要承担机制诊断职责；不要把三个诊断性 P 值和 D 的方法学比较 P 值拼成所谓“综合显著性”。

如需为五个锚点构建单一主复合评分，只能使用**在看到结果前冻结**的方向、标准化和等权聚合规则，并同时展示五个单项、缺失规则和敏感性。最稳妥的默认方案是：D 的主估计为五项固定族的**向量效应**，不事后捏造唯一的“知识复用分数”。

### 推断单位与重复实验

- 生物学/技术主推断：每位 query 的配对效应先汇总至真实**外部 query cohort**，cohort 等权；患者对或近邻对不当独立单位。
- 训练种子和伪 cohort 重排：分别记录**设计间变异**与 query cohort 之间变异；不能把 5×3 训练结果误作 15 个独立外部人群。报告多层区间时明确条件对象，必要时使用以 query cohort 为外层、训练设计为内层的分层 bootstrap 或预设混合效应敏感性分析。
- cohort 模块的来源检验：以**真实 cohort 身份**保持分组；伪 cohort ID 仅是训练标签，不能用于外部推断重采样。
- 外部 ICI AUC：公共验证 3 cohort 可合并估计且保留逐 cohort 效应；QL1706 单独报告，按实际事件数和癌种构成审慎解释。成对 DeLong 适用于同一测试集两个分数的差，但跨 cohort 聚合及重新训练不确定性还需要对应的分层/重复设计描述。
- 不可估计：缺失标签、签名覆盖不足、样本或 cohort 不足、模型训练失败、类别塌缩、平台分层无法重排、临床数据缺失等均保留显式 `status/reason`，不得用零值补齐。

**统计验收不要求 D1 获胜。** 科学结论必须依据效应大小、区间、异质性、来源审计及跨种子重复性，而不是选择最有利的某次训练。

如果项目已具备可直接复用的函数/文件，实施者应**最小化新文件数**，上述名称是职责约定，不是要求机械新增同名重复实现。保留原 `02.03` 结构比较和四份 HTML 的科学口径，不修改公共 `R/ablation.R` API，除非证实训练接口不能通过分析内包装复用并给出相应兼容性测试。

### DAG 的建议结构

```text
existing representation_inputs / biology_inputs / structural_analysis
                    │
           source + config audit
                    │
         ┌──────────┴──────────┐
         │                     │
 frozen-bank A / B / C    D model_train provenance
         │                     │
         │              D1/D2/D3/D4 designs
         │                     │
         │            cohort-grouped model fits
         │                     │
         │             external predictions
         │                     │
         │       representation + ICI evaluation
         └──────────┬──────────┘
                    │
         paired inference + report tables
                    │
          new Rmd -> new HTML/PDF
```

关键 targets 至少需要覆盖：`knowledge_attribution_contract`、`frozen_negative_controls`、`bank_incremental_contribution`、`selective_neighborhood`、`training_design_manifest`、`pseudo_cohort_designs`、`matched_model_fits`、`external_strategy_predictions`、`representation_strategy_evaluation`、`clinical_strategy_evaluation`、`knowledge_attribution_inference`、`knowledge_attribution_report_sources` 和 `knowledge_attribution_report`。具体命名可遵循现有项目风格，但依赖链必须可观察。

**缓存与增量重算要求：** 每个 D 训练模型按 `strategy / tissue / training-design-hash / seed` 分开缓存；严格跟踪原始训练表达、标签、注释、配置、源码、包版本及允许的患者 ID 内容哈希，避免旧模型因文件名相同被误用。只改报告样式应只触发新报告渲染；改 D 模型代码不应导致 A/B/C 旧缓存失效；更改原始训练源或学术参数必须使 D 受影响后代失效。中断后从正式 targets 自动恢复。

**资源管理：** 先由小规模输入完成可行性验收，再按照冻结正式设计运行；模型训练通过 crew 受控并行，限制线程过度订阅。保存每种策略实际可训练数、平均单模型耗时、CPU/RAM 峰值、预计总量与因资源无法估计的分支。**不要承诺固定耗时或在超预算时偷换科学参数**。

## 实施顺序与阶段门禁

### 阶段一：数据资格与审计（必须先通过）

核查外部 cache 中完整输入 RDS、训练模型路径、`subtype` 标签生成所需数据、真实 bank 模块、五锚点表达、ICI derivation/external 表达与结局的可访问性；形成按真实 cohort 的不重叠审计、平台/癌种适配、候选 D1/D2 分组可行性、训练资源报告。**不具备原始局部状态生成和模型训练输入时，不可把 D 替换成 d1 置乱。**

### 阶段二：冻结科学合同与建立 D1 复训一致性

先使用少量具有不同样本数、标签数和平台来源的真实 cohort 复训 D1，与同样输入/参数/种子条件下的历史函数输出核对；如果历史训练运行环境/随机数/包版本已不同，记录非精确复现原因，后续 D1/D2/D3/D4 使用**同一当前环境和重训流程**，不能让 D1 沿用旧训练工件而对照臂重新训练。

### 阶段三：完成 A/B/C 冻结模型诊断

复用 existing d1、Direct 和高覆盖锚点缓存，执行正式置乱、相同模块预算增量比较、受控生物邻域；复算可比的既有基线并检查一致。保持三项结果独立，可先报告但不能将其替代 D 的最终归因。

### 阶段四：D1-D2 模型族匹配的核心重训

在冻结的真实 cohort 和伪 cohort 训练分组上，完整生成局部 `subtype`，调用同一 GSClassifier 训练及预测路径，完成数据来源审计和每组输出维度的匹配评价。D1-D2 是**必须首先完成**的方法学主比较。

### 阶段五：D3 pooled 与 D4 autoencoder 的必要竞争对照

在同一原始样本和严格相同的外部 cohort 上训练 pooled 多状态模型与无监督 MLP encoder，完成共同维度/共同下游读出比较及计算预算敏感性。若 D3/D4 需要额外包，需在既有 `renv.lock` 中显式锁定，不能隐式调用系统不同版本。

### 阶段六：临床评价、统计与独立报告

复用已确认的 ICI derivation/validation 人群与结局定义，各策略独立在 derivation 训练同一临床读出；完整状态映射采用自己的状态编号与自己的锁定映射。完成 paired inference 与 PDF/CSV，再用**新增 Rmd** 读取 target 产物生成 HTML。科学结果不自动写回论文，需先人工解释。

### 阶段七：回归验证及项目文档同步

通过全部科学、工程和统计门禁；同步 `test/ablation-03/README.md`、`analysis-plan.yaml`、`docs/ablation.md`、`CHANGELOG.md` `[Unreleased]`，将计划归档 `docs/plans/`。按仓库 `AGENTS.md` 使用 `humanization` 润色新报告并复核数字保真，按 BAC 工具进行贡献记录与哈希链验证，不擅自调整版本或发布。

## 如何确认完成

### 科学验收矩阵

| 检验 | 必须通过的验证 | 失败处理 |
| --- | --- | --- |
| 来源独立 | 四类数据角色的样本/cohort 不重叠审计、原始模型训练来源可追踪 | 阻断独立归因结论 |
| D1 复训 | 同环境下重复训练/预测确定性；与旧基线差异有审计解释 | 不允许直接混用旧模型和新对照 |
| D2 伪 cohort | 保留训练样本总集、每组织样本数/组规模；真实来源确有混合；重生成标签 | 失败设计标明无效，不按效果选设计 |
| D3 pooled | 使用同样的训练患者、预设状态/模型预算与明确的 ensemble 定义 | 缺预算匹配只能作带限定的辅助比较 |
| D4 非线性 | 使用同样无标签输入，无 ICI 标签泄漏，独立 cohort 分组调参 | 泄漏即阻断临床对比 |
| 输出比较 | 各臂同样 external query、相同基因覆盖/癌种资格、共同距离/读出合同 | 不可比时停止配对结论 |
| 原生 d1 | 模块数、列宽、输出值、权重、参考拟合和实际训练身份可审计 | 发现错配先修复输入 |
| A/B/C | 置乱不跨队列、不改边际；复制不新增函数；配对候选不看结果 | 缺条件标注不可估计 |
| ICI 映射 | 各臂只在 derivation 学习和选择，外部结局完全盲；不能直接复用旧映射 | 临床层不完整时标为 partial |
| 统计 | query cohort 为主独立单位；训练重复与 cohort 变异分离；置信区间和多重比较可追溯 | 不把重复模型/患者对当独立 cohort |
| 结果保真 | positive / null / negative 都按相同模板展示；原本不利于 d1 的结果保留 | 不许后验换主要终点 |

### 代码与展示验收

- 从 `test/ablation-03` 的**现有** `scripts/run-targets-renv.ps1` 以 `-Action manifest` 能看到新增完整 DAG；`-Action make` 使用正式 targets store；`-Action watch` 指向同一个 store。禁止另建正式 runner。
- `tests/45` 和 `tests/46` 应覆盖极少 cohort、技术元数据缺失、重复 sample ID、单状态模型、不同模块列宽、训练失败、无有效伪混合、同一真实来源泄漏、不同表示标签不可对齐、ICI 小事件数、缺失 FFPE、重复设计去重和 ties。
- 有效的 2×2 交叉检查：相同来源不同训练种子改变结果但不会改变数据角色；相同种子改变原始来源应导致正确 targets 失效；只改 Rmd 不得重训 D；只改 D 代码不得不必要地重跑 A/B/C。
- `reports/tables` 中四项实验、四个训练策略的估计值、CI、P/q、`n_cohort`、`n_query`、`n_unique_design`、模型训练数量与 HTML 一致；任何 `NA` 附具体理由。
- 新 HTML 不内置敏感原始表达/结局表；互动表格和 PDF 视图可用，文字、标题、中文字体、统计单位清楚，正式科研图保持真正矢量元素、不能以嵌入位图伪装可编辑图。
- 进行隔离数据集的完整 end-to-end 验收及正式数据运行；通过历史四份报告的输入哈希和 target 状态回归核验，确认原报告科学结果未被污染。
- **成功标准是正确而可复现地得到比较，不是 D1 必须获胜，也不是某一 AUC 必须达到特定值。**

## 关键风险、失败恢复与论文措辞边界

**最大风险不是计算量，而是归因不公平。** 若训练组划分改变了组织/技术构成、`subtype` 生成流程或有效患者量，那么 D1-D2 的差异不能简单解释为“独立队列知识”。必须同时交代这些伴随差异，给出可比严格子集及敏感性结果。

另外需要防范：

- **数据不一定全在当前机器：** GitHub 只包含源代码及聚合报告；新增 D 需要原始训练表达、局部 subtype 生成所需输入及模型/结局数据。缺失则生成阻断审计，不编造结果。
- **重训费用可能很大：** 真实/伪 cohort 各自需要重新状态发现与 GSClassifier fit；正式规模和并行预算在不观察 external 结果的前提下冻结。不因耗时长静默改变迭代次数、训练样本或试验组。
- **训练目标不同：** D1/D2 可以较好控制模型族，D3/D4 的学习目标天然不同，后者用于竞争替代方案而非单因素因果证明；不要将所有臂的效应归为同一种因果解释。
- **学习标签可能不同：** D1 局部 subtype 与 D2 pseudo subtype 没有可直接一一对应的语义；必须对输出做共同评价，不强行对齐标签编号。
- **多癌种/多平台异质性：** 同组织自由混合不应让平台归一化能力差异掩盖科学主张；来源和癌种混杂需双向审计。
- **五锚点同源性：** RNA signature 不是独立于 RNA 输入的病理真值；若能在同一患者中连接额外蛋白/病理测量，可另补强，但不得因此阻断当前已可执行的固定表达锚点任务。
- **临床外部数据少：** 三个公开 cohort 共 128 名可评价患者、QL1706 50 名应答可评价患者（基于论文现有资料），事件数有限，区间较宽；不能承诺方法在临床 AUC 上一定有统计学优势。
- **中断恢复：** 使用原 targets 的 file hash、model checkpoint 及 crew 管理，不清理或覆盖旧正式 store。失败只修复失败目标；必要时重新执行受影响分支并保持历史 hash 可审计。

论文最终应区分四档陈述：

1. **算法事实：** 独立队列模型组成固定 bank，对新患者给出共同概率坐标（已经成立）。
2. **冻结 bank 贡献：** 真实患者对应、模块互补和生物学选择性是否可由 A/B/C 支持（本次待检验）。
3. **训练来源独特性：** 在受控比较下真实来源边界相对于伪混合/pooled 的价值（必须由 D 的结果决定）。
4. **临床迁移归因：** 在同一 ICI 监督资源下，表示差异能否产生更可迁移的外部读出（D 临床层；不能把重新训练的映射贡献自动记到 bank 上）。

即使 D 结果显示其它方法接近，CCS 仍可准确主张多队列模型的模块化知识复用和单样本固定参照；但应避免宣称该策略在表征准确率上具有已证实的普遍优势。反之，如果 D1 在跨种子、跨来源、跨临床测试的多个预设终点稳定优于 D2/D3/D4，才有更直接的证据将差异与独立队列知识的复用联系起来。

## 最终交付与判定

**必须交付：** 新 `02.05.00` 源 Rmd、由正式 `targets` 生成的 HTML，A/B/C/D 四组实验的合法结果或精确失败审计、正式图表/CSV、模型/数据/策略审计、测试和复现记录。

**不能偷换：** D 不是“可选增强”；即使 A/B/C 全部有利于 CCS，也不能据此宣称 H4 已验证。若 D 缺原始训练数据、训练失败或缺必要 ICI 临床数据，应将整体完成状态明确写成 `partial` 或 `blocked`，而不是将原计划改回三个冻结模型分析。

**判断是否有利于论文：** 不看是不是得到最多显著 P 值，而看是否能诚实地区分四个来源——真实联合响应、多个队列模型的互补、训练边界本身、以及后续监督映射——各自究竟贡献了什么。

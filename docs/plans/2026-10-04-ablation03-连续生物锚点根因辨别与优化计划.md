# ablation-03 连续生物锚点根因辨别与优化计划

## 当前方案修订：恢复秩评分与低覆盖探索

2026-10-05 按负责人最新指示恢复 common_raw/common_rank、秩主评分及评分切换。严格门槛不变；另将固定残余基因代理作为低覆盖探索，缺失策略、比较、区间与验收冻结于[恢复计划](2026-10-05-ablation03-恢复秩评分与低覆盖探索性诊断计划.md)。该修订替代下方停用方案；正文原尺度单一方案与停用验收仅作为历史设计，不代表当前运行配置。探索不能确证完整锚点或原负差根因。

## 历史方案修订：停用样本内秩评分

依据项目负责人本次指示，正式分析停用样本内秩评分。原尺度锚点均值只需要签名中的基因，例如增殖签名的基因，不需要额外五千个背景基因。共同背景的 1,130 个基因只保留为测量审计描述，不再作为正式评分资格门槛。

共同基因原尺度评分成为当前唯一新增评分及连续读取器目标；候选池、距离和技术来源对照均使用它。全癌种／同癌种各比较 Direct 与 d1，形成四个表示×候选池组合；取消原先原尺度／秩评分的四格与评分切换差中差。签名仍要求至少原签名的 50% 且不少于 8 个基因，当前仍按全部 190 个契约队列取共同签名；停用秩评分不会自动改变这一交集或恢复低覆盖签名。

实施顺序为：同步正式配置与评分／推断选择；验证低于五千背景时仍能计算有支持的原尺度目标、停用分支不会限制原尺度配对；串行复核后经同一 targets DAG 更新正式结果与报告。验收要求产物仅包含 common_raw，原 172 格效应与人数及旧科学文件保持一致，报告分别解释背景审计和签名覆盖。下文凡涉及秩评分或评分切换的设计均由本修订替代，初次执行记录保留为历史证据。

## 通俗解释：究竟发生了什么

现在用 d1 为患者寻找相似患者时，找到的人在增殖、免疫和基质等表达分数上，通常没有 Direct 找到的人接近。需要弄清楚：是患者信息在重编码后难以辨认，还是寻找相似患者的方法、评价相似性的尺子影响了结果。

可以把这件事理解为按成绩寻找学习伙伴。Direct 保存较细的答题线索，d1 保存多个模型给出的判断；表达锚点相当于用来评价伙伴是否相似的科目分数。如果不同学校使用不同评分尺度，或者检索时换了学科类别，仅比较分数距离就难以判断伙伴是否真的更合适。对应到本问题，学校是 cohort，评分尺度是表达预处理，类别是癌种，伙伴是 reference 邻居。

目前只能看到“d1 的锚点接近度普遍较低”。优化后，应能分别回答“换一把可比较的尺子是否改变差异”“固定癌种后是否仍有差异”“d1 能否预测这些连续分数”“调整距离是否改善邻居”。例如，若 d1 能准确预测免疫分数，但按当前距离找到的邻居免疫分数仍不接近，就优先调整距离设计。

## 专业判断与数据充分性

本轮使用现有冻结数据执行预设根因诊断与资格审计。原始表达资源、签名资源、冻结输入、Direct/d1 矩阵与正式结果缓存均已确认存在；资源可访问不代表共同测量一定有支持。正式审计发现全契约共同签名覆盖不足，按下述门禁保留不可估计状态，未获得机制比较的可估计证据。当前样本内秩评分已停用，背景基因数量不再是评分门槛。病理、蛋白、治疗反应等不同来源的生物效用验证，需要对应测量。

| 现有资源 | 已核实的规模或状态 | 计划用途（以资格审计为准） |
|---|---|---|
| reference 表达与表示 | 24,487 个样本、147 个 cohort | 定标、锚点基因审计、连续锚点预测器训练、距离诊断 |
| 外部 query 表达与表示 | 14,060 个样本、43 个 cohort | 冻结模型条件下的外部配对评估 |
| Direct / d1 | 分别为 529 / 583 列；d1 来自150个冻结模块 | 输入重叠审计、模块距离对照、信息可读出性检查 |
| 癌种终点资格 | 现有 cancer retrieval/readout 为17个 estimable cohort，其余26个不满足既有资格规则 | 癌种内检索需另列资格表，不能用“标签非空”代替支持门槛 |
| assay / source 标签 | 当前契约字段齐全，仍需检查证据和分层支持 | 检测类型、来源系统的支持范围内敏感性分析 |
| platform 标签 | query 仅357/14,060个有非未知值 | 已知平台只能作小范围补充；unknown/unknow 不视为同一真实平台 |
| 完整表达来源与签名来源 | 生物缓存记录的两个来源文件均可访问 | 建立共同签名和拆分 IFN、IL6 签名 |

当前172个 cohort–anchor 格子中155个为负，37/43个 cohort 四项都为负；四项 cohort 等权差约为−0.044至−0.055。reference 几何子样本中，d1有效秩约48，Direct约97，top-30邻居Jaccard约0.335。四项队列效应相关约0.895–0.967。这些是待解释的现象，不能单独确认压缩或批次机制。

评分直接提取各 cohort 的表达数值，再应用混合 reference 基因标尺，未在该步骤统一表达预处理。GSE21983的锚点基因表达中位数约353，utility接近地板；不同队列表达分布也明显不同。表达分布差异可能同时含技术与生物因素，应先追溯现有预处理记录，不能仅凭范围差异自动取对数、逐队列中心化或判定数据错误。

## 要达到什么目标

交付一份能够区分测量尺度、癌种组成、距离权重和连续信息可读出性的诊断报告；每项结论对应一个明确的受控比较，并交代适用队列、效应量和不确定性。允许最终结论仍是“多个机制共同作用”或“现有支持不足以辨别”。

本次优化以解释现有负差为目标，成功不要求 d1 胜过 Direct。不重训原有 CCS bank，不调整发布版本，不更改既有主分析患者契约或默默替换原锚点评分。既有结果保留为基线，新增实验作为并列诊断。四项原锚点保持主诊断集合；IFN、IL6拆分和输入不重叠签名列为补充。

## 改进方向与实验设计

### 测量与资格审计：先确认用的是同一把尺子

在任何新比较前，生成每个 cohort 的测量审计：表达单位与变换证据、锚点基因和共同背景基因覆盖、非有限值、零值与并列秩比例、分数分布、utility地板情况，以及癌种/检测类型/来源/平台标签的有效支持。没有可靠证据的单位或预处理标为未知，不靠数据分布猜测后写成已知事实。

同时核对样本ID唯一性、reference/query互斥、模型训练来源与外部资格、两臂共同query、同cohort排除、基因ID和特征构造来源。冻结输入中恢复普通基因、基因对和gene-set特征涉及的完整基因集合；set-pair不能只凭列名解析。若无法恢复完整输入支持，输入不重叠实验标为不可估计，不声称独立。

把四项共同签名清单写成版本化产品。同一实验中的所有评分样本使用相同清单，不按 cohort 更换签名子集。签名至少保留原签名 50% 且不少于 8 个基因，否则该实验组合不可估计。当前原尺度评分没有背景基因数量门槛，全表达交集仅保留为测量审计清单。

确定清单只依赖基因可用性和预设队列契约，不依据query表达值、锚点分数或两臂胜负。它描述的是当前固定输入范围，不能外推到其它测量平台。

对读者而言，这一步能明确哪些队列确实可比较，哪些结论仅受测量限制。

### 评分与候选池对照：把测量因素和癌种组成分开

先复现原评分、原邻居名单和原配对效应，建立零改动基线。随后用共同签名清单建立原尺度评分：

**共同基因原尺度评分**：沿用 reference-only gene-wise z-score 和签名均值，只固定实际参与基因；用于区分基因构成变化与尺度变化。

在支持癌种内检索的固定query集合上，执行以下最小对照矩阵；每格都比较Direct与d1，保持k=15、距离基线和患者配对不变：

| 分数定义 | 全癌种跨cohort候选池 | 同癌种跨cohort候选池 |
|---|---|---|
| 共同基因原尺度 | 测量对照A | 组成对照B |

同癌种候选池要求癌种标签具有可用证据、至少两个独立reference cohort且至少15个合格reference样本。cohort内至少20个有效query才进入跨cohort推断；不足仍保留描述值。借用现有endpoint资格逻辑核验，不以tissue替代缺失癌种；新资格表保留与原17个癌种终点队列的差别和原因。

候选池对照采用共同 query 和共同 cohort 交集；全 43 队列可估计部分另作覆盖更广的共同签名分析，不混用分母。记录每个患者两臂同癌种邻居比例、邻居来源、邻居重叠及锚点距离，辅助解释名单组成。

主要终点仍是患者配对后 cohort 等权的 d1−Direct utility 差；辅助保留分数绝对距离、各臂 utility 和分数分布。原尺度共同基因分数按 reference 分数标准差定标后使用 exp(-绝对差) 映射。癌种候选池切换在同一评分及共同患者上估计配对差中差，取消原尺度／秩评分切换比较。

这组实验让读者检查：固定共同原尺度签名后，邻居癌种组成是否参与原负差。当前没有秩评分对照，不能估计改变测量定义的影响。

### 连续锚点预测：检查信息能否被读出来

对 Direct 和 d1 各训练一个同规格的连续分数预测器，使用共同基因原尺度评分作为唯一目标。先用带 L2 惩罚的线性回归读取信息；它的作用是测试表示中是否含有可利用的连续状态线索。

训练仅使用reference；按cohort分组进行5折内部验证，使用相同折分和lambda网格0.1、1、10。特征定标、目标尺度和所有拟合步骤都只用相应训练折。外部43个query cohort在可估计范围内一次性评估，不参与调参。另给出reference整体均值预测；癌种均值基准只在有支持的共同子集上比较。

主要比较为cohort等权的标准化MAE差，定义为d1 MAE减Direct MAE，正值表示d1更差；辅以预测值与真实值的Spearman相关。reference目标零方差时标准化MAE不可估计；query cohort目标或预测零方差时仅相关不可估计，MAE仍按其自身条件计算。有效query不足20的cohort保持描述值和原因，不进入主要推断。

如果线性读取明显受限，再运行唯一一个预先固定的非线性读取器：沿用现有XGBoost依赖，平方误差回归，深度3、学习率0.05、200轮、样本及列采样均为1；参数在实验配置中完整冻结，不看query结果调参。两臂采用同规格读取器，不进行额外模型搜索；此项为补充证据。

若预测表现接近而邻居表现较差，支持距离未充分使用连续信息；若线性较差而非线性改善，支持信息编码变复杂；若两种读取器都较差，只能说明在当前读取能力和外部范围内较难恢复，不能证明信息永久丢失。以上比较条件于已冻结bank，reference分组验证不包含bank重新训练的不确定性。

对读者而言，这一步区分“记住了但不好找”与“目前方法确实读不出”。

### 距离与模块对照：定位近邻重排的来源

固定共同基因原尺度评分和合格癌种内候选池，只改变 d1 检索距离；Direct 始终使用原基线距离。保留三个预先指定的 d1 方案：

- 当前逐列reference标准化、模块平衡欧氏距离。
- 不除以列标准差、仍保持模块平衡的欧氏距离，检验小波动被标准化放大的影响。
- 保持逐列reference标准化，改为tissue等权、tissue内module等权、module内列数平衡的欧氏距离，检验模块数量不均对bank距离的影响。

第二和第三方案分别相对原方案只改变一个权重规则，不组合寻找最优方案。tissue归属来自已冻结且审计过的module manifest，无法解析时该分支不可估计。对全部query仍保留全癌种候选池补充结果，但不再展开所有评分×距离的组合。

补充输出模块间相关、每个模块对query–邻居平方距离的贡献、reference与query的概率饱和比例和标准化幅度。这些诊断提出冗余或域迁移线索；不按外部效果筛选模块，不把模块输出强行归一化成和为1的多分类概率，也不从没有外部真实训练目标的概率计算伪校准误差。

这一步能判断当前“相似患者”的定义是否过度强调小波动或模块较多的组织。

### 同源性、签名构成与技术来源补充

使用前述完整输入基因支持，建立排除输入重叠基因的签名敏感性；沿用至少50%且不少于8个基因的门槛，失败时明确不可估计。即便无直接重叠，表达相关性仍存在，所以这项结果只称“直接输入不重叠”，不称独立生物验证。

IFN与IL6分别评分，不再仅凭合并签名判断两条通路；维持原四锚点为主要集合，两个拆分指标构成独立补充比较族。不要根据结果挑选基因、签名或有利队列。

检测类型和source的敏感性在同癌种候选池内分别限制来源，避免把癌种组成变化误当技术效应。每种限制都重新核对reference支持和两臂共同query；每个可比较层至少3个query cohort且各有20个query才估计区间。平台分析仅用已知真实标签，不将unknown视为平台，支持不足则只报告覆盖。

保留GSE21983等测量异常候选在基线中。另输出对全部cohort逐一删除的对称敏感性，不能只删除负差最大的队列。单个异常的处理依据预处理证据和预设测量门禁，与效应方向无关。

### 精确检索核对：排除工具误差

在调研新检索机制前，用固定cohort分层子样本核对精确欧氏检索与Annoy：每个合格cohort最多20个query，seed为20261004，比较top-15召回和utility配对误差。既有30个query的top-30验证不足以直接覆盖全部锚点任务。

每臂总体平均召回至少0.95、每个cohort平均至少0.90；不达标时按预定搜索预算升级，仍未达标的检索方案切换精确实现，全部由targets执行。参考池、距离和并列距离处理保持一致；同时报告距离并列程度，避免将等距候选的ID差异误读为搜索失败。实验正式结果必须来自达到门禁的检索，不能先用不合格名单计算正式效应。

## 推断口径与机制判读

这批结果已被查看过，本轮属于预先固定新对照的探索性诊断，不能宣称在未观察数据上完成确认性机制验证。以下规则在新结果计算前冻结。

| 估计对象 | 观察单位与尺度 | 区间与检验 |
|---|---|---|
| 各实验的d1−Direct utility | 患者配对、cohort内均值、cohort等权；每项锚点分别报告 | 2,000次完整cohort配对bootstrap，95% CI；至少3个有效cohort；四原锚点为一族，预设零差双侧sign-flip及BH校正 |
| 同评分下候选池切换、距离切换的变化 | 同患者同cohort的配对差中差 | 共享cohort重采样索引；完整报告各预定比较，族内BH校正，不按显著性选方案 |
| 连续预测的MAE差与相关差 | 各cohort先算性能再等权；使用同query集合 | 固定训练模型条件下的cohort bootstrap；主要MAE的四锚点×预定读取器为一族，零差双侧sign-flip及BH校正；辅助相关只给CI；不声称包含重新训练bank的波动 |
| 固定cohort局部utility差 | cohort内完整配对query | 至少20个query的2,000次百分位bootstrap，点式95% CI；不补单格P值，不以172格反复检验确认亚组 |
| 覆盖、饱和、模块相关、秩范围、精确检索误差 | 当前固定输入的诊断描述量 | 说明分母和定义，不附没有推断目的的P值 |

各实验在开始前生成共同query/cohort清单；对不同定义或人群的差异，仅在交集上比较变化，完整范围另列。effect、CI、有效query/cohort数、评分与距离身份、候选池、seed、重采样有效次数及不可估计原因同时保存。未来来源泛化另给source层的留一敏感性；共享来源的cohort不能自动当成完全独立抽样。没有至少3个有效source组时，不做source层泛化推断。

统一seed为20261004，由冻结的实验ID映射派生子流。2,000次bootstrap至少1,900次有效才发布区间，否则保留NA、有效次数和失败原因；不同指标因不可估计使用不同人群时分别列分母。模型和 reference 标尺的不确定性不包含在固定模型的query/cohort区间中，报告明确其条件边界。

| 新实验中的模式 | 更支持的解释 | 仍不能据此推出什么 |
|---|---|---|
| 同评分下癌种内负差缩小 | 邻居癌种组成参与了原负差 | 癌种内部连续信息完全保留 |
| 锚点预测接近Direct，距离对照改善检索 | 连续信息可读出，距离权重限制了邻居质量 | d1无损或该距离是全任务最优 |
| 非线性读取优于线性读取 | 表达信息可能被非线性编码 | 未测试读取器也能恢复或所有患者均获益 |
| 可比评分、癌种内、不同读取器下仍偏弱 | 当前表示的连续信息利用受限 | 全部生物信息永久丢失或临床效用更差 |
| 不重叠签名方向不同或不可估计 | 输入同源性或可测签名范围影响结论 | 具备独立病理/临床验证 |

对“接近”“缩小”“改善”先报告差值和CI，不凭CI跨零宣称等价或完全解释。此次不设未经科学依据支持的非劣效界值，也不将若干受控变化加总为根因贡献百分比。

## 实施范围与顺序

1. 冻结实验配置与输入身份，复现既有基线；完成测量、基因支持、标签及候选池资格审计。若reference与query混淆、ID不一致或正式DAG与实际执行不一致，先停止计算并修正契约。
2. 建立共同基因原尺度评分产品，运行最小候选池对照，检查精确检索门禁，形成共同签名／癌种组成诊断。
3. 用reference训练连续锚点读取器，在固定外部query上评估；执行两个单因素d1距离对照及模块贡献诊断。
4. 在支持范围内执行输入不重叠、IFN/IL6拆分、检测类型/source与对称留一敏感性；汇总机制证据、限制及仍未辨别的部分。
5. 更新生物锚点报告、README、analysis-plan.yaml及CHANGELOG [Unreleased]，经隔离小测、正式targets执行和报告检查交付。原结果的解释若受新证据影响，采用并列修订说明，不隐藏原负差。

首批核心只包含基线/测量审计、共同原尺度候选池对照、连续预测、两个距离对照。补充分支按明示支持门禁运行，避免所有因子全组合扩张。执行前用隔离小测记录耗时和内存，再按实际branch数量估算正式资源；计划阶段不给未经测量的工期承诺。

## targets接入与产物

继续使用现有`_targets.R`作为唯一依赖图，新增实验配置文件及其file target；既有`representation_inputs`、`biology_inputs`、冻结模型输入和`biology_analysis`是新分析的上游，不复制一套runner或checkpoint。正式store继续指向本次cache root下的`targets`；正式执行和监控通过既有launcher调用`tar_make()`与`tar_watch()`。

建议新增的语义节点及依赖为：

- `biology_diagnostic_audit`：输入契约、完整表达来源、特征manifest、实验配置 → 资格/尺度/共同基因审计。
- `biology_diagnostic_scores`：审计通过的表达和清单 → 各预定评分产品。
- `biology_diagnostic_retrieval`：冻结两臂矩阵、审计资格、预定距离 → 合格邻居及精确检索核对；评分变化复用同名单。
- `biology_diagnostic_readout`：冻结reference/query矩阵、目标分数、分组划分 → 读取器拟合与外部预测。
- `biology_diagnostic_inference`：评分、邻居、预测、共同query清单 → 患者/cohort汇总与推断。
- `biology_report`及`report_payload`：加入新产物依赖，展示新诊断；资源汇总节点显式等待新增计算节点，保证新worker日志进入最终metrics。

具体target名称可以在实施时调整，依赖语义和单一入口不能变化。共享的科学计算进入包内计算层；targets文件只做wiring，Rmd只读取产物，不训练模型或重算bootstrap。包源代码若改变，先同步已安装代码身份及检查门禁；本计划不授权修改DESCRIPTION Version、tag或release。现有ablation重构升版例外不被扩展解释为本次实验的自动升版权限。

冻结配置、清单和需要复核的科学结果写入正式cache root的独立`biology-diagnostics`目录，由targets管理依赖和恢复，不写入raw或现有基线文件。项目reports目录保存可分享的聚合CSV、PDF与HTML，不导出患者身份或表达原值。完整表达读取集中为一个受控准备节点，提取后各分支复用，避免多个worker重复装载整套atlas。

target-level并行继续接入现有crew controller；主进程与worker日志、CPU/RAM采样写入cache root的observability日志目录，并由autometric读取/绘图，不混入科学缓存。保留现有renv；需要新依赖时先检查可用环境并同步锁文件，不自制资源采样或并行调度器。

## 如何确认完成

- 交付数据资格表，逐项说明43个原锚点队列中哪些参与各新实验，以及排除原因；不因结果方向改变资格。
- 原基线172格的点估计和人数在数值容差1e-10内复现，既有科学结果未被新实验覆盖。
- 原尺度候选池对照、两个距离对照和两臂预测均在各自共同患者集上计算；改变候选池或标签资格后显式记录分母变化。
- 用包含多个cohort、已知/未知标签、不同表达尺度、缺失基因、零方差、并列值及支持不足的合成fixture运行同一DAG。断言reference-only拟合、query互斥、完整top-15、共同签名、不可估计原因、配对汇总和图表数据对应。
- 专门验证停用秩评分后，仅 100 个背景基因仍能计算有支持的原尺度目标；背景中非签名基因的增减不改变原尺度分数；候选池、距离、技术来源对照不会依赖秩分支。保留休眠秩实现的既有数学断言。验证精确检索的同 cohort 和癌种限制，以及 bootstrap 对相同有效 cohort 集合共享索引。
- 隔离小测使用独立输入、cache root、store和OutputRoot，不能写正式reports/raw。R执行、情景检查和包检查使用`C:/R/R-4.3.1`。若修改包计算层，运行适当情景检查及`R CMD build/check`，同步文档并安装相同版本的经验证代码；结果必须如实列出未运行项。
- 正式`tar_make()`完成新节点，`tar_watch()`指向同一个store；模拟局部失效后通过targets恢复，并证明无关已有效节点未重算，不另建临时恢复入口。
- 每个主要对比提供effect、95% CI、有效cohort/query数、预设检验族与校正结果；预测区间、局部query区间和跨cohort区间分别说明条件范围。
- 报告给出“支持何种机制、相反证据、适用范围、仍不能辨别什么”；最终候选排序随新证据修订，不以显著性或d1胜负作为验收。
- 完成数据流与DAG、R实现与恢复、科学统计口径的顺序只读自审；记录检查结果及限制。BAC记录需求、改动、命令与验证，交付前核验哈希链。

## 风险与待确认事项

共同基因交集、真实平台覆盖和癌种 reference 支持可能使部分补充实验不可估计，这是应输出的测量边界，不通过补造标签或事后降门槛解决。原尺度分数仍受表达单位和预处理差异影响，未知来源需如实报告。

表达尺度异常队列的上游预处理证据尚未完成审计。先搜索本地数据说明和处理代码；能从已有记录解决时不要求负责人额外提供资料。若既有记录缺失，记录未知并限制该分支解释，仍可推进其它可估计实验。平台证据不足不阻塞全轮分析。

已有外部结果已参与假设提出，仍可能有探索性选择偏差；冻结新对照、保留完整结果和query不参与调参可以降低新增偏差，不能把现有数据变成全新的独立确认集。独立生物/临床效用验证属于未来研究，需要对应不同来源结局。

# normCCS 目标函数扩展实施计划

本文规划如何为 `subtypePerformance()` 增加目标函数选项。默认 `median` 完整保留现有行为，其他策略由调用者显式选择。本轮只交付计划，尚未修改算法或验证新策略的预测收益。

## 问题与预期变化

现在，函数会尝试把原始分型合并成若干等级，再按一个固定标准选出最佳方案。搜索变快以后，“用什么标准选最佳”仍然只有一种选择。

以五个队列为例：方案 A 的 AUC 为 0.80、0.80、0.80、0.51、0.50，方案 B 全部为 0.75。只比较真实队列的中位数时，A 获胜；比较平均效果或较差队列时，B 更有吸引力。现有默认评分还包含合并样本得到的 `All` AUC，因此真实择优结果也取决于该汇总行。这说明不同目标会选出不同分级，不能把某一种汇总方式视为普遍最优。

改造后，旧脚本继续得到原来的结果；研究者可以用同一份数据、同一排序和同一搜索方法比较不同目标。新增策略用于比较不同的分级选择标准，能否提高跨队列预测效果仍需独立验证。

## 已核对的实现

| 位置 | 当前职责 | 本次需要处理的部分 |
| --- | --- | --- |

| [R/subtype_norm_dp.R](../../R/subtype_norm_dp.R) | 前缀计数、区间损失、DP 初值、多起点精修、原 ROC 复核 | 将候选评分、初值选择、精修和最终排序接到同一目标 |
| [R/ccs_base.R](../../R/ccs_base.R) 中的 `get_perform_markers()`、`multiXClass_roc()` | 计算 `Raw` / `OptimizeRank` AUC，沿用 pROC 方向规则 | 本次保持统计定义，不借新增目标调整 ROC 行为 |

当前目标的精确定义是 `median(c(AUC_All, AUC_1, ..., AUC_C), na.rm = TRUE)`。`All` 与真实队列共享样本，且 pooled AUC 包含跨队列的病例—对照比较；它既不是独立队列，也不等于队列 AUC 的样本量加权平均。

当前 DP 精确求解固定方向、固定权重的均值 Raw AUC 子问题，再按遗留中位数选择和精修候选。最终评分仍兼容 pROC 自动方向，`OptimizeRank` 还会按当前队列结局重排等级。因此，把最终目标改成 `mean`，也不能直接把整个搜索标为全局精确。

本计划承接 [现有 DP 搜索优化计划](CCS_normCCS_DP_search_optimization_plan_2026-10-29.md)。后续实施时，目标函数固定为遗留中位数的要求按本文扩展；原排序、连续分段空间、穷举保护和 ROC 复核要求继续保留。

## 接口与兼容约定

只新增一个公开参数：`norm_objective = "median"`。将它追加到 `subtypePerformance()` 当前形参列表的最后，也追加到内部 `subtypeNorm()` 的最后；其他内部参数按调用链需要追加。这样不会改变旧位置参数的含义。

三个参数分别负责三件事：`norm_search_method` 决定如何搜索，`norm_roc_method` 决定如何计算每个队列的 AUC，`norm_objective` 决定如何把这些 AUC 汇总成候选得分。穷举和 DP 都支持新增目标，避免同一参数在两条路径中含义不同。

新参数只接受下表中的完整名称。对 `NA`、空字符串、未知值、非字符输入和长度不为 1 的显式输入，在搜索或绘图前报错；不接受部分匹配，也不回退到默认值。`n_norm_subtype = NULL` 时仍检查参数是否合法，但不执行归一化搜索，继续返回 `Data$Normalization = NULL`。

默认兼容以当前 0.8.5 实现为准：不传参数与显式传入 `"median"` 必须一致；`Raw`、`Summary`、最佳 `Info`、等级编码、最终切点及候选选择不变。保留默认 `"bruteforce"`，不修改 RR/NRR 排序、连续区间限制、ROC 方向、`OptimizeRank`、并行方式或科学数据。

## 首批策略及其数学定义

记切分为 P，真实队列数为 C，当前 ROC 方法得到的队列 AUC 为 a_c(P)，合并样本 AUC 为 a_All(P)。所有目标都按得分从高到低选择。

| `norm_objective` | 得分定义 | 用途 |
| --- | --- | --- |
| `median` | `median(c(a_All, a_1, ..., a_C), na.rm = TRUE)` | 默认；完整复现遗留中位数策略 |
| `cohort_median` | 仅对 C 个真实队列取中位数 | 单独观察移除 `All` 的影响，保留中位数思路 |
| `mean` | C 个真实队列的等权平均 | 优化总体跨队列表现，作为最清楚的新基线 |
| `lower_tail` | 真实队列 AUC 分布最低 25% 概率质量的平均值 | 更关注表现较差的队列 |
| `mean_lower_tail` | `0.5 * mean + 0.5 * lower_tail` | 折中考虑总体效果与较差队列，优先推荐用于探索 |

四种新增策略均排除 `All`，但 `Raw` 继续保留 `All` 行供描述和复核。等权指每个真实队列权重相同，不按样本量加权，也不自动改为癌种等权。

### 下尾均值如何计算

为避免队列数不能被 4 整除时口径不清，将下尾均值定义为下侧条件风险价值的离散形式，即对最低 25% 的队列概率质量取平均。按 AUC 从低到高排序为 a_(1), ..., a_(C)，令 t = 0.25 * C，r = floor(t)，d = t - r，则：

```text
lower_tail = (sum(a_(1), ..., a_(r)) + d * a_(r+1)) / t
```

当 r = 0 时求和项为 0；当 d = 0 时不计算最后的加权项。边界队列按剩余比例计入，而不是简单取 `ceiling(0.25 * C)` 个队列。

例如，四个队列的下尾均值就是最小 AUC；五个队列则为 `(a_(1) + 0.25 * a_(2)) / 1.25`。只有一个真实队列时，四种新增策略全部等于该队列 AUC，不会产生标准差未定义或空集合问题。

首版把下尾比例固定为 0.25、折中权重固定为 0.5，作为明确的策略定义，不再增加调参接口。这两个数值并非已验证的最优超参数；以后如需开放调整，应另行设计可复现的参数扩展。

### 为什么先不加入其他损失

这一版集中于已有 AUC 的不同汇总方式。log-loss、Brier score 需要另外定义等级到概率的映射、训练与验证边界，以及队列基线应答率的处理，不宜混入本次兼容修改。AUPRC 受应答率影响较大，跨队列汇总也需额外定义。

暂不加入 `mean - SD`：它可能因为某个高分队列进一步改善、队列间差异随之增大而降低总分。均值与下尾均值的非负加权组合没有这个问题：其他队列不变时，提高任一队列 AUC 不会使目标变差。纯最小 AUC 则过于容易受单个小队列影响，先用下尾均值覆盖这一需求。

## 如何改造目前的函数

### 共用一个评分函数

新增内部文件 `R/subtype_norm_objective.R`，用普通函数实现评分，不新增类或依赖。建议核心接口为 `norm_objective_score(auc, cohorts, objective)`：`auc` 是候选 × 队列矩阵，`cohorts` 明确标识各列，返回长度等于候选数的数值向量。

该函数按名称识别 `All`，不依赖它恰好位于第一列；子集操作始终保留矩阵维度。遗留分支保留原来的 `na.rm = TRUE` 语义；新增策略要求所有纳入评分的真实队列 AUC 有限，不能通过临时丢弃低分或缺失队列改变比较人群。无真实队列、重复队列标识或非有限结果应给出可定位的错误。

穷举路径从 `df_perform` 提取逐候选 AUC 并调用它；DP 路径把 `norm_auc_batch()` 的矩阵交给它。原始 ROC 逐队列复核后，再用同一函数汇总。这样，精修和最终 Summary 就会使用同一个目标。

兼容处理应留在输出整理和必要的旧分支中，不复制五套搜索算法。先保证默认结果不变，再逐步共用评分逻辑。

### 穷举路径按选定目标择优

保持当前合法切分枚举、内存保护和逐队列 ROC 计算。`median` 的 `Summary` 仍只有原有列，并按原有规则排序；新增策略按 `objectiveScore` 排序。

不要把均值或下尾得分写进 `medianROCAUC`。新增策略的 Summary 保留该列及其旧定义，另增加 `objective`、`objectiveScore`、`cohortMedianROCAUC`、`cohortMeanROCAUC` 和 `cohortLowerTailROCAUC`。其中 `medianROCAUC` 是描述性指标，可能不随行序递减；首行代表当前目标的最佳候选。

新增策略得分并列时，先按真实队列均值降序，再按 `Info` 字符串升序，保证重复运行选中同一个方案。默认 `median` 沿用原有并列规则。

### DP 的全部择优环节同步切换

保留现有计数模型、区间 DP、多权重初值、单切点和相邻双切点精修，以及最终原 ROC 复核。第一版沿用现有初值集合、最多 6 个精修起点和 10 轮上限，不引入新的优化框架。

必须一起替换的环节包括初值打分、精修起点选择、单切点与双切点候选比较、收敛判断、最终排序和最佳切点定位。精修只接受目标提高超过 `1e-12` 的移动；新增策略在同分时使用前述确定性规则选择起点和最终候选，不依靠同分移动扩展搜索。

`median` 继续保留当前初值同分顺序、容差、精修次序和候选去重行为。新增目标只能复用搜索骨架，不能顺便改变默认路径的这些细节。

复核时同时核对逐队列快速 AUC 与原 ROC AUC，容差沿用 `1e-10`，再核对目标得分。任何不一致都停止返回结果，不以快速近似得分替代复核结果。

### 精确性与诊断信息

穷举在通过规模保护的合法空间内按所选目标全枚举，可以找到该目标的最佳连续分段。DP 的固定方向均值子问题仍精确；五种公开目标在现有自动方向或重排评分下，统一按近似搜索说明，不因为名称是 `mean` 就把 `exact_global_optimum` 改成 `TRUE`。

默认 DP 诊断保留现有字段及含义。新增策略使用通用字段描述本次优化，例如 `objective`、`objective_scope = "cohorts_only"`、`best_initial_objective_score`、`best_final_objective_score` 和逐起点的初始／最终目标得分。下尾与混合策略分别记录 `tail_fraction = 0.25`、适用时的 `mean_weight = 0.5`；同时报告真实队列数、候选数、评分次数、切点和实际耗时。

不要将新的目标得分填入 `best_initial_median_auc` 或现有精修记录中的 `initial_auc` / `final_auc`，也不要保留与实际目标不符的 `legacy_median_auc_including_All` 标签。`exact_global_optimum = FALSE` 与 `dp_subproblems_exact = TRUE` 分别说明整体搜索和内部子问题，含义必须区分。

公开结果的复现信息对非默认策略增加 `Repeat$norm_objective` 和适用的固定设置。为保护默认对象结构，`median` 不新增 Repeat 字段；文档明确，缺少该字段表示遗留 `median`，包括显式传入 `"median"` 的调用。`n_norm_subtype = NULL` 时，非默认策略可以记录选择，但不能生成虚假的搜索诊断。

## 实施顺序

1. **固定兼容基线。** 在修改源码前，保存当前 0.8.5 的合成输入、穷举与 DP 输出、切点、关键函数指纹及 R 会话信息。已有 0.8.4 穷举参考继续保留；DP 还需当前版本的基线，不能拿单切点初版当成当前实现。
2. **实现评分与参数透传。** 先完成独立评分函数和小规模手算核对，再把新参数从公开函数传到两条搜索路径。此时先跑默认回归，确认接口接入没有改变旧结果。
3. **接通完整搜索与输出。** 为穷举和 DP 接入同一目标，处理新策略的排序、诊断和复现信息；用可穷举问题比较两者，而不要求非可加目标全部匹配。
4. **完成组件、公开入口与包检查。** 通过下节验证后，再扩展合成基准并同步文档。任何默认回归失败都先修复，不以新策略得分提高作为接受理由。

### 搜索差距与性能

每种目标分别计算 `gap = exhaustive_best_objective - dp_best_objective`，同时报告切点、真实队列 AUC 向量、均值、中位数、下尾均值和等级人数。不能用旧中位数最优值减去新目标得分，也不能比较不同目标的绝对数值来宣称某策略更好。

先使用小规模合成数据完成精确核对，再参考现有 `benchmark-config.json` 的质量配置 M = 10、C = 4、10 个固定种子和 K = 4、5、6 扩展比较。真实队列数另外覆盖非 4 的倍数，确保下尾分数计算确实经过检验。均值 DP 子问题与同目标穷举最优损失仍应在 `1e-12` 内一致。

公开目标搜索的 `gap <= 0.005` 可沿用为工程质量目标，不是数学保证或统计显著性标准。逐例保留超过该值的情况；若近似质量不足，先调查初值覆盖与精修停滞，不能删除失败种子或将近似结果标为精确。

性能比较同时记录当前基线与修改后默认 `median` 的耗时、候选数和评分次数，以识别评分抽象带来的额外成本。新策略的大规模测试沿用 M = 107／216、C = 20 和 K = 5、6、8、10、12；在小规模正确性通过后运行，不预先物化全部切分组合，也不许诺未经测量的加速倍数。

以上测试沿用现有包组件和合成基准的运行方式。后续若在已声明 targets 依赖图的真实分析中比较策略，必须更新其正式 `_targets.R`、函数依赖及 store，通过 `tar_make()` / `tar_watch()` 运行和监测；不得以本节测试脚本替代正式分析。

## 风险与后续科学评价

下尾目标会更关注低 AUC 队列，也更容易受小队列噪声影响。它改善训练集上的下尾分数，不足以证明迁移能力改善；`mean_lower_tail` 的固定权重也只是清楚可复现的起点。首版不再叠加样本数约束、癌种权重或自适应调参，以便判断变化究竟来自哪个目标。

新增目标继续沿用自动方向与 `OptimizeRank`，搜索结果仍按现有评分定义解释。评价统一等级的外部预测能力时，应在训练数据内确定排序、切点、等级数、方向和映射，在留出队列中固定使用；不能根据验证队列结局再翻转或重排等级。需要选择目标函数时，在训练部分完成选择，再报告外层留出队列结果。

本轮完成标准是交付这份实施计划；后续代码阶段的完成标准是默认回归、策略定义、搜索一致性、公开入口及包检查全部有对应证据。新策略是否优于旧策略属于后续科学验证，不与工程验收混为一谈。

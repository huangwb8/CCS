# ablation-03 锚点队列内区间图

## 目的与输入

为生物锚点报告“锚点格子的队列内波动”增加可发表的区间图。直接消费正式 `statistical_inference$biology_local`，不重算评分或 bootstrap。估计对象为固定 cohort 中配对 query 的平均 d1−Direct utility 差，区间来自 cohort 内完整配对 query 的百分位 bootstrap；少于 20 个有效 query 的格子保持描述点与 NA 区间。

## 图形与解读

“锚点格子的队列内波动”作为“队列间效应分布”下的子节，紧接队列配对均值热图，连续呈现同一格子的均值、区间与明细表；总体推断表保留在“配对效应与不确定性”。

四列分别为 Proliferation、Immune TME、Stromal TME、IFN / IL6，顺序沿用冻结配置；cohort 按字典序自上而下排列，与异质性热图一致。各列共用效应横轴和零虚线，点表示当前 cohort 均值，短端帽细线表示点式 95% CI；不可估计区间用空心描述点标明，不伪造为零。保留完整明细表，导出同源 CSV，正文动态给出有效 query 数范围和区间跨零情况。

此图只呈现队列内患者组成的波动，条件于固定模型、reference 尺子和近邻名单，不替代队列间主效应区间。172 格的点式区间未做同时覆盖校正，不绘显著性星号、不补单格 P 值、不据此确认亚组差异。

## 执行与验收

图代码放入对应 Rmd，PDF/CSV 纳入 `analysis-plan.yaml`；沿现有 `biology_report` 对 `statistical_inference` 的正式依赖，通过同一 store 的 `tar_make()` 更新 HTML、PDF 与预览。核对每个图点与既有 cohort 差值、人数一致，无重复或漏格；科学 summary RDS 哈希不变，数据流、R 实现、科学口径顺序审查。视觉检查标签、行距、区间和字体，不新增另一套计算入口。

## 验收记录

正式 `tar_make()` 更新两个报告相关节点、跳过 25 个缓存节点；科学 summary RDS 的 SHA256 未变。43 个 cohort × 4 个 anchor 的 172 格均可估计，有效 query 为 24–1,094 个，19 个点式区间包含零。输出 CSV 按既有字段类型回读后与冻结推断结果一致；绘图时逐格核对热图均值和人数。PDF 为单页且字体已嵌入，JPG 预览的四列、行标签与区间完整可读；三项顺序独立只读审查通过，报告 target 无渲染警告。

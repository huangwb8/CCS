# CCS d1 vs TSP 消融源码优化计划

## 结论先行

`R/ablation.R` 应从“分层 CCS 全流程实验调度器”收敛为“冻结证据层的表征消融器”。核心只回答：

> 相对 CCS 实际使用的 GSClassifier-native TSP 特征空间，d1 怎样重组了样本关系；这种重组在严格跨 cohort、有限样本条件下改善了什么，又牺牲了什么？

本轮最优设计不再用 d2、d3、metaCCS、normCCS 或 ICI response 证明 d1 更好。这些层有各自的科学问题与超参数空间，最多作为后续独立研究，不能进入 d1 必要性的核心证据链。

源码中的主比较应收敛为两个有明确合同的表示：

| 表示 | 精确定义 | 能回答的问题 |
|---|---|---|
| `GSClassifier-TSP` | `GSClassifier::geneMatch()` 后调用原生 `trainDataProc_X()`，再按冻结模型实际使用的 feature manifest 截取完整输入；当前对象为 32 个 single-bin、496 个 gene-pair 和 1 个 set-pair | 不经过 cohort bank 时，CCS 原生 TSP 特征体系本身能做到什么 |
| `Cohort-d1` | 完整冻结 cohort bank 的原始 probability blocks | 当前 d1 的真实收益与代价 |

唯一主要差值是 `Cohort-d1 - GSClassifier-TSP`。496 个普通 gene-pair 列只是完整 GSClassifier 特征合同中的一个 feature type，可用于 manifest 和兼容性审计，但不再作为独立实验组。这样比较的唯一主动改变才是“是否经过冻结 cohort bank”。

本文中的 `GSClassifier-TSP` 是 CCS 项目内对该原生输入体系的简称，不表示 529 列全部属于经典二元 TSP；机器可读 `group_id` 更建议使用无歧义的 `Direct-GSClassifier`。

## 问题是什么

### 科学问题被下游实验稀释

当前 [`ablation()`](../../R/ablation.R) 默认执行 `cohort`、`scaling`、`tissue_first` 和 `metaccs` 四类实验。后面三类实验分别改变 module 子集、UMAP/tissue-first 路径和 DBSCAN 解，回答的是 bank scaling 或下游工程问题。即使 d1 路径最终获得更好的 metaCCS 或 ICI 结果，也无法排除 TSP 路径需要另一套最优降维、聚类或任务头超参数。

这会让最重要的结论——d1 相对 TSP 的机制价值——反而成为整条超参数链中的一个模糊因素。

### TSP 基线必须服从 GSClassifier 原生合同

GSClassifier 0.4.0 的 `trainDataProc_X()` 并不是只生成二元 gene-pair。它依次构建 `Xbinned`、`Xpairs` 和 `Xset`，再合并为模型输入 `Xbin`。因此，CCS 语境中的正式 TSP 路径不能被手工缩减为 496 个 `geneA:geneB` 列。

当前 `R/ablation.R` 的输入路径在这一点上是正确的：

- `.ablation_gsclassifier_matrix()` 调用 `GSClassifier::geneMatch(..., matchmode = "fix")`；
- 通过 `getFromNamespace("trainDataProc_X", "GSClassifier")` 生成原生特征；
- 按冻结 class models 的 `bst$feature_names`，或旧模型的 `genes`，截取实际被消费的完整 feature support；
- 当前真实合同为 529 个特征：32 single-bin、496 gene-pair 和 1 set-pair。

因此，计划必须保留 `prepared$direct` 作为主基线，而不是改用 `prepared$tsp`。后者只负责记录 ordinary gene-pair 子集，不代表 normCCS/CCS 的完整 TSP 计算体系。

数学定义也应以准确输入为准。令

$$
Z_{GSC}=G_{GSC}(E;\,geneSet, breakVec, feature\ manifest),
\qquad d1=F(Z_{GSC}),
$$

其中 $G_{GSC}$ 是版本锁定的 GSClassifier 原生变换。数据处理不等式相对完整的 $Z_{GSC}$ 成立；不能先把它缩成纯二元 gene-pair 子集，再声称该子集就是 d1 的完整输入。

### 默认跨 cohort mixing 指标不可用

默认 `n_folds = Inf` 会形成 leave-one-cohort-out。当前 `.ablation_mixing_purity()` 只在测试折内部找近邻，而测试折只有一个 cohort，因此：

- `cohort_mixing` 默认必然为 0；
- “biology 相同、cohort 不同”的测试折内边不存在；
- `concordant_cross_cohort_rank_change` 默认不可估。

项目 BAC 中已有定向只读验证确认这一点。继续把这些值用于 Gate 或论文会产生错误结论。

### grouped validation 仍未证明 d1 本身无训练暴露

外层按 cohort 划分只能阻止 probe、标准化或调参读取测试 cohort，不能自动证明 `object@Data$Probability$d1` 是对评价样本的 out-of-fold/out-of-cohort 输出。若评价样本参加过对应 cohort module 的训练，d1 可能携带训练记忆。

确认性结论必须先解决 d1 provenance；做不到时只能交付描述性几何，不得把 grouped probe 写成外部泛化证据。

### 当前读出器仍可能偏向某种表示

当前 linear XGBoost probe 固定 `lambda = 1`、固定迭代次数，并在 PCA score 上拟合。两种表示的 score 尺度和最优正则化不同，同一固定超参数并不自动公平；反过来，允许每组任意搜索又会引入不同的研究者自由度。

正确方案是：共享外层 folds、共享内层 grouped-CV、共享模型族、共享候选网格和计算预算，但让每个表示只在训练数据内选择自己的最优正则化参数。

### 其它会影响强结论的实现边界

- `distance` 目前只是审计标签，实际计算始终是 Euclidean，容易让配置与行为不一致。
- `biology` 缺失时静默回退为 `tissue`，不能充当独立生物锚点。
- cohort 内恒定的 tissue/cancer 无法验证 within-cohort `Null-Perm`；当前代码仍可能把这种 Null 纳入 Gate。
- 有限 grouped-fold 的贪心分配已有可复现的不平衡反例；若用于内层调参，需要更可靠的确定性分组策略。
- 约 200 行合成测试嵌在导出函数的 `if (FALSE)` 中，且整个文件膨胀到 3810 行，增加了科学逻辑与下游遗留逻辑互相污染的风险。

## 要达到什么目标

### 完成后的变化

- `ablation()` 默认只运行 d1 表征消融，不再默认触发下游降维、聚类或 ICI 路径。
- 结果能回答“在相同 GSClassifier-native TSP 输入支持下，cohort transformation 是否改善了有限样本跨队列表示”。
- 每项优势都与对应代价成对报告，不生成事后加权的综合冠军分。
- TSP 与 d1 获得相同的调参机会，而不是强迫共用同一最优参数。
- 默认 LOCO 下的跨 cohort 指标真正使用其它 cohort 作为 reference，不再产生恒为 0 的伪 mixing。
- 没有合格的 d1 provenance 或独立锚点时，函数明确降级为 descriptive，不输出 confirmatory pass。
- 所有结论均能追溯到样本、cohort、特征合同、module bank、anchor、fold 和 seed。

### 不在本次核心范围

- 不比较 d2/d3、tissue-first、UMAP、DBSCAN、metaCCS 数量或 normCCS。
- 不使用 ICI response 选择 d1 消融方案；ICI 只属于冻结方案后的独立任务验证。
- 不重新训练 150 个 cohort submodels，不搜索新的 32-gene signature。
- 不证明 d1 “创造了新信息”；只检验它是否改善有限样本下的信息可利用性。
- 不用当前 150 个 module 的 retrospective 子集曲线外推“第 151 个 cohort 必然继续增益”。

## 核心研究设计

### 先冻结唯一主要 estimand

两个表示共享完全相同的样本、原始表达、GSClassifier 版本、`geneMatch`、`geneSet`、`breakVec` 和 frozen feature manifest。唯一主要 estimand 是：

$$
\Delta = S(Cohort\text{-}d1)-S(GSClassifier\text{-}TSP).
$$

源码组名建议从含混的 `Direct` 改为 `GSClassifier-TSP` 或 `Direct-GSClassifier`，并在 manifest 中明确它包含 single-bin、gene-pair 和 set-pair。纯 496 gene-pair 子集不进入主 contrast。

### 数据准入先于指标计算

确认性运行至少要求以下合同：

- `sample_id`、`cohort_id`、`cancer_type/tissue` 完整且一一对齐；有患者级重复风险时增加 `patient_id`。
- `assay_type` 与 `platform_id` 尽量完整，用于平台分层和运输性解释；未知值可以保留，但不支持超出证据粒度的主张。
- 每个生物锚点声明 `anchor_role`：
  - `bank_aligned`：cohort models 已经使用或高度接近其训练目标；
  - `independent`：未用于 d1/metaCCS 构造的样本级标签；
  - `technical`：cohort、assay、platform 等 nuisance 标签。
- 每个样本声明 d1 生成来源：`external_frozen`、`out_of_fold`、`in_sample` 或 `unknown`。
- confirmatory 模式只接受 `external_frozen` 或可审计的 `out_of_fold`；其余模式在输出中强制标为 descriptive。

若缺少独立、且在至少两个 cohort 内有样本级变化的生物锚点，代码仍可描述 d1 怎样改变几何，但不能声称这种改变具有独立生物学价值。

### 第一部分：回答 d1 与 TSP 到底有什么区别

这部分不拟合 task head，直接比较 GSClassifier-native 输入与 d1。特征生成保持原生，但距离预处理需要显式锁定：

- `GSClassifier-TSP` 完整保留 `trainDataProc_X()` 的 single-bin、gene-pair 和 set-pair 数值，不再假定整个矩阵是二元，因此不使用全矩阵 Hamming/Jaccard。
- 主几何方案在 reference/train 边界内对 GSClassifier 特征做列标准化，再使用 Euclidean；gene-pair-only Hamming 只作为 feature-type 敏感性审计。
- `Cohort-d1` 先验证每个 module block 是否为概率单纯形。满足合同时，以 module 等权的 Hellinger 距离作为主距离，防止类别更多、输出更宽的 module 自动获得更大权重。
- 若 d1 block 不满足概率合同，确认性运行应停止；标准化 Euclidean 只能作为显式敏感性方案，不能静默替代。

需要输出的描述性结果：

- GSClassifier-TSP 与 d1 样本距离次序相关；
- 两种表示的 kNN overlap；
- d1 各 module 对总距离的贡献集中度；
- d1 effective rank、block 内冗余和概率熵；
- GSClassifier-TSP-close edges 在 d1 中的名次变化分布。

这些指标只回答“变了多少、怎样变”，不作为 d1 成功与否的单独判据。

### 第二部分：回答 d1 改善了什么

核心改成 held-out-cohort query-to-reference retrieval：

1. 每次完整留出一个 cohort 作为 query。
2. 其它 cohort 构成 reference atlas；所有表示使用同一 query/reference sample IDs。
3. 对每个 query 只在 reference 中找近邻，因此每条边天然跨 cohort。
4. 按 reference 中标签和 cohort 的可获得机会校正，避免大 cohort 或高频类别自然占优。
5. 先计算每个 query 的 paired delta，再以 cohort 为统计单位汇总。

主要效用指标：

- independent anchor 的 top-k retrieval purity、mean reciprocal rank 或 multiclass neighbor vote；
- biology 一致的跨 cohort 邻域保留；
- GSClassifier-TSP-close、biology-discordant edges 被 d1 选择性推远的程度；
- 最差 cohort、稀有 tissue/label 和不同 assay/platform 分层结果。

技术来源的可分性必须与生物保真成对解释。d1 只有在提高跨 cohort 生物检索、同时不抹平 independent anchors 时，才可称为改善；单独提高 mixing 不构成成功。

### 第三部分：回答 d1 是否改善有限样本学习

这是 d1 理论叙事中最关键、也最能避开“信息新增”误解的实验。

- 外层使用 leave-one-cohort-out，测试真正的新 cohort。
- 内层仍按 cohort 分组，只在外层训练数据中选择正则化强度。
- 两种表示使用同一个低容量模型族；优先复用现有 deterministic `xgboost` linear booster，不新增依赖。
- 两种表示共享同一 `lambda` 网格、相同迭代上限、相同 class weighting 规则和相同总计算预算；每种表示可在内层数据中选择自己的最优 `lambda`。
- 标准化、低方差过滤、缺失处理和概率校准全部只在外层训练边界内完成。
- 不再用 PCA rank 作为主比较的额外超参数；若因计算限制需要降维，只能作为预注册敏感性分析。

除全量训练外，还应构建配对学习曲线：固定外层测试 cohort，在训练侧按 cohort 数和样本数的预设档位做重复子采样。报告：

- cohort-macro balanced accuracy、macro AUROC 及概率型指标；
- d1 相对 GSClassifier-TSP 的 paired delta；
- 达到预设性能所需的训练 cohort/样本量；
- 小样本优势是否随样本量增大而消失、保持或反转。

若 d1 只在小样本时更好、随后与 GSClassifier-TSP 收敛，结论应是“改善样本效率/归纳偏置”，而不是“信息更多”。

### 第四部分：回答 d1 妥协了什么

代价至少从三个方向量化：

- **输入信息压缩：**用训练 cohort 拟合低容量 decoder，从 d1 重建完整 GSClassifier-native 输入。gene-pair 使用 balanced accuracy/Brier，single-bin 使用有序一致性，set-pair 使用相关或误差指标；按 feature type 分层汇总哪些输入结构被稳定保留、哪些被系统丢失。
- **生物信号偏向：**分别汇总 bank-aligned 和 independent anchors。若只改善 aligned label，却损伤独立 subtype/pathway 或稀有类别，应解释为任务定向压缩。
- **贡献集中：**检查 d1 距离或 probe 是否主要由少数大 cohort、宽 block 或单一 tissue bank 驱动。此处只做贡献审计，不开启大规模 module 数量搜索。

原始表达扰动、缺失基因和跨平台技术重复需要重新执行冻结 bank。当前函数只读取已生成 d1，第一版不伪造这些结果；待有可审计的 d1 re-encoding/cache 合同后再作为独立 robustness 扩展。

### Null 只保留为诊断，不再决定主结论

- `Null-RP` 可用于确认结果不是任意随机重组就能产生，但不替代 GSClassifier-TSP 与 Cohort-d1 主比较。
- `Null-Perm` 只对 cohort 内实际变化的 sample-level anchor 有效；若 anchor 在 cohort 内恒定，结果应标记 `not_eligible`，不得进入判定规则。
- 增加 within-cohort label permutation，验证 probe/调参流水线没有在无信号时产生系统性假优势。
- 删除当前服务 scaling 的 Gate 1。新的输出只提供预注册 contrast、置信区间、最小重要差异和保护指标，不合成自动冠军。

## 源码改进方向

### 收紧公共入口

推荐让 `ablation()` 默认只运行 `representation`：

- 旧名称 `cohort` 可在一个过渡期映射到 `representation`，并发出清晰 deprecation 提示。
- `scaling`、`tissue_first`、`metaccs` 不再作为默认值。
- 是否彻底删除旧选项属于公共 API 的破坏性决策，实施前由项目负责人决定；在此之前可将遗留实现移出 `R/ablation.R`，放入明确标记 exploratory/legacy 的独立模块，避免继续污染核心实验。

参数结构收敛为：

| 参数域 | 内容 |
|---|---|
| `comparison` | GSClassifier-TSP、Cohort-d1、主 contrast 与原生 feature contract |
| `provenance` | confirmatory/descriptive 模式、d1 训练暴露字段 |
| `anchors` | 主/次生物锚点、角色与最小 cohort 覆盖 |
| `geometry` | TSP/d1 原生距离、k、query/reference 规则 |
| `validation` | 外层 LOCO、内层 grouped-CV、正则网格、学习曲线 |
| `controls` | label permutation、可选 Null-RP/Null-Perm |
| `output` | 覆盖策略、缓存和审计选项 |

删除 `dr`、`cluster`、`metaccs` 和 scaling Gate 配置后，调用者看到的参数将直接对应研究问题。

### 分离职责但不扩张抽象

建议使用最小文件边界：

- `R/ablation.R`：公共函数、配置解析、阶段调度和返回对象；
- `R/ablation-input.R`：两臂 GSClassifier 原生特征合同、样本对齐、provenance 与 manifest；
- `R/ablation-representation.R`：原生距离、query-to-reference retrieval、选择性重构和信息损失；
- `R/ablation-statistics.R`：nested grouped validation、学习曲线、cohort-level paired inference。

若项目负责人希望继续单文件，也应按上述四个职责段落重排；不需要引入注册器、插件系统或新 S4 类。

导出函数内的 `if (FALSE)` 合成夹具移到 `test/ablation/`，源码不再同时承担测试数据生成职责。

### 修正指标与统计单位

- 原生几何不拟合任何全数据 scaler；需要训练参数的步骤必须在 fold 内完成。
- LOCO retrieval 的 reference 为训练 cohorts，不再在单 cohort 测试折内部计算 mixing。
- finite grouped-fold 用确定性、可验证的负载与标签覆盖优化；若只用于 smoke test，可明确标为近似验证，不与 confirmatory LOCO 混用。
- 所有 stochastic repeats 先在 cohort 内平均，再对 cohort 做 paired bootstrap；同时报告 cohort 数和最差 cohort，不把 seed 或 sample 当独立重复。
- 最小重要差异由调用者在看结果前提供；源码不再用 `0` 伪装成领域默认阈值。

### 重建输出合同

建议把 `CCSAblation` manifest schema 升级并保存以下核心结果：

| 输出 | 内容 |
|---|---|
| `manifest.rds` | 两臂特征数/hash、GSClassifier 原生变换合同、module bank、d1 provenance、anchor role、fold 与软件版本 |
| `native_geometry.rds` | 距离相关、kNN overlap、edge transitions、module contribution |
| `retrieval.rds` | query-to-reference 的逐样本与逐 cohort 指标 |
| `readout.rds` | nested-LOCO 预测、内层所选超参数和两组配对差值 |
| `learning_curve.rds` | 每个训练规模、重复、外层 cohort 的性能与不确定性 |
| `tradeoffs.rds` | 按 feature type 的 GSClassifier 输入保留、anchor 分层、稀有组与贡献集中度 |
| `audit.csv` | 输入合同、资格状态、随机索引、metric 与 contrast 的长表 |

不再生成 d3、cluster assignments 或 metaCCS parameter-grid 结果。返回对象必须显式包含 `evidence_level = confirmatory/descriptive` 及降级原因。

## 实施范围与顺序

1. **先锁定科学与数据合同。**把 `GSClassifier-TSP`、`Cohort-d1` 两组命名、完整原生 feature support、GSClassifier 版本/变换函数、d1 provenance 和 anchor role 写入 manifest；更新 `d1 = F(Z_{GSC})` 的准确边界。
2. **保留正确输入路径并修正指标硬错误。**继续使用 `prepared$direct`，禁止把 `prepared$tsp` 提升为主实验组；重写 LOCO query/reference 指标，移除不可用的默认 mixing、伪 distance switch和不合格 Null-Perm Gate。
3. **实现无下游超参数的原生表征比较。**加入完整 GSClassifier-TSP 的混合特征距离、d1 等权 block 距离、选择性邻域重构和贡献集中度；gene-pair Hamming 仅保留为分层敏感性审计。
4. **实现等调参预算的受限读出。**建立外层 LOCO、内层 grouped-CV 和 representation-specific 正则选择；保存每折选择记录。
5. **加入配对学习曲线与代价审计。**以相同训练 cohort/样本子集比较两组，并增加按 feature type 的输入保留、独立 anchor、稀有组和最差 cohort 结果。
6. **最后缩减遗留代码与同步文档。**把下游实验从默认入口移出，迁移内嵌夹具，更新 roxygen/Rd、`test/ablation/ablation.md`、相关计划与 `CHANGELOG.md` 的 `[Unreleased]`；不修改项目版本号。

## 如何确认完成

### 科学验收

- 结果给出唯一主要差值 `Cohort-d1 - GSClassifier-TSP`，并按 feature type 审计输入构成与信息保留。
- 默认分析完全不读取 d2/d3/metaCCS/normCCS/ICI response。
- 每个优势指标都有保护或代价指标；不存在单一加权总分。
- confirmatory 结果只来自合格 provenance 和独立 anchor；不合格输入会降级或早返回。
- 学习曲线能区分“低样本归纳偏置”与“信息上限更高”两种解释。

### 代码与场景测试

- 真实合同测试确认 GSClassifier 0.4.0 的 529 维完整输入由 32 single-bin、496 gene-pair 和 1 set-pair 组成，并与冻结模型的 `dataProc()` 实际输入列一致。
- 构造 LOCO 夹具，确认 query 只在其它 cohort 的 reference 中找邻居，跨 cohort 指标有限且不再恒为 0。
- 构造 cohort 内恒定 anchor，确认 Null-Perm 自动 `not_eligible`；构造样本级变化 anchor，确认置乱会破坏对应关系。
- 构造 provenance 为 `in_sample/unknown` 的输入，确认 confirmatory 模式拒绝或降级。
- 构造“d1 去除 cohort 噪声并保留 biology”的数据，确认收益被检出；再构造“d1 过度平滑、损伤稀有 biology”的数据，确认代价被检出。
- 核对两组共享外层 folds、训练子集、lambda grid 与计算预算，但允许各自在内层选择不同 lambda。
- 修改 held-out cohort 的标签或分布不能改变训练折 scaler、调参或 feature filter。
- 相同 seed 的完整结果可复现；不同 seed 的审计索引可区分。

## 结果怎样解释

| 真实结果模式 | 允许的结论 |
|---|---|
| d1 优于 GSClassifier-TSP，独立 anchor、稀有组和最差 cohort 无重要损伤，小样本增益明显 | 支持 cohort bank 在相同原生输入上提供有用的跨队列归纳偏置和样本效率改善 |
| d1 只改善 bank-aligned label，却损伤 independent anchor 或稀有组 | d1 是有方向的信息压缩；必须公开其适用范围和代价 |
| d1 与 GSClassifier-TSP 等价 | cohort bank 未显示足以抵偿复杂度的净收益；按 KISS 优先更简单的 GSClassifier-native 表示 |
| d1 更差，或表现接近随机/置乱对照 | 当前 cohort bank 的压缩或重权重损失超过收益，应收紧 CCS 核心主张 |
| provenance 不明或评价样本参与 bank 训练 | 只能报告描述性几何，不能写跨 cohort 泛化或 d1 必要性结论 |

## 风险与待确认事项

- **最关键前置条件：**是否存在可证明未参与 cohort bank 训练的评价样本，或可恢复严格 OOF d1。若没有，确认性实验无法成立。
- **独立锚点：**若现有 metadata 只有 tissue，而 tissue 与 cohort 高度绑定，最多能验证 bank-aligned 结构；需要至少一种跨 cohort、样本级变化且未参与 d1 构造的 biological anchor。
- **d1 block 合同：**实施前确认每个 block 是概率向量、是否按行和为 1，以及类别宽度是否一致；这决定 Hellinger 主距离是否可用。
- **公共 API：**移除 `scaling/tissue_first/metaccs` 是破坏性变化。推荐先取消默认执行并移出核心文件，彻底删除的版本与时间由项目负责人决定。
- **GSClassifier 版本合同：**`trainDataProc_X()` 与 `dataProc()` 都是当前真实预测链的一部分，且前者通过非导出接口访问；必须记录 GSClassifier 版本、`breakVec`、feature manifest 和函数体 hash，并用契约测试防止包升级后静默漂移。
- **计算量：**按 feature type 重建完整 GSClassifier 输入和执行 LOCO 学习曲线可能昂贵，应使用缓存和预注册训练规模；不能为了省时改用会泄漏的全数据预处理。

## 方法学依据

- CCS 的直接输入合同以本地安装的 GSClassifier 0.4.0 `trainDataProc_X()` / `dataProc()` 及冻结模型 feature manifest 为事实来源；经典 TSP 文献只解释其中 gene-pair 组成，不覆盖 single-bin 和 set-pair。
- TSP 的单样本相对表达基础与小样本解释性：[Geman et al., 2004](https://doi.org/10.2202/1544-6115.1071)。
- 多研究 TSP 需要真正的 cross-study validation：[Kim et al., 2016](https://doi.org/10.1093/bioinformatics/btw115)。
- 常规同研究 CV 可能高估跨研究预测并改变算法排序：[Bernau et al., 2014](https://doi.org/10.1093/bioinformatics/btu279)。
- 分子分类器内部 CV 与独立验证之间存在系统落差：[Castaldi et al., 2011](https://doi.org/10.1093/bib/bbq073)。
- 存在层级结构时应按预测目标做 blocked/grouped validation：[Roberts et al., 2017](https://doi.org/10.1111/ecog.02881)。
- 学习曲线应同时报告训练样本效率与测试不确定性：[Beleites et al., 2013](https://doi.org/10.1016/j.aca.2012.11.007)。
- batch removal 必须与 biological conservation 联合评价：[Luecken et al., 2022](https://doi.org/10.1038/s41592-021-01336-8)；[Büttner et al., 2019](https://doi.org/10.1038/s41592-018-0254-1)。
- d1 provenance、折内预处理和嵌套调参必须显式审计以避免 leakage：[Kapoor and Narayanan, 2023](https://doi.org/10.1016/j.patter.2023.100804)。

# normCCS 论文口径延伸分析实施计划

## 问题与目标

原论文只探索将 CCS 状态合并为 2–4 个等级，本次要在相同样本和评分口径下判断，增加到 5–12 级是否改善队列 AUC。现有 premium 分析额外筛除了治疗后样本、重复测量、来源重叠和非 ICI 队列，并使用自定义搜索；这些结果回答的问题与论文延伸不同，其定义与历史记录单独保留，被替代的旧产物按负责人后续授权清理。

## 输入与方法

只读解析两份历史脚本，核对四个 PanIMT/CDSDB 输入、22 个开发队列及 9 个外部队列、response.classic 和历史配色。固定模型 5ff3a2de76e6cf902e765e8224f9cb66，沿用 PADv20250720 模型对象与 PADv20240911 底层目录，不训练模型或 scaller。重建历史逐队列 inner_join 和缺失／可计算性筛选；额外筛选只用于差异审计。

冻结预测只有在原始表达、模型、预测参数和样本对应均获得证据支持时复用。若无法证明一致，通过正式 DAG 重新预测，绝不执行历史脚本的写入或训练段。

统一调用 CCS::subtypePerformance：OptimizeRank、NRR、median、DL，cohort_level 使用完整历史名单。K=2–4 完整穷举并另跑 DP；K=5–12 运行 DP。DP 固定单核；穷举核心数通过资源试运行确定，同时仅运行一个搜索任务，保留 crew 和 autometric 监测。

## 实施顺序

1. 在现有 `_targets.R` 增加 `paper_` 分支和独立产物目录，保留旧分析定义及仍被复用的依赖；文件依赖覆盖历史脚本、原始输入、冻结预测核对证据及包内实现。
2. 重建历史 df2，保存输入一致性、样本流程、逐队列计数和旧筛选影响。轻量数据通过同一 DAG 验证筛选、全部候选导出、映射规范化、评分和报告生成。
3. 正式资源试运行后固定 brute_cores，完成 K=2–12 主分析及 K=2–4 DP 对照。Raw、Summary、SearchDiagnostics 原样保存；穷举保存全部候选，DP 保存实际返回的全部候选。
4. 按 Info 计算开发中位数（排除 All 与外部）、外部中位数及四个重点队列 AUC；分别按内部目标和历史探索性排序比较 K=4。比较所有并列最优映射和逐队列 AUC，规范化等级内成员顺序，不把后处理指标冒充 DP 目标。
5. 生成 HTML、CSV、完整状态成员、搜索诊断和执行证据，经过结构／恢复／科学口径串行检查及 humanization 表达润色后，通过正式 targets 入口更新报告。

## 验收与解释边界

正式入口为 `test/normCCS-premium/_targets.R`，R 使用 `C:/R/R-4.3.1`，tar_make 与 tar_watch 指向同一 store。轻量测试使用独立 store 和输出目录；完成后检查正式 targets 的错误、产物、增量复用和原始输入哈希。

K=2–4 最优结果来自完整连续归并穷举；K≥5 仅代表 DP 已找到的候选，不保证 OptimizeRank/median 全局最优。内部目标包含 pooled All，历史开发中位数不包含 All 和外部队列。外部队列参与搜索评价及历史筛选，结果属于探索性评价；本次描述性 AUC 和 K 差值不构成独立验证或未经预设的显著性检验，不伪造置信区间。原始逐队列 AUC 区间若包内提供则完整导出。

原始文件和包版本保持不变。根据负责人随后授权，新结果验收后已清理被本次分析替代的旧 HTML、图表、汇总表和失败测试现场，共 720 个文件，并同步修正文档链接；仍被本次分析复用的冻结预测、模型快照与核对证据保留。既有 targets 定义未删除或降级。行为和流程变更记录在 CHANGELOG 的 Unreleased，协作证据通过 BAC 命令记录并验证。

正式结果及验收见 [论文延伸验收说明](../../test/normCCS-premium/paper-verification.md)。

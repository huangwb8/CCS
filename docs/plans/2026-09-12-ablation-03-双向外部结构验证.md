# ablation-03 双向外部结构验证实施计划

## 通俗解释：究竟发生了什么

- **一句话说明：** 当前报告只让 reference cohort 模型去观察 external cohort 样本；新增分析会把方向反过来，再让 external cohort 模型观察 reference cohort 样本，从两个方向检查 d1 是否保留可复现的生物结构。
- **具体场景：** 这像两组医院互相盲评病例。现在只有 A 组医生评阅 B 组病例；改进后还会让 B 组医生评阅 A 组病例。医生对应 cohort-specific module，病例对应目标 cohort 样本，评阅结果对应 d1 坐标。
- **改变前后：** 当前只能判断 reference bank 对 external 样本的外部投影；改进后可以区分观察到的结果是 d1 的一般性质，还是由某一侧 bank 的规模、组织覆盖或模型构成造成。

## 专业判断：问题在哪里

- **当前现象：** 现有结构分析仅计算 150 个 reference modules 到 external targets 的正向投影。完整 d1 同时保存 43 个 external modules 对所有可用样本的输出，因此反向投影在数据上可行，但尚未纳入分析。
- **证据边界：** externality 应定义为目标样本是否参与所用 module 的训练，而不是固定的数据集名称。正向 `reference bank → external targets` 与反向 `external bank → reference targets` 都属于 bank–target 不重叠的外部投影。
- **已知约束：** 193 个 modules 的 tissue 均可由既有审计映射确定；45 个历史 `Undefined` 标签全部可恢复。两侧 bank 规模为 150 对 43，且只有 22 个 modules 能在共同 tissue 内无放回一一匹配，因此不能把两个完整方向的差异直接归因于投影方向。
- **数据完整性风险：** 完整表达数据有 39,112 个样本，完整 d1 有 38,818 个样本；反向计算必须显式记录共同样本边界。现有 expression-anchor cache 只覆盖 query 与被检索到的 reference 邻居，不能作为反向分析的完整 reference 目标样本池。

## 要达到什么目标

- 保留现有正向 external–external 结构分析及兼容产物。
- 新增反向 external-bank → reference-target 结构分析，并分别报告 Direct 与 d1 的跨队列结构相似度及 d1−Direct 差。
- 新增共同 tissue 上的 22 对 22 module-bank 重复匹配敏感性分析，明确其为 bank 构成范围而非置信区间。
- 使用完整共同样本构建结构分析专用 anchor 子集；正向由 reference 样本拟合尺度，反向由 external 样本拟合尺度。
- 更新 Rmd、README、`CHANGELOG.md`、机器可读产物、回归测试和 HTML，不修改项目版本号。

## 改进方向

### 建立双向、互不重叠的 bank–target 合同

完整 d1 的 modules 按审计后的 cohort key 划分为 reference bank 和 external bank。正向继续使用 reference bank 观察 external targets；反向使用 external bank 观察 reference targets。每个方向的 Direct 与 d1 标准化都只在 bank 一侧拟合，再应用到 target 一侧，避免目标数据参与尺度估计。

### 使用完整结构分析样本而非邻居子集

从已加载的完整表达 atlas 中仅提取四个 anchor 所需基因，并限制到 Direct/d1 共同样本。各方向分别用 bank 侧样本拟合 gene-wise 标准化，再在 target cohort 内定义高低三分位实体。现有 biology cache 继续服务原有邻居 utility，不改变其合同。

### 分离完整 bank 结果与公平匹配敏感性

完整方向回答各自真实 bank 的外部投影能力；共同 tissue 的 22 对 22 重复匹配用于观察 bank 容量和组织构成变化是否改变 d1−Direct 的方向。两者分别汇总，不把匹配重复范围写成统计置信区间，也不把两个方向强行合并成一个总体效应。

### 让报告能够审计方向与样本边界

机器可读结果记录方向、bank/target 角色、module 数、d1 列数、拟合和目标样本数、有效 cohort 数及 module/sample hashes。Rmd 增加双向结果表和图，解释“互为 external”的含义、完整 bank 的不对称性、匹配敏感性的边界，并继续保留当前地图类比与原始热图。

## 实施范围与顺序

1. 扩展 Stage 04 helper：解析 module tissue、划分 bank、构建完整 anchor 子集、执行方向化结构比较并生成匹配 bank 设计。
2. 扩展 Stage 04 主脚本：计算正向、反向和匹配敏感性，保留旧产物并新增方向化结果。
3. 扩展 24 号回归测试，覆盖 tissue 恢复、bank 不重叠、方向元数据和 22 对 22 匹配合同。
4. 更新报告、README 与 `[Unreleased]`，运行完整 Stage 04 后重新渲染 HTML，并检查新图及机器可读结果。

## 如何确认完成

- 43 个 external modules 和 150 个 reference modules 均被唯一、无遗漏地分配，训练 bank 与目标 cohort 集合的交集为零。
- 正向和反向结果均存在，且每个方向的 Direct/d1 使用完全相同的 target 样本与实体。
- 反向结果只使用完整 d1 中存在的共同样本，并输出排除样本审计。
- 每个匹配重复在两侧各含 22 个 modules，逐 tissue 计数完全一致；结果明确标记为 design sensitivity。
- `Rscript test/ablation-03/tests/24-test-structural-reproducibility.R`、Rmd 静态门禁、HTML 渲染和 BAC 验证通过。
- 新增图以矢量 PDF 交付并由同源 JPG 进行视觉检查；HTML 确实包含双向解释和动态结果。

## 风险与待确认事项

- external modules 曾被排除在当前生产 reference bank 外，反向方向用于检验表示的互惠性和 bank 依赖，不自动等价于生产模型的外部验证。
- 完整方向的 150 对 43 module 数和 tissue 覆盖不同；方向间数值差异必须结合匹配敏感性解释。
- 共同 tissue 匹配只能覆盖 22 个 modules，不能代表 external bank 中缺少 reference 对应 tissue 的 21 个 modules。
- 若反向有效 target cohort 数不足以支持稳定 node bootstrap，应保留完整结果并将相应推断标为不可估计，而不是降低预设实体门槛。

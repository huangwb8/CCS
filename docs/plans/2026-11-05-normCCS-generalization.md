# normCCS 完整泛化流程实施计划

## 要解决的问题

当前 normCCS 会根据输入结局学习状态顺序和等级分界。如果在同一批患者上报告搜索后的最高 AUC，就把学习成绩当成了新患者预测成绩。已有稀疏等级惩罚只能约束分界，不能消除排序和择优造成的偏差。

本次完整实现训练、应用、评价与验证接口。新患者只接受训练侧冻结的映射；测试结局只进入最终评价。旧接口及其 ROC 语义保持兼容，版本保持 0.8.9。

## 接口与科学边界

新增 `fitNormCCS()`、`predict.normCCSFit()`、`evaluateNormCCS()` 和 `validateNormCCS()`。拟合对象保存冻结排序、映射、固定方向、超参数、等级支持和输入身份摘要，不保存患者表达或逐记录结局。

按当前源码整理要求，以上接口、内部辅助函数及精确搜索适配统一放在 `R/phenotype.R` 底部，不再单独设置 R 层模块；原生桥接仍由 `R/RcppExports.R` 承担。

新拟合流程在固定方向下完整搜索 K=2–8 的连续分段，使用既有 C++ 内核；增加独立的可选区间资格矩阵，不改变旧搜索。等级支持包含人数、正负事件数和独立来源数；状态排序提供向队列基线收缩的可调强度。未见状态返回 NA 并报告覆盖率，不能利用测试数据补映射。

嵌套验证按独立来源划分，患者标识必须全局唯一，来源别名由调用方预先统一。每个内层训练折重新学习排序和映射，外层测试不参与选型。候选须在所有内层折可拟合且达到预设覆盖率，按来源等权固定方向 AUC 选型，提供最佳得分及 one-SE 规则。来源不足或无合法方案明确失败，不自动降级为随机患者划分。

诊断覆盖逐来源表现、等级支持、跨折状态排序及等级归属稳定性、同来源内结局置换后的完整嵌套流程。置换保留固定折设计，每次重新选型；报告有效次数、失败和置换交换性限制，不删去失败后伪造完整检验。

## 实施与验证

实现上述全部能力及轻量离线示例，同步双语 README、roxygen、CHANGELOG 和用途文档。测试覆盖独立逐记录 AUC 与完整小空间穷举、支持约束、冻结与序列化、结局扰动隔离、按来源隔离、每折重新排序、未见状态覆盖、无合法解、置换复现及 RNG 恢复，另对旧内核做回归比较。

Windows 使用 R 4.3.1；编译、包库、构建、检查、模拟和日志统一写入 `D:/cache/ccs/normCCS-generalization/`。不运行真实患者分析，不变更既有 targets 流程。不承诺外部 AUC 提升；用合成独立测试衡量行为和科学边界。交付前复核文档表达、包检查及 BAC 哈希链。

# ablation-03 邻居重叠图展示与模块距离解读优化

## 目标与范围

原邻居 Jaccard 图左右分面共用纵轴，全癌种仅有不限制技术来源的实验，造成左面板
大量空行。改为上下分组的横向点图，仅给实际有结果的条件分配高度，并明确队列数
及描述性汇总。只修改生物锚点报告的展示代码及相应文档；不调整科学计算、候选池、
测量门槛、检索规则或版本号。

## 数据与展示

- 消费正式 `biology_diagnostic_inference` 中已有的 `neighbor_summary`。
- 全癌种 43 个队列；同癌种不限制、同检测类型及同来源分别为 17、10、5 个队列。
- 各队列均值以小点表示，队列中位数以菱形表示，Q1–Q3 以短横线表示；
  范围为队列间描述性分布，不是置信区间。
- 两组共用 [0,1] 横轴，标注实际队列数及中位数 [Q1, Q3]，不为未设置或无支持条件补零。
- 不同条件的有效队列／患者集合不同，不能把组间位置之差解释为配对改善。

## 执行与验证

用户追加模块距离集中度图解读需求：保留现有曲线与科学份额，在报告中补充模块、
横纵轴和对角参照的直观解释，从同源份额动态汇总前 10% 与累计一半距离所需模块数，
区分组织预设等权、实际模块贡献及生物学表现。该追加不触发科学重算。

正式入口为 `test/ablation-03/_targets.R`，沿项目 launcher 执行 `tar_make()`。
运行前检查正式 store 的失效集合及科学节点 metadata；只允许报告来源及生物报告
因本次修改失效。运行后核对科学节点未重算、聚合表数值不变，并视觉检查 PDF/JPG
中的空行、文字裁剪、字体及所有队列点。无需为纯展示修改重跑训练或包检查。

按 `bensz-rmd-rules` 对结构／数据流、R／恢复及科学／统计依次作只读独立审查。
通用 checker 对本项目既有包内 R 计算层和 `targets/` wiring 提示非 R-first；
本次保持既有项目结构，不迁移 DAG。

## 验证结果

三轮串行独立审查通过。结构审查发现新增解读在空贡献时引用未定义对象，已改为
显式空结果说明并跳过表格；R／恢复及科学／统计审查针对修正后版本通过。
Rmd 抽取代码语法解析、`git diff --check` 与项目 R 4.3.1／renv／CCS 0.8.4 检查通过。

正式 launcher 调用同一 `_targets.R`，22.1 秒完成：2 执行、52 跳过，退出 0。
运行后 `tar_outdated()` 为 0；116 条非报告 metadata（包括科学节点和动态分支）
与运行前完全一致，33 张已有聚合 CSV 的 SHA256 不变。新版邻居 PDF／JPG 已视觉
核对：无空类别、标签裁剪或文字遮挡，保留全部队列点及 [0,1] 标尺。

新增 HTML 解读及表格显示完整，数字与同源结果一致：基线前 15 个模块贡献
16.9%／17.1%，组织等权贡献 51.2%／55.5%；累计一半距离分别需要 56／55 和
15／12 个模块。集中度曲线未改。其余九张 PDF 重渲染仅日期元数据变化，已核对
内容一致并恢复原字节。

证据位于 `.bensz-api/task-20261005-2120-neighbor-plot/shared/`，包含 preflight、
正式执行、metadata 前后比较、聚合表／PDF 核验、三轮审查摘要与图预览。
本次仅改展示及解释，未重跑训练、科学推断或包检查；版本保持 0.8.4。

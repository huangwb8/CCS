# normCCS-premium：各 K 优秀组合与训练、外部 ICI 表现优化计划

日期：2026-10-30。状态：已实施并完成正式全量计算；执行与验收证据见[验证说明](../../test/normCCS-premium/verification.md)。

本计划调整[原分析计划](2026-10-29-normCCS-premium-analysis-plan.md)的中心任务：**对每个 K，找出训练 ICI cohorts 中表现最好的一个或若干具体组合，明确组合成员，并逐一展示它们在训练及外部 ICI cohorts 中的表现。**等级稳定性、概率校准、DCA 和默认 K 推荐作为补充，不作为主交付的前置条件。既有分析与来源记录继续保留。

## 究竟要改变什么

以 K=8 为例，读者最需要看到的是：哪几个 metaCCS 被放进了同一级；这个八级组合为什么在训练数据中排在前面；训练各队列 AUC 是多少；应用到鼻咽癌、肺癌、胃癌和默克尔细胞癌队列后，表现分别如何。如果还有训练表现接近、成员构成不同的组合，也应一起看到。

当前报告主要沿 K 和目标函数展示首选映射的性能曲线，随后强调支持、稳定性和嵌套验证。具体组合与训练表现没有成为阅读主线。改进后，报告开头就是“每个 K 的优秀组合及其训练—外部表现”总表，读者可以从任意一行直接展开完整映射与逐队列结果。

本计划现已落实到分析专用搜索、候选评价和新主报告。正式流程保留原五目标、来源验证与稳定性分支，包版本不变。

## 现状与需要纠正的判断

已有实现并没有混合全部组合求平均：`R/search.R` 仅用开发数据搜索，取 `fit$Summary$Info[1]`，再固定到外部评价。55 个配置是 11 个 K 与五种目标的交叉，每个配置只评价一个首选映射。bootstrap 区间是固定映射的性能不确定性，不是全部组合的性能分布。

真正影响中心任务的缺口是：

- **候选保留不足。**少量返回候选虽已缓存，正式流程没有系统评价各 K 的多个训练优秀组合；旧搜索也不足以提供完整的近优候选集合。
- **“最优”的范围不清。**现有搜索先按 NRR 排序，再做连续分段；整体采用多初值和局部精修，没有证明任意归并下的全局最优。
- **合理性检查在选择之后。**先取最高分组合，再检查样本支持；首选不满足条件时，没有另外求解满足条件的最佳组合。
- **报告缺少组合身份和训练结果的直接联结。**只看外部 AUC 曲线，无法回答“究竟是哪种组合好”。
- **队列角色不足以定义 ICI 资格。**当前配置按训练名单分配开发角色，其余默认外部；其中可见 `GSE35640_MAGE-A3_melanoma`、`Lauss2017_ACT_Melanoma` 等治疗标签。实施前必须按治疗机制核对，不能把所有免疫治疗或所有外部队列都自动当作 ICI。

此前“增加等级没有收益”的结论应收窄为：现有受限搜索选出的那些映射，尚未形成一致外部收益。首选映射不受支持，不能推出同 K 下不存在合理且优秀的其他组合。

## 完成后必须交付的中心结果

主表按 K=2–12 排列，每个 K 至少提供训练排名第一的组合；默认展开前 5 个优秀候选。候选不足时保留实际数量，不能复制或放宽规则凑数。

| 信息 | 主表及其展开内容 |
| --- | --- |
| 组合身份 | K、稳定的组合 ID、完整 metaCCS→等级映射、搜索范围、训练排名、候选来源 |
| 训练表现 | 真实训练 ICI 队列等权平均 AUC、逐队列 AUC、下尾 AUC、相对同范围最佳分的差值 |
| 分组构成 | 各等级包含的状态、测量人数、应答与非应答数、应答率、来源组数 |
| 合理性 | 无约束或满足支持约束、具体未通过项；不把后验检查结果当作可行性证明 |
| 外部表现 | 各外部 ICI 队列 AUC、95% CI、可评价人数、事件数、覆盖率及相对四级的配对 ΔAUC |
| 搜索证据 | 精确解或当前最好已找到解、搜索预算、实际完成量、候选截断状态 |

重点外部队列仍为 LSY01_PD1+CTLA4_NPC、LSY01_PD1+CTLA4_LUNG、Kim2018_PD1_STAD、Zachary2024_MultiICI_MKCC；其他符合资格的外部 ICI 队列完整导出。主表必须同时展示训练和外部表现，不能只展示映射字符串，也不能只展示 AUC。

## 改进方向

### 先固定状态与 ICI 队列的定义

确认用户所称 metaCCS 与当前预测对象中 `CCS` 字段及模型状态字典的对应关系，明确本次被归并的状态全集。训练中出现的状态数按新的 ICI 资格与样本清理结果重新核对，不能直接沿用旧结果中的 98 个状态。

增加明确的队列资格表，记录治疗方案、ICI 类型、单药或联合、开发或外部角色、来源组及纳入依据。主分析纳入含免疫检查点抑制剂的方案；疫苗、ACT 及其它非 ICI 治疗放入单列的补充分析，不进入主训练目标。治疗资格存疑的队列先标为待核对，不能凭队列名称静默决定。

继续保留现有基线测量、重复样本及来源重叠检查。Zachary 总队列与药物子队列分别报告，不能相加为独立证据。未知状态不使用外部结局补排，覆盖率与条件性能同时给出。

### 用明确、同方向的训练目标选组合

主目标固定为真实训练 ICI 队列的等权平均 AUC，排除 pooled `All`。所有队列采用相同方向：“等级越高，预测应答越高”；训练评分、候选排序和外部评价完全一致，不沿用逐队列自动翻转方向。

训练成绩直接回答拟合后的组合在训练数据中表现如何，标为训练内描述，不称为无偏泛化估计。主表不为这些被优化过的训练得分套用普通患者 bootstrap 区间。来源组验证另列，避免替代用户首先需要的训练成绩。

`mean_lower_tail` 作为优先的稳健性补充，帮助识别均值较高但个别队列表现很差的组合；其余三种原目标保留原有结果和必要补充，不再将五条曲线等量铺成报告主线。不同目标的分数不直接比较。

### 同时寻找最高分组合与满足支持条件的优秀组合

每个 K 保留两条候选序列，均在查看新增外部结果前生成并冻结：

- **训练最高分序列：**只要求恰好 K 个非空等级及合法映射，展示该搜索范围内的性能上限与其支持代价。
- **支持约束序列：**在搜索过程中要求每级达到既有开发支持标准：至少 20 人且达到训练人数的 1%，应答与非应答各至少 5 人，至少 3 个来源组。阈值是操作标准，不解释为临床有效性的界线。

支持条件随新训练集合重新计算，并直接限制候选生成。最高分方案不受支持时，继续报告受约束序列的最佳方案及其得分损失，不能直接宣布该 K 无用。95% 映射覆盖另列为应用检查，不用训练覆盖代替外部覆盖。

每个搜索范围、每条序列默认保存训练前 20 个不同映射；报告默认展示前 5 个，另标记与第一名平均 AUC 差不超过 0.01 的近优候选。0.01 仅是展示近似程度的操作定义。第 20 名仍落在近优范围或存在未收全并列时，标明截断；不能称为全部近优组合。完全相同映射跨序列合并展示，但保留全部来源及排名。

排名按主目标降序；数值并列使用固定精度规则，再以训练下尾 AUC 和规范化映射字符串确定展示顺序。所有判据只读取训练数据，保留并列标记，不能因为并列处理隐藏同分但成员不同的方案。保存数量和展示数量分别配置；近优阈值不用于排除另一个序列的最佳方案。

### 连续分段提供精确基线，非连续归并检验搜索限制

NRR 顺序不应被默认等同于用户允许的全部组合空间。因此分两层开展，结果分开标记。

**连续分段层：**训练数据确定 NRR 顺序，固定方向、队列等权平均 AUC 可写为各分段损失之和。基于每个队列的状态应答与非应答计数，扩展为保留多条路径的动态规划，分别求无支持约束和有支持约束的前 20 个分段方案。支持约束对应区间是否可用，进入转移过程。小规模穷举核对通过后，可以称为“给定训练顺序和目标下的精确前列解”。

**非连续归并层：**以连续分段前列解和固定训练随机种子生成的不同初值为起点，允许跨段状态迁移及状态交换，始终保持 K 个非空等级；受约束序列的移动还须满足支持条件。采用主训练目标评分，保留最好已找到的不同映射及搜索轨迹。开发训练内确定等级方向，外部不重排。初始预算建议每个 K、每条序列最多 20 个起点、每起点最多 100 轮完整邻域扫描，无严格改善则提前停止；真实训练小规模试运行后，只依据成本和训练收敛记录一次性固定正式预算。

非连续搜索用于检验连续顺序是否遗漏优秀归并，不声称任意归并下已证明全局最优。输出各起点最好值、改善幅度、预算是否耗尽及精确小问题差距；不能仅因多个起点收敛就改标为精确解。若后续确需全局最优证明，再单独评估整数优化求解器，不将新增求解器与环境改造设为本轮主结果的前置条件。

两层分别给排名，再合并成训练候选总表。主表必须让读者看见某个更宽泛归并是否真正超过连续分段基线，以及提升对应什么成员变化。

### 固定训练候选后，完整展示外部 ICI 表现

训练候选清单包括组合 ID、训练排名、完整映射、适用状态及评分定义；外部评价只能读取这份清单，不能在评价函数中重新搜索、调切点或翻转方向。相同训练候选清单应用于全部合格外部 ICI 队列。

主表按训练排名组织，重点队列并排展示。可以增加外部综合视图，帮助查找“训练优秀、外部也表现较好”的组合，但仍保留所有入围候选及训练原排名，不只留下外部最高的一行。若据外部结果推荐组合，明确这是既有外部数据上的探索性筛选，推荐原因与每个队列的实际表现一同报告，不将所用数据重新称为未参与选择的最终验证集。

逐队列 AUC 与配对 ΔAUC 继续使用 1000 次结局分层患者 bootstrap，共用索引并保留共同患者分母。区间以固定训练映射为条件，不包含候选搜索和外部再筛选的不确定性。本轮以性能估计和完整展示为主，不新增逐格显著性检验。

每条主要候选与本轮同训练口径得到的四级基线比较；每个候选的基线 ID 及共同人数必须明确。旧历史四级单列。新增 ICI 资格或评分口径改变后，不能拿旧四级分数冒充同条件对照。

### 围绕组合重写报告

正式报告主体按以下阅读顺序组织：

1. **各 K 的主结果总表：**训练第一名、最佳受支持方案与前列替代方案，训练和四个重点外部结果同屏出现。
2. **具体组合怎么分：**状态—等级对应表或热图，展示最优及近优组合的成员差别；各等级列出训练人数和应答率。
3. **训练与外部表现：**训练逐队列矩阵及外部候选×队列热图；点开候选查看 AUC 区间、覆盖和配对差，不能用排名代替实际数值。
4. **按 K 作科学判断：**增加等级提高了多少训练表现、外部是否保持、受支持方案损失多大、连续限制是否影响搜索；允许不同 K 各有优点，不强行归结为一个默认 K。
5. **补充结果：**固定 K 的来源组验证、必要的映射稳定性、校准和 DCA。保留已有分支和历史证据，明确哪些结果对应旧训练集合或旧目标，避免混用。

最终主要图表与表格集中到 `test/normCCS-premium/final/reports/`，报告仍位于分析目录。新增核心表建议为 `best_mappings.csv`、`mapping_members.csv`、`training_performance.csv`、`external_performance.csv` 和 `search_diagnostics.csv`，统一由组合 ID 关联。只含汇总与状态映射，不把患者级信息嵌入 HTML 或 Git。

## 执行与缓存约定

继续通过现有 `_targets.R`、R 4.3.1、renv 及 `D:/cache/ccs/normCCS-premium/targets` 执行。新增 ICI 资格→训练计数→按 K 搜索→训练候选清单→候选预测→外部评价→主报告的依赖链；使用候选 ID 或列表分支表达多个组合，不另写 runner 或 checkpoint。

保留现有 targets 分支，不删除或降级既有来源验证、稳定性及正式验收。增设面向中心结果的主报告 target，可先通过 `tar_make(names = ...)` 完成核心交付，既有全流程仍保留；更新验收规则，使新核心目标成为必要项，旧辅助结果标明对应的分析口径。

冻结表达预测与 150 个模块在输入、模型及推理代码身份仍相同时复用。ICI 子集与候选策略变化，从队列资格和映射层开始失效；不把无关候选 helper 的变化接到昂贵推理依赖上，也不绕过真正影响预测的指纹检查。新评分或新训练集合对应的旧搜索、候选排序和验证数值不能直接复用。

正式计算均由 `tar_make()` 驱动，`tar_watch()` 指向同一正式 store；target 级并行仍使用 crew，主进程和 worker 日志、资源指标继续写正式 cache root 的 `observability/`。保留 Windows 启动前线程限制与逐模块退出措施。中间诊断归入本任务既有 `.bensz-api` 根目录，科学缓存不迁入任务工作区。

## 如何确认完成

验收首先检查用户能否直接回答：**K=2 到 12，各自训练最好的是哪个或哪些组合，它们具体怎么分，训练表现多少，外部 ICI 表现多少？**以下条件必须同时满足：

- 每个 K 都有最高分候选及受支持候选的明确状态；不足、不可行或未找到时分别说明，不能用一个失败方案证明全空间不可行。
- 小规模合成问题分别核对无约束和受约束连续搜索的第一名、前列解及并列；另设计非连续归并优于连续分段的例子，验证挑战搜索确实覆盖预期移动。
- 构造“无约束第一名支持不足、另一个组合满足支持”的例子，确认后者仍能被找出并进入主表。
- 改变外部结局后，训练排序、成员映射和候选 ID 均保持不变；外部成绩随结局变化。主训练不含疫苗或 ACT 队列。
- 所有候选固定方向 AUC 在独立 pROC 核对中一致；组合 ID 与完整映射唯一对应。每个训练状态恰好属于一个等级且共有 K 个非空等级，覆盖率分母完整。
- 主表的任意一行都能回查完整成员、训练逐队列 AUC、外部 AUC 与区间、人数及四级基线 ID。前 5 的展示截断不能删掉前 20 的科学产物。
- 同一正式 DAG 在隔离合成 fixture/store 中贯通搜索、候选分支、评价和 HTML，并验证中断恢复与仅改展示参数时不重算搜索；不通过自定义执行链生成验收结果。
- 最终报告正文以组合和训练—外部成绩开篇；来源组选择 K=2、稳定性分位数或 DCA 均不能代替中心结果。正式产物验收、BAC 哈希链检查及 humanization 表达复核完成。

## 风险与明确边界

“最好”必须带上目标和搜索空间：连续分段主目标可验证精确前列解，非连续归并只报告预算内最好已找到解。近优候选多时如实标注截断，不以展示前 5 冒充只有 5 个优秀方案。

ICI 资格核对可能改变训练人数、可用状态与过去的 AUC；旧结果保留为旧口径，新的中心结论只使用新口径。现有支持阈值可能使高 K 没有可行连续解，此时同时展示无约束结果和非连续搜索状态，不事后为提高外部成绩调整阈值。

候选越多，外部最好的一行越可能包含选择乐观性。报告提供实际性能与候选全貌，并说明据外部结果推荐的步骤；不以该限制阻止用户查看和比较有价值的组合，也不把它写成否定整个分析的结论。
